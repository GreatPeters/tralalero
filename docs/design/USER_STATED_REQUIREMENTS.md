# 사용자 직접 발언 원칙·요구사항 원장

## 2026-09-20: 현재 기준 검은 원 +20%, 갈매기 +30%

사용자는 직전 적용 크기를 기준으로 검은 동그라미를 약 20%, 갈매기 크기를 약 30% 더 키워 달라고 요청했다. 착지 시점과 충돌 시 양쪽 회전 동작의 변경은 요청하지 않았다.

## 2026-09-20: 갈매기 추가 확대와 충돌 시 회전하며 튕겨 나감

사용자는 갈매기를 직전보다 약 50%, 검은 그림자 크기를 약 30% 더 키워 달라고 요청했다. 상어가 갈매기와 부딪히면 상어는 빙글빙글 돌고 갈매기는 튀어 나가면서 회전하도록 요청했다. 구체적인 갈매기 회전 수·궤적·연출 시간은 구현 선택이며, 앞서 요청한 미리 착지·접촉 피해는 유지한다.

## 2026-09-20: 상어 도착 전에 갈매기 착지 완료

사용자는 상어가 조금 지난 뒤에 갈매기가 완전히 내려온다고 지적했다. 첨부 화면처럼 상어가 아직 착지 지점에 도착하기 전인 시점에 갈매기가 이미 있어야 하며, 이를 위해 검은 표시도 더 일찍 나오도록 요청했다. 구체적인 거리·시간과 착지 후 대기 방식은 구현 선택이다.

## 2026-09-20: 갈매기 착지 표시의 명도·예고 시점·크기 후속 조정

사용자는 검은 착지 표시가 잘 보이지 않으므로 더 잘 보이게 하고 더 미리 나타나게 해 달라고 요청했다. 갈매기와 검은 표시의 지름은 직전 적용보다 약 50% 키우도록 요청했다. 구체적인 알파값, 거리와 대기 시간은 구현 선택이다.

## 2026-09-20: 갈매기 착지 그림자를 피할 수 있는 크기로 축소

사용자는 내려오는 갈매기의 그림자가 너무 커서 피할 수 없다고 지적했다. 첨부 화면에 표시한 작은 동그라미 정도로 줄여 피할 공간을 확보해 달라고 요청했다. 구체적인 미터 단위 크기와 모델·접촉 범위의 조정은 구현 선택이며, 앞선 접촉 시 두 바퀴 회전·약 20% 체력 감소 요구는 유지한다.

## 2026-09-20: 뚱보 투척의 떨림과 선행 발사 수정

사용자는 던지는 동작이 이상하고 선/손이 덜덜 떨리며, 실제로 던지기 전에 상자가 미사일처럼 먼저 날아간다고 지적했다. 양손으로 드는 요구는 유지하면서 떨림과 동작·발사 시점 불일치를 수정한다. 구체적인 동작 제어 방식, 셰이더와 시간값은 구현 선택이다.

## 2026-09-20: 갈매기 접촉 판정과 불이익

사용자는 갈매기와 닿지 않는 것 같고 닿아도 불이익이 느껴지지 않는다고 지적했다. 닿으면 기름처럼 캐릭터가 두 바퀴 돌고 체력이 약 20% 감소하도록 요청했다. 현재 체력/최대 체력 중 비율의 기준과 회전 시간은 직접 지정하지 않았으며, 구현 선택과 검증은 별도 작업 기록에 둔다.

## 2026-09-20 재수정: 뚱보가 상자를 양손으로 든다

사용자는 직전 상자 보정 화면을 보고 상자가 몸을 뚫고 간다고 지적하고, 양손으로 들게 해 달라고 요청했다. 오른손 하나에만 붙인 배치는 승인된 결과가 아니다. 몸 앞에서 양손으로 상자를 잡고 던지는 동작으로 수정한다. 배의 길 방향 대기·발사는 이번 요청의 변경 대상이 아니다.

## 성장과 밸런스

### U14. BonusWall : 적군 : 기믹 비율은 1 : 2 : 1로 적용한다

> 내가 BonusWall, 적군, 기믹 비율을 1:1:1로 했는데, 잘못인 것 같아. 1:2:1이 맞는 것 같아. 적군이 제일 많이 나오는 게 맞는 것 같아. 그렇게 적용해줘. 전반적으로. 근데 그렇게 하려면 배치도 네가 다시 해줘야겠지?

`1:1:1`은 사용자가 직접 정정한 이전 비율이다. `1:2:1`과 그에 맞는 재배치가 요구다. 25쌍/50명/25구간 같은 절대 수량이나 방어전의 별도 예외 비율은 사용자 발언으로 확정하지 않는다.

### U15. 업그레이드 후 생존시간이 늘어나는 구조를 만든다

> 15~~20초 정도가 늘어난 구조지.

> 300초를 다 깨려면

첫 30초, 업그레이드 후 45초·60초처럼 한 판마다 15~20초 정도 더 버티는 성장 구조와 300초 완주가 직접 제시되었다. 이전 같은 요청의 완주 도전 수는 15~20판이었고, 뒤의 U16에서 챕터당 20판을 명시했다.
