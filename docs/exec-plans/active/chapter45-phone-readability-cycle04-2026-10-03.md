# Ch4 촬영 군중 의미 전달4차

이번 주기 적용·검증 완료. 상세 결과는 [최종 검토](../../reviews/chapter45-phone-readability-cycle04-2026-10-03.md).

 기존 모델·리그·휴대폰 소품의 팔/시선/방향과 반응을 조정한다. 모델 생성·결제보다 기존 자료 수정 우선. 씬과 충돌/체력/피해/보상/위험물은 보존한다.

1. 실제 카메라와 같은 접근 거리의 수정 전/후 원본 화면 기록. 역할 설명 없는 새 독립 검토에서 화면만 보고 행동을 설명하게 한다. 안내 문구는 별도 blind 캡처에서만 가려 단서 제공을 피한다.
2. 역할 동작·pause/reset/death·근접 충돌·안전 통로·관련 위험 예고 검사. 거리 양쪽 기본 능력치350ms 반응 입력 회귀.
3. 기존60요구사항은 미확인/약한 의미 전달 항목을 재점검하되 통과한 범위의 반복 변경은 하지 않는다.
4. 최종 공유자산/원래 씬/기존미커밋/설정/PT 보존 확인. 폰검증/APK/commit/push/삭제/외부백업 금지.

변경 전 촬영역할은 기존 phone clip이 idle/walk에 연결되어 있었고, 소품은 왼손의 낮은 문자입력 자세를 따라갔다. 이 기준 화면에서 촬영 의미가 약해 양손 자세와 반응 단계를 개선했다.

## 최종 결과

- 역할 설명 없는 독립 검토에서 근거리 촬영 의미 개선·최종 보정 후 유지. 원거리/정확한 촬영 대상 모호성 명시.
- v3 짧은 팔 미도달 실패를 v4에서 수정·25/25.6F 사망/Replay15/15, 역할10/10, 집중39/39, 위험물8/8, 거리 두 선택 경로 새 완주.
- 소스2/컨트롤러3개 변경, 씬SHA 유지. 새생성/비용0. 현재 설정·공유자산 복원 검증 완료.
