# 예고와 실제 피해 판정 대조 — cycle11

최신 승인에 따라 맨홀·철근·TV·잡기·골프채·투척·돌진과 다른 예고 공격을 대조한다. 일반 접촉과 투사체 자체의 이동 충돌은 구분한다. 이전 청소부 검증은 재사용한다. 실제 native Update/물리 접촉으로 표시 밖 피해가 재현된 경우만 최소 수정하며 전투 수치와 난이도는 변경하지 않는다.

진행: 현재 상태와 306개 제품 파일·78개 게임 설정·정확히 허용된 저장 6키·Editor 시험 설정 9키·native registry 읽기 전용 기준을 기록. 저장된 장면의 역할/위험물 목록과 짧은 directed native 장면으로 범위·활성 시간·회피 경로를 대조한다. 초기 위치와 이전 구간 완료 처리는 시험 조건이며 일반 완주로 보고하지 않는다. 실제 피해/역할 Tick/위험물 Hit 수동 호출은 금지한다.

제품 수정 전 대상 소스의 최소 PC 내부 복구 사본을 만든다. 엔진 세션 값 복원 쓰기·폰·APK·새 생성·유료 호출·인증·설치·commit/push·외부 백업·기존 파일 삭제 금지. 테스트가 건드린 허용 게임 키와 시험용 Editor 설정만 현재 기준으로 복원한다. 기존 자산과 장면은 보존한다.


## 완료 — 2026-10-04 cycle11

재현된 이동 잡기/차량 표시 밖 접촉과 지면 아래 묻힌 경고를 코드2개·Jamsil1개에 수정했다. 63개 짧은 native 창, 최종15표본/1245활성상태, 수명주기11검사를 완료했다. 전체 경로·이어하기·기기 시험으로 집계하지 않는다. 골프·카트 기하 후보와 TV 실제 접촉 경계는 미확인으로 남긴다.

독립 원본 화면 검토2명 및 코드 검토1명 완료. 공유208자산·관측설정78개 보존. 4개 실패 도우미 시도와 복구도 남겼고 엔진 세션 복원 쓰기는 없었다. 새 모델/유료 호출/폰/APK/commit/push/삭제 없음. 청소부 표적 재시험0. 요구사항60행의 기존 필드는 유지하고 관련18행에만 cycle11 근거를 덧붙였다.
