# 휴게소 수동 360도 방어 수정

상태: 완료. 2026-09-25 후속 요청으로 방어 시간은 30초로 갱신됐고, 상단 배너·밸런스는 `map-concepts/meshy-reststop-2026-09-25/README.md`에 기록했다.

사용자 요청: 방어 중 사방을 볼 수 있는 쿼터뷰, 고정 위치, 좌우 드래그 수동 회전, 더 지속적인 적 접근. 이전 60초·초당90도 요구를 유지한다.

확인된 원인: `PlayerMove`가 고정 전투 입력을 무시했고 `RestStopHoldout.TryAim`이 방향과 무관한 최근접 적을 선택했다. `LateUpdate`는 자동 표적을 따라 몸체만 즉시 회전했다. 뒤쪽 카메라 계약이 그대로 유지되었고, 초기1.8초 지연 및1명씩 출현·최대40m 접근 거리로 화면이 비었다.

구현: 방어 컴포넌트가 드래그 입력을 읽어 최대90도/초 회전하고, 손을 떼면 정지한다. 고정 쿼터뷰는 몸체 회전에 영향받지 않는다. 원래 카메라와 이동은 방어 종료/사망/리셋에 복원한다. 네 접근 지점을13m로 배치하고 시작4명, 이후2~3명씩 기존16개 풀을 재사용한다. 전방10도 안에서만 보정하고 빈 방향에도 사격한다.

증거: `outputs/reststop-holdout-2026-09-25/`의 이전 씬·진행값·카메라 캡처, `tmp/image-previews/reststop-holdout-2026-09-25/`의 실제 런타임 캡처. 현재 컴파일 두 어셈블리 통과, 접근 경로84지점 지면 검사 통과. 최종 게임플레이/입력/복원 결과는 완료 후 기록한다.

기존 한국 휴게소 구조 분석 요청에서 추가된 문서 내용은 보존한다. 전체 레벨 재배치나 새로운 TRELLIS 생성은 이번 수정에 포함하지 않는다.
