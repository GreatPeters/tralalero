# 노량진 스크린샷 피드백 3차 적용

## 목표

사용자의 최신 첨부 화면과 직접 요구를 우선한다. 번호 수집과 불공정하게 보이는 무인 기물은 제거하고, 가림·물·셔터/연결 다리·컨테이너를 고친다. 냉동창고 내부를 실제 경매 공간으로 재구성한다. 최종9999/빠른 좌우 이동ON 검수 보고서를 실제 Claude Code 실행으로 독립 검증한다.

## 보호와 연결

- 작업 저장소는 D의 현재 프로젝트. 공식 Unity CLI/Pipeline에 프로젝트 경로를 지정하고 좁은 씬 명령으로 연결을 확인한다. Codex Unity MCP의 남아 있던 C 기본 인수도 D로 교체한다. 포트는 CLI가 발견하게 한다.
- 원본 SR18·Data.xlsx·Build Settings와 기존 dirty 작업·게임 저장값을 보존한다. 안전본 SR18_Revamp만 적용한다.
- Claude Code는 설치된 네이티브 CLI와 기존 로그인으로 보고서/코드/이미지를 읽도록 호출한다. 검증 결과와 실제 실행 영수증을 남기며 미실행을 실행 완료로 표현하지 않는다.

## 선택과 순서

- 새 에셋은 냉각기, 수산물 경매대, 얼음 위 참치 팔레트, 산업용 창고 입구4종. 기존 새 남녀 상인은 바닥 높이와 배치를 올바르게 맞추고 입찰/호명 동작을 추가한다. 형태가 부적절하면 검수 후 교체한다.
- 상자·문은 움직이는 부품과 프레임을 분리해서 실제 셔터 개폐로 보이게 한다. 가림 처리는 충돌/진행 바닥을 숨기는 수단으로 쓰지 않는다.
- 컨테이너/물의 판정 변경은 기존 규칙을 최대한 보존하되 불필요한 예고 기하와 갑작스러운 side spawn은 제거한다.
- 연결/백업 → 에셋 생성과 새 배치 → 규칙/표현 수정 → 씬 저장 → 검사와9999 Play → 발견 수정 → 보고서 → Claude Code 검증 → 지적 처리·최종 상태 확인.
