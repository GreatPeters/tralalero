# 노량진 개편 씬 수정·완성 (Codex 인계, 2026-09-28)

이 문서만 읽고 작업을 시작할 수 있게 정리했다. 기획 원본은 Claude Docs 문서 "노량진 맵 개편 기획"
(<https://claude.ai/code/artifact/cb72a501-1556-40c6-8aae-f3679371003c>)이다. 로그인 없이는 열리지 않을 수 있으므로
필요한 기획 내용은 아래에 모두 옮겼다. 콘셉트 이미지는 로컬 `outputs/noryangjin-revamp-2026-09-27/concepts/`에 있다.

## 0. 먼저 읽을 것과 지킬 것

- `AGENTS.md`, `docs/design/USER_STATED_REQUIREMENTS.md`, `outputs/noryangjin-revamp-2026-09-27/README.md`(1차 적용 기록).
- 작업 대상 씬: `Assets/ShooterSurvival/Scenes/Tools/Noryangjin_MapTool_Mode_SR18_Revamp.unity`만 고친다.
- 원본 `Noryangjin_MapTool_Mode_SR18.unity`와 Build Settings는 바꾸지 않는다. 교체는 사용자가 따로 결정한다.
- 맵툴 편의 탭 "시작 스테이지 1 (노량진)"은 이미 개편 씬으로 Play를 시작한다. 확인할 때 이 버튼을 쓴다.
- 맵툴 테스트 속도의 1배/2배/3배는 그대로 둔다. 2배를 빼지 않는다(사용자 확정).
- 개편 요소의 원본은 `tools/install-noryangjin-revamp.cs`이다. 이 스크립트는 씬의 `NoryangjinRevamp` 루트를
  지우고 다시 만든다. 그러니 루트 아래 수정은 씬에서 손으로 하지 말고 스크립트에 넣는다.
  루트 밖의 씬 수정(예: 경매장 옆 점포 12개 끄기)은 스크립트가 되돌리지 않는다. 이런 수정은 무엇을 바꿨는지 README에 적는다.
  - 재생성: `unity command --project-path . run_script --file tools/install-noryangjin-revamp.cs --entry InstallNoryangjinRevamp.Main`
- 런타임 코드: `Assets/ShooterSurvival/Scripts/Game/NoryangjinRevamp/`
  (Director, 이벤트별 `Noryangjin*Event`, `NoryangjinBreakable`, `NoryangjinRevampSuppressor`).
  배치 데이터는 `ChapterSceneKey`로 SR18의 Data.xlsx 행을 그대로 쓴다.
- 새 Meshy 모델: 먼저 목록과 예상 크레딧을 보여 주고, 콘셉트 이미지를 확인받은 뒤에 만든다.
  Meshy는 모델·텍스처 생성에만 쓰고, 이미지는 Codex가 만든다. 노량진 Meshy 예산은 아직 정하지 않았다.
  지금까지 120크레딧을 썼다(N01 터렛트, N02 LPG 가스통).

### 1-1. 실내 시장동을 진짜 건물 안으로 (콘셉트 `n6-indoor-v3.png`, 보조 `n6-indoor-v2.png`)

- 기획: 낮은 흰 천장, "활어-135 오성수산" 같은 파란 번호 간판, 빨간 디지털 시계, 천장 TV, 번들거리는 젖은 바닥.
  휴게소 건물 내부에서 이미 해 본 방식으로 천장 있는 건물 안을 지나가게 한다.
  낮은 천장이 카메라를 가리는 문제는 기존 가림 처리(`NoryangjinCameraOcclusion`, 반투명)로 풀고,
  필요하면 이 구간만 카메라를 조금 낮춘다.
- 해야 할 것:
  - 구간(`HallOrigin (124.3,0,45)`에서 남쪽으로 약 378m) 안의 나무 판자 바닥을 젖은 타일이나 콘크리트로 덮거나 숨긴다.
  - 같은 구간의 SR18 점포, 차양, 부두 난간, 바다가 보이는 옆면을 숨기고, 실내 벽과 가게 칸으로 바꾼다.
  - 카메라 화면 안에 들어오는 높이에 낮은 흰 천장과 조명을 둔다.
  - 기존 SR18 고가 교차(along 36~68, 112~134)와 겹치는 부분의 처리를 정한다.
  - 기존 점포는 `NoryangjinRevampSuppressor`처럼 개편 씬 실행 중에만 숨기는 방식을 우선한다.
- 휴게소 실내 참고: `Assets/ShooterSurvival/Scenes/Tools/RestStop.unity`와 `tools/`의 reststop 관련 스크립트(예: `RestStopSceneBuilder.cs`).

### 1-2. 기존 기물과 겹치지 않게 (모든 세트 전체 점검)

- 각 세트(A 바리케이드, E~H 실내 시장동, C 파도, D 경매장, I 보스, 랜덤 게이트 2곳)의 진행 구간 앞뒤로
  SR18의 적, 보너스, 기믹, 점포, 소품이 있는지 전부 조사한다.
  ID 목록 대신 구역 기준(`InZone`, `InHallEvents`, `InPier` 확장)으로 적도 숨긴다.
- `EncounterPlacementController`가 Data.xlsx로 적을 다시 켜므로 씬에서 지우지 말고 Suppressor로 숨긴다.
  Data.xlsx도 바꾸지 않는다(원본 SR18과 같이 쓴다).
- 터렛트 위의 화물 상자와 운전자, 체력 숫자, 피해 숫자가 한 덩어리로 겹치지 않게 크기와 위치를 정리한다.
  콘셉트: `n7-turret.png`.
- 끝나면 세트마다 에디터 캡처와 Play 캡처를 찍어 겹침이 없음을 보인다.

## 2. 아직 적용하지 않은 기획 항목 (전부 진행)

1차 적용은 A~I의 뼈대만 만들었다. 아래는 기획서에 있지만 빠진 것이다.
(확정)은 사용자가 좋다고 한 항목이다.

### 2-1. B. 60초 갈림길: 시장 건물 안 / 바깥 부두 (확정, 콘셉트 `n3-fork.png`)

- 고속도로와 같은 카드 팝업을 쓴다. 5초 동안 고르지 않으면 안쪽(건물)으로 간다. 두 길은 150초쯤 냉동 창고 앞에서 합류한다.
- 안쪽 길은 E 실내 시장동이고 공격력이 높은 플레이어에게 유리하다. 바깥 길은 C 파도 부두이고 잘 피하는 플레이어에게 유리하다.
- 지금은 실내 시장동이 기존 남쪽 직선 위에 있고 분기가 없다. 새 길이 필요하다.
  기획서의 "기존 230개 길 보존 규칙"은 B가 확정되면서 풀어야 하는 상태다. 개편 씬 안에서만 바꾼다.
- 고속도로의 기존 갈림길 코드를 재사용한다(`docs/design/USER_STATED_REQUIREMENTS.md`의 60초 분기 항목 참고).

### 2-2. E. 실내 시장동 세부 (콘셉트 `n6-indoor-v3.png`, 러시 참고 스샷 없음)

- 호객 러시: 상인 15명 안팎이 "잡아!", "보고 가!"를 외치며 정면에서 우르르 달려온다. 지금은 9명이다.
  옆에 서 있기만 하는 상인은 두지 않는다.
- 바가지: 상인에게 잡히면 체력 대신 코인을 잃는다("바가지! -30코인"). 방식이 괜찮은지는 사용자에게 아직 묻지 않았다.
- 짐 카트: 스티로폼 상자를 실은 손수레가 통로를 가로지른다.
- 천장 TV 뉴스: "속보: 상어, 노량진 시장동 진입". 이미 있으니 새 천장 높이에 맞춰 보이게 한다.
- 가게 지킴이 고양이: 그 가게를 건드리지 않고 지나가면 뒤에서 코인을 물어다 주는 숨은 보너스.

### 2-3. 더 넣어 볼 재미 (기획서 "더 넣어 볼 재미" 절)

- 번호 모자 수집: 놀란 중도매인과 상인이 떨어뜨린 번호 모자를 주울수록 D 낙찰 보상 등급이 오른다.
- 관리사무소 방송: 시장 스피커 방송이 내 행동에 반응한다("활어 코너 고객님들은 상어를 피해 주세요").
- 손수레 행렬: 상자 실은 손수레가 줄지어 통로를 가로지른다. 틈으로 지나가거나 부수고 지나간다.
- 상하차 상자 토스: 하역장 일꾼들이 통로 양쪽에서 상자를 던져 넘긴다. 사이로 지나가거나 공중에서 맞혀 떨어뜨린다.
- 활어차 후진: "후진합니다" 경고음과 함께 한 차로를 막는다. 부수면 물과 활어가 쏟아져 바닥이 미끄러워진다.

### 2-4. 그 밖의 사건 후보 (기획서 "그 밖의 사건 후보" 절, 사용자가 링크한 항목)

- 크레인 컨테이너: 작업항에서 그림자로 떨어질 자리를 보여 주고 내리꽂는다.
- 도망치는 수조 카트: 앞에서 달아나는 카트를 부수면 코인이 쏟아진다.
- 갈매기 떼: 기존 갈매기 기믹을 여러 마리로 묶은 사건.
- 시장 방송 자막: "오늘 참치 시세 폭락, 상어 때문"처럼 내 행동에 반응한다.
- 규칙: 한 순간에 큰 위험은 하나만 둔다. 갈림길, 회전 주변, 사건 직후에는 새 위험을 넣지 않는다.

### 2-5. 노량진다운 작은 재미

- 새벽 시계: 화면 구석 시계가 04:00에서 경매(04:30)를 지나 해 질 녘까지 흐른다. 구역별 하늘색과 맞물린다.
  지금은 조명색 변화와 고정 시계뿐이다.
- 미끄러운 바닥: 깨진 수조 물이 고인 곳에서 좌우 이동이 잠깐 미끄러진다.
- 스티로폼 상자 단위 보너스: 부순 상자에서 생선과 코인이 한 상자씩 쏟아진다.
- 1호선 전철과 육교: 방파제 구간 멀리 육교 위로 전철이 지나간다.

## 3. 사용자에게 물어볼 것 (답을 받기 전에는 기본값으로 진행하고 README에 적는다)

1. 바가지 벌: 체력 대신 코인을 잃는 방식이 괜찮은가.
2. 파도 즉사: 포트홀처럼 부활 규칙을 그대로 쓸지, 파도만 따로 둘지.
3. F 터렛트와 I 아줌마를 하나의 보스로 합칠지(아줌마가 터렛트를 모는 뜻이었는지).
4. 난이도: 1챕터인데 현재 세이브 완주가 0/4다. 사건을 더하면서 앞 60초를 더 쉽게 할지.
5. Meshy 예산: 고속도로의 2,000크레딧 한도를 노량진에도 적용할지. 새 모델 목록과 크레딧은 먼저 보여 준다.

## 4. 검증과 기록

- `dotnet build Assembly-CSharp.csproj -nologo`, `dotnet build Assembly-CSharp-Editor.csproj -nologo`.
- Unity: `unity command --project-path . list_open_scenes`로 연결을 확인한다. 테스트는
  `unity command --project-path . --timeout 280 run_tests --mode EditMode --filter <이름>`로 돌린다.
  `NoryangjinMapToolTestStartStageTests`는 8/8을 유지한다.
