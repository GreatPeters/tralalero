# 휴게소 Blender v2 — 실제 게임 기준, 확대 시설, 쿼터뷰

사용자는 화장실·편의점이 여전히 작다고 지적했고 실제 게임 기준, 더 많은 자동차, 재미있는 기믹과5구간 쿼터뷰를 요구했다.300초·10구간·60초 제자리 방어·90도/초 제한과 TRELLIS/Seedance 제외는 유지한다. 이번 결과는 새 Blender 버전이며 Unity 설치 요청으로 확대 해석하지 않는다.

## 실제 게임에서 읽은 값

- 공식 Pipeline으로 현재 HighWay와 RestStop 미리보기 씬을 읽었다. 원래 활성 씬과 dirty=false 상태가 보존됐다.
- 상어 시각 바운드: 폭2.7495, 길이5.1901, 높이3.2624유닛. 현재 캡슐 반경0.46,루트 스케일1.5.
- 실제 카메라: 수직FOV40도, 높이 오프셋12.546,후방19.269,피치17.4656도.
- Data.xlsx:휴게소 속도7.8유닛/초, 경찰3.8유닛/초,기본 등장 간격1.05초. 기존 게임의 방어시간30초는 이번 사용자 요청의60초와 구분한다.
- 게임에서 실제 사용한 차량2종의 FBX/텍스처를 재사용한다. 새 TRELLIS 생성은 하지 않는다.

## 제작 선택

- 편의점과 화장실은 상어와 기본 통로 폭을 기준으로 대형 시설로 재구성한다. 임의의 실측㎡ 대신 게임 유닛과 이전 크기 대비를 기록한다.
- 일반 이동은7.8유닛/초를 기준으로 한다. 남는 구간 시간은 차단기·교전·위험 예고의 짧은 대기로 배분하고 숨은 슬로모션으로 늘리지 않는다.
-5구간은 사선 쿼터뷰로 고정하고 상어 몸체만 연속 회전한다. 적의 접근 방향과 피격을 읽을 수 있도록 가까운 전투 구역과 경고를 둔다.
- 조밀한 주차 구역, 여러 후진차, 교차 차량, 짐/식사 카트, 상품 진열대 쓰러짐, 청소 로봇·누수, 주유소 대형 차량, 연속 차단기를 실제 키로 움직인다.
- 전체 렌더 전 각 구간과 사건의 시작/작동/종료를 먼저 확인한다. 렌더는 Blender의 네이티브 animation=True를 기본으로 한다.

## 확인한 보정

- 평가된 상어 몸체와 조준 표식을 분리해서 크기를 측정했다. 기준 프레임의 최종 크기는 2.749493×5.190154×3.262408 유닛이다.
- 방어 시작 직전 프레임까지 포함한 최대 회전 속도는 89.989327도/초다. 방어 중 XY 위치 고정과 사선 카메라를 네이티브 프레임으로 확인했다.
- 도로 곡선에서 접선으로만 움직이던 출구 차량이 잔디를 지나는 결함을 수정했다. 전체 렌더를 새 프레임 폴더에서 재시작해 이전 프레임의 혼입을 방지했다.
- 전체 지도용 원거리 카메라는 게임 촬영용 far clip 값을 그대로 쓰면 먼 진입로를 자른다. 별도 전체 지도/새 GLB 임포트 촬영에는 충분한 far clip을 사용한다.
