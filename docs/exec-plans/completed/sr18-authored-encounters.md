# 범위

사용자가 마지막으로 제공한 실제 SR18 맵을 기준으로 현재 `map2` 브랜치의 `Noryangjin_MapTool_Mode_SR18.unity`에 배치한다. 기존 230개 길, 666개 Props, 물, 회전·경사 스팟과 게임 인프라는 유지한다. 새 길, 건물, 그림용 확대, 밸런스 테이블 변경, 강제 보너스 1택이나 보스 보상 잠금은 포함하지 않는다.

# 작업 단위

1. 현재 씬 사본을 백업하고 기존 배치·프리팹 기본값을 기록한다.
2. 전체 흐름 데이터의 25개 편성(적 69명)과 9개 보너스 지점(14개)을 표준 맵툴 크기로 설치한다. 순차 편성은 발동 스팟을 나눠 총 31개로 연결하고, 이동 적 27명에는 독립적인 목표를 둔다. 첫 고가의 두 편성은 상부 평지에 둔다.
3. 씬 계약 검사를 갱신한다. 원본 길·소품 보존, 정상 크기, 실제 바닥 높이, 연결 누락·몸체 겹침, 보너스 등급·보존 마커를 검사한다. 저장 후 집중 테스트와 실제 플레이 상태의 발동/리셋을 확인한다.
4. 실제 저장된 씬의 전체·플레이 시점 화면과 검증 기록을 전달한다.

# 검증 경계

출현 수·배치는 1차 플레이테스트용이다. 생존 30초와 4–5분 완주 난이도는 본 작업만으로 확정하지 않는다. 테스트에서 코인·업그레이드 영구 저장을 변경하지 않는다. 원본 Map1/Map2와 빌드 씬 목록을 수정하지 않는다.
