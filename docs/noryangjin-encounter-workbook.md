# 노량진 조우 엑셀 설정

2026-09-10 현재: 적27명·고정 선택25쌍·기믹24지점, 총76행이다. `적 배치`28/29행은 E02/E06의 오른쪽 Normal 적이며 N/O는 각각4/8행을 참조한다. 보너스 쌍과 달리 적은 독립된 사용 여부·이벤트·발동 스팟·사망/드롭을 가지므로 오른쪽 적도 별도 행으로 등록한다. 기존25개 적 행과 성장 수식은 유지한다. [현재 배치와 검증](../map-concepts/sr18-contact-pairs-2026-09-10/README.md).

2026-09-07, `Data.xlsx`에 SR18의 적 25명·고정 BonusWall 25개·기믹 24개 설정을 추가했다. 기존 8개 시트는 보존했다. 길·상점·배치 위치와 모델은 맵툴이 관리하고, 엑셀은 기존 배치의 사용 여부와 동작을 관리한다.

2026-09-09 변경: 고정 보너스는 **25쌍(실물 50개)**이다. 엑셀 25행은 그대로 유지하며 기존 왼쪽 배치ID 한 행이 좌우의 등급과 사용 여부를 함께 관리한다. `_Right` 행을 별도로 추가하지 않는다. 한쪽 선택 시 다른 쪽은 닫히고, 처치 드롭은 기존 단일 제단이다. [배치·검증 기록](../map-concepts/sr18-choices-and-corner-space-2026-09-08/README.md)을 따른다.

## 수정할 시트

| 시트 | 설정 |
| --- | --- |
| 적 배치 | 사용, 이벤트, 이동 설정, **타입(M), 공격력(N), 체력(O), 증가율(P)** |
| 몬스터 성장 | 배치 전투 수치가 없는 기존 맵의 챕터·티어별 수치. SR18의27명에는 적용하지 않음 |
| 보너스 배치 | 고정 제단 사용 여부와 Normal/Rare/Unique 등급 |
| 보너스 | 기존 효과와 최소/최대 수치 |
| 기믹 배치 | 사용과 효과값. Bucket은 3개 묶음의 각 바구니에 적용할 발사 금지 지속 초, Light/Hole은 접촉 피해량 |
| 환경 변수 | playerDefaultHp 등 플레이어 기본값 |

`사용`은 1=유지, 0=숨김이다. 맵·배치ID는 씬/배치 이름과 일치해야 한다. 기믹종류는 모델 확인용이며 셀만 바꿔 다른 3D 모델로 변환하지 않는다. 행 삭제는 씬 오브젝트 삭제가 아니다. 배치를 빼려면 사용=0을 쓴다.

이동거리는 왕복의 전체 폭(기본 8), 매복 진입점의 전방 거리(보통 8, 짧은 E05/E24 구간은 4), 또는 지정 이동 거리다. 매복은 길 가장자리 1.6유닛에서 보이는 상태로 대기하고 속도 3의 Walk로 중앙 진입 후 0.8초 준비하여 사격한다. 발동앞거리는 조우 중심에서 뒤쪽 발동선까지의 거리이며 매복 기본값은 44다. 코너 안전구간에 의해 실제 앞거리가 줄어드는 두 짧은 구간은 걷는 거리를 줄여 사격 준비 중 플레이어가 너무 가까워지지 않게 했다. 사격은 투사체가 설정된 경비원/뚱보만 지원한다. 이동은 같은 높이의 길 안에서만 허용한다.

## 적 공격력·체력·타입 (2026-09-09)

SR18은 `적 배치`의 **공격력·체력·타입이 최종 기준**이다. 타입은 Normal/Elite/Boss 중 선택하며 보스 추가 피해 판정도 이 값을 따른다. 몬스터/몬스터 성장 시트를 수정해도 이 배치의 수치를 덮어쓰지 않는다. 세 전투 열 중 일부만 있거나, 체력이 0 이하이거나, 비정상 수치면 거부한다. 세 열 모두 없는 구형 데이터만 기존 성장 방식을 유지한다.

Normal 기본 수식은 직전 Normal의 수치에 `1+증가율`을 곱하고 정수 반올림한다. 공격력 33→43→56, 체력 55→72→94로 시작한다. Elite는 직전 Normal의 공격력 ×55/33·체력 ×2, Boss는 공격력 ×5·체력 ×190/55를 초기 수식으로 사용한다. 첫 Normal과 Elite/Boss의 P열은 비어 있으며 적용되지 않는다. **N/O열 수식을 원하는 숫자로 덮어써도 된다.** M열은 실제 전투 타입을 바꾸지만 모델은 바꾸지 않는다.

후반 Normal은 공격력 6,339·체력 10,607, 마지막 Boss는 31,695·36,642로 크게 상승한다. 이는 요청한 강한 성장 곡선의 초안이며 플레이어 성장과 전체 완주 난이도는 별도 검증 대상이다. 기존 다른 9개 시트는 보존했다.

코너 대응 여유가 엑셀 앞거리보다 우선한다. `EnemyCornerClearance`가 설치된 SR18 적은 시작/목표 지점이 코너 뒤 28유닛 이상이어야 하며, 발동 스팟 중심은 20유닛 이상 뒤로 제한한다. 경로의 일부 지점은 간격 확보를 위해 재배치했으므로 배치ID의 T값은 식별자이지 실측 시각이 아니다.

## 적용

맵툴 `편의 > Data.xlsx 열기`에서 수정·저장하면 **다음 Play부터 배치 설정이 적용된다**. 전투 중 저장해도 이미 진행 중인 적이나 제단을 되감지 않는다. Domain Reload와 Scene Reload가 꺼진 현재 프로젝트에서도 Play 진입 시 다시 적용한다. 배치가 수치를 소유한 적은 이후 챕터 성장 계산에서 건너뛰므로 체력이나 타입이 덮어써지지 않는다.

기존 몬스터·보너스 효과·플레이어 기본값 재로딩은 유지한다. 제단 등급을 적용할 때 효과·수치·UI도 새 등급으로 다시 추첨하므로 등급 표시만 바뀌고 옛 효과가 남지 않는다. 빌드는 기존 서명·암호화 `Data.bytes`를 사용하며 이번 데이터로 보호 파일도 갱신했다. 이후 빌드 시에도 자동 갱신/검증된다.

중복 ID, 잘못된 이벤트·등급·사용값, 음수·비정상 숫자는 거부한다. 없는 배치, 사격 불가능 모델, 기믹 종류 불일치, 길 밖 이동은 실제 변경 전에 거부하며 `[EncounterData]` 로그에 원인이 나온다. 원본 프리팹·맵툴 저장 좌표는 덮어쓰지 않는다. 처치 보너스 드롭은 기존 규칙이며 고정 제단 25개와 별도다.

## 체력 수정

기존 `ReloadCharacterDefaults()`는 기본 최대값만 다시 읽고 현재 체력과 업그레이드 반영 최대값을 갱신하지 않았다. 이제 함께 갱신하되 체력 비율을 유지한다. 완전한 50/50은 최대값 100 변경 후 100/100이 된다. 이미 피해를 입었거나 사망한 플레이어를 엑셀 저장만으로 회복/부활시키지 않는다. 업그레이드 관리자가 없어도 오래된 최대값 캐시를 제거한다.

실제 새 Play에서 현재·최대 체력과 HUD가 모두 100/100임을 확인했다. 사용자가 본 특정 50/100 화면의 직전 피격 이력은 확인하지 못했다. 가로등 접촉 피해 50 등 실제 피격에 의한 감소는 정상이며 없애지 않았다.
