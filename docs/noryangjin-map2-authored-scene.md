# 노량진 맵2 정적 구현 기록

## 상태

`Assets/ShooterSurvival/Scenes/Tools/Noryangjin_MapTool_Mode_2.unity`는
`outputs/chapter_campaign_reference_orthogonal_20min`을 현재 맵1 위에 구현한 정적 씬이다.
맵1을 원본 그대로 복제한 뒤 맵2에만 경로와 환경을 추가했으며, 다시 생성하는 에디터 명령은 두지 않는다.

보호 기준:

- 맵1 GUID: `594a2107b4741084ea468072f4b4642a`
- 맵1 SHA-256: `6A72F7D82D672059143AB38EDB1F366FAB00042B6D204B6FBE7494F233947109`
- 맵2 GUID: `e07c347ef8dc34844882b8b0c4fd1763`
- 현재 맵2 SHA-256: `08B18CFC4B941A58D1ABEAC499730637DDFC58D1619DC9952F9085D6C3B22139`
- 두 씬 모두 게임플레이 루트 9개를 가지며, 맵2의 앞 24개 도로와 162개 소품은 맵1과 이름·프리팹·Transform이 같다.
- Build Settings는 맵1 `Noryangjin_MapTool_Mode` index 0, `Forward March Mode` index 1만 유지한다.

## 설계도 재검증

참조 묶음은 서로 다른 제작 시점의 수치를 함께 담고 있었다.

| 항목 | 참조에 기록된 값 | 현재 씬에 적용한 판단 |
| --- | --- | --- |
| 복제 원본 | 도로 21, 소품 170 | 현재 맵1의 실제 값인 도로 24, 소품 162를 그대로 사용 |
| 본선 목표 | 워크북 총 142개 | 현재 24개 + 명시된 구간 합계 118개 = 142개 |
| 최종 도로 | 후대 리포트 총 146개 | `21 + 본선 117 + 가지 8`이라는 과거 기준이다. 명시된 구간 수의 합은 실제로 118이므로 현재 기준은 `24 + 118 + 8 = 150` |
| 모듈 피치 | 과거 작업 기록 8.85 | 현재 맵툴 프리팹의 실제 피치 11.25 |
| 최종 소품 | 총 511개 | 현재 162개를 보존하고 349개를 추가해 총 511개 유지 |
| 이동 시간 | 약 4분 30초 | 현재 런타임은 `playerSpeed` 값1인 8 units/s 고정이며 가속하지 않는다. 같은 약 1,582-unit 기준은 회전 정지 전 약 198초다. |

따라서 맵2의 수용 기준은 “과거 씬 수량을 재현”하는 것이 아니라 “현재 맵1을 바이트 수준으로 보존하면서, 참조의 명시적 경로와 최종 시각 구성을 구현”하는 것이다.

## 구현 구성

- 도로 150개
  - 맵1 복제 24개
  - 본선 118개: `E13 → N18 → W17 → S12 → W6 → N19 → E33`
  - 중앙 `+` 막다른 가지 8개: 북 4개, 남 4개
- 소품 511개
  - 맵1 복제 162개
  - 바다 타일 196개
  - 부두 20개
  - 시장 소품 123개
  - 회전 스팟 6개
  - 고속도로 요소 4개
- 회전 스팟은 복제된 2개를 포함해 총 8개다.
- 동쪽 종점은 도로와 0.25-unit 겹쳐 접속하는 90-unit 고속도로 데크, 표지판, 톨게이트, 터널로 끝난다.
- 바다는 전체 도로 외곽에서 최소 70-unit 기준을 넘기며, 현재 최소 실측 여유는 81.7 units다. 맵2 전용 `Noryangjin_Map2_Water.mat`은 원본 아틀라스의 물 영역만 반복해 참조 전체도처럼 연속된 수면을 만든다.
- 부두는 5개씩 네 군집이고, 시장 소품은 `31 / 31 / 31 / 30` 네 군집이다. 큰 시장 건물 22개는 `6 / 6 / 5 / 5`로 모두 부두 위에 놓였다. 시장 소품끼리 수평 Renderer bounds 겹침은 0건이고 경로 중심선 최소 여유는 9.50 units다.

## 의도적으로 남긴 런타임 범위

맵2는 참조의 지형·경로 구현이다. 4분 30초 이동 시간과 5개 챕터/20분 웨이브 구성은 현재 이동 코드 및 웨이브 데이터와 계약이 맞지 않아 구현 완료로 간주하지 않는다. 이를 맞추려면 공용 `playerSpeed` 값1을 임의로 바꾸지 말고, 맵2 전용 속도 또는 구간 시간과 웨이브 정의를 별도 요구사항으로 결정해야 한다.

## 검증

```powershell
dotnet build Assembly-CSharp.csproj -nologo
dotnet build Assembly-CSharp-Editor.csproj -nologo
powershell -ExecutionPolicy Bypass -File tools/validate-agent-harness.ps1
```

- `NoryangjinMapToolMode2SceneTests`
- `MapProductionToolMenuTests`

첫 번째 테스트는 맵1 해시, 복제 접두 구간, 경로·가지·회전 스팟, 시장 충돌/여유, 부두 군집, 바다 외곽 여유, 고속도로 접속, Build Settings 비포함을 검사한다. 두 번째 테스트는 남은 수동 맵 제작 메뉴와 참조 폴더 연결을 검사한다.
