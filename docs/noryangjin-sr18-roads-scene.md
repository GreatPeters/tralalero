# 노량진 SR18 등대 인피니티 제작 씬

## 상태

`Assets/ShooterSurvival/Scenes/Tools/Noryangjin_MapTool_Mode_SR18.unity`는 현재 노량진 맵1을 원본으로 만든 정적 맵 제작 씬이다. 기존 맵1과 `Noryangjin_MapTool_Mode_2.unity`는 변경하지 않았으며, SR18 씬도 Build Settings에는 포함하지 않았다.

길 전용 기반 제작과 도로 접합 수정 후, 2026-09-05 길 양옆 상점 배치를 적용·저장했다. 이전 417점포·넓은 지면 배치는 길을 가리고 별도 시장 골목을 만들어 철회했다. 현재 점포 306개, 좁은 안벽 306개와 기존 장식·코너 스팟 15개·경사 스팟 8개를 합친 `Props` 기존 직접 자식은 666개이며, `Water`에는 배경 물 1개가 있다. 플레이어·카메라·Managers·Canvas·EventSystem·UpgradeServices와 맵툴 루트를 유지한다. 2026-09-09 적 25명, 고정 보너스 25쌍(50개), 기믹 24개와 코너 대응 공간을 적용했다. Props에는 적 발동 스팟 25개·기믹 24개를 추가해 현재 직접 자식은 715개이며, 독립 이동 목표 10개는 SR18_EnemyTargets에서 관리한다. 기존 길·소품은 그대로 보존했다. [적용·검증 기록](../map-concepts/sr18-choices-and-corner-space-2026-09-08/README.md)을 참고한다.

## 고밀도 시장 배치

- 기존 맵1에 실제 배치된 점포 세 종류의 크기·정면·인스턴스 오버라이드를 재사용해 306점포를 기존 길 양옆에 배치했다. 별도 내부 시장 블록은 없다.
- 점포를 받치는 안벽 306개는 폭 9 × 길이 12.2이며, 상점·지면 모두 나무 길 전체 경계와 겹치지 않는다. 점포 이외의 기존 장식 31개와 물 배경 1개를 유지한다.
- 도로 230개와 회전 스팟 15개는 변경하지 않았다. 코너·경사·입체 교차 주변에서는 상점 후보를 제외해 경로를 드러낸다.
- 모든 배치물은 연결된 프리팹 인스턴스다. 외곽선과 물 타일링은 SR18 전용 재질 13개에 저장했으며 원본 공유 재질은 변경하지 않았다.
- 현재 배치, 최종 수량, 복구 백업과 적용 스크립트는 [기존 길 중심 상점 배치 기록](../map-concepts/sr18-roadside-market-2026-09-05/README.md)을 따른다.

## 경로 규격

- 보존 구간: 맵1 도로 51개와 회전 스팟 5개
- SR18 신규 구간: 도로 179개와 회전 스팟 10개
- 전체: 도로 230개, 수평 코너 스팟 15개와 추가 경사 스팟 8개
- 신규 경로: `남27 → 서17 → 북24 → 동26 → 북12 → 동9 → 북13 → 동10 → 남6 → 서17 → 북18`
- 최종 진행 방향: 북쪽
- 신규 길 종류: 기본길 157, 오르막길 6, 내리막길 6, 우회전길 8, 좌회전길 2
- 신규 도로 루트 경계: 대략 `X -67.00~439.25`, `Z -347.75~338.50`
- 배치 기준: 맵1 종점의 실제 판자 출구 `(124.2499, 0, -44.0011)`, 피치 11.25

전체 179개 Transform과 교차 계약은 `map-concepts/noryangjin-expansion-2026-09-02/sr18-unity-placement.json`의 schemaVersion 2를 따른다. `source.endpointWorld`는 원본 프리팹 피벗이며 실제 경로 원점은 `target.routeOriginWorld`다.

## 2026-09-05 도로 표면 수정

초기 제작본은 직선 부두 프리팹의 한쪽 끝 피벗을 도로 중앙으로 취급해 코너가 어긋났다. 판자보다 길게 뻗은 기둥을 포함한 Renderer 경계 검사는 바닥의 틈을 검출하지 못했다. 이를 실제 판자 길이 4.95와 중앙 X=-1.5 기준으로 보정했다.

`Assets/ShooterSurvival/Models/Generated/SR18RoadDecks/`의 여섯 공유 메시가 중앙 정렬 직선, 코너, 코너 진입부, 고가, 오르막, 내리막 표면을 담당한다. 원래 맵툴 프리팹 연결과 재질은 유지하며, MeshFilter와 MeshCollider가 같은 보정 메시를 참조한다. 코너의 출구 길은 3.3만큼 뒤로 확장하고 진입 길은 같은 양만큼 줄여 빈 모서리와 판자 중복을 없앴다. 일반 이음새에는 0.24의 여유를 둔다. `이어 복붙`은 해당 프리팹 인스턴스의 메시 오버라이드도 함께 보존한다.

## 입체 교차

2026-09-05 경사면의 검은 줄무늬는 텍스처 손상이 아니라 기존 도로 재질의 강한 셀 셰이딩으로 확인했다. 오르막·내리막 12개만 `Materials/Generated/SR18_RoadSlope.mat`를 사용한다. 음영 크기는 `0.838 → 0.45`, 경계 완화는 `0.016 → 0.08`로 조정했고 나무 텍스처·메시·위치·충돌과 공용 재질은 유지했다. [원인 및 검증 기록](solutions/ui-bugs/avoid-binary-black-cel-shadows-on-sr18-ramps-2026-09-05.md)을 참고한다.

세 교차는 하나의 갈림길이 아니라 먼저 지나간 하부 길을 나중의 상부 길이 넘어가는 구조다.

| 교차 | 하부 | 상부 | 기준 좌표 |
| --- | --- | --- | --- |
| 첫 8자 중심 | 신규 3번 | 신규 85번 | `(0, -3)` |
| 기존 맵 재통과 | 맵1 첫 도로 부근 | 신규 73번 | `(-12, -3)` |
| 등대 고리 중심 | 신규 122번 | 신규 154번 | `(18, 16)` |

- 상부 기본길의 루트 Y는 12다. 고가의 기둥 하단을 짧게 조정해 하부 도로와 겹치지 않는다.
- 첫 경사: 70~72번 오르막, 73~86번 고가, 87~89번 내리막.
- 두 번째 경사: 151~153번 오르막, 154~155번 고가, 156~158번 내리막.
- 경사 한 조각마다 높이 4를 변화시켜 3개 길, 33.75의 수평 거리로 높이 12를 연결한다. 내리막은 높이가 실제로 감소한다.
- 초기 도면의 한 조각 내리막을 세 조각으로 늘려 실제 고가 영향 구간은 `[70,90)`, `[151,159)`다. 도로 총수, 회전 순서, 세 교차는 유지한다.

SR18 플레이어에 `NoryangjinRoadHeightFollower`를 추가해 실제 도로 표면 높이를 따른다. 네 경사 구간의 시작·끝에는 이동 유지 스팟 8개가 있으며, 전진을 멈추지 않고 0.25초 동안 약 ±19.573°와 수평 자세 사이를 전환한다. 기존 카메라도 캐릭터와 함께 이동한다. 두 고가 구간의 Play Mode 상승·하강을 확인했으며, 전체 스테이지 전투·완주·모바일 성능은 별도 검증 대상이다. [경사 설정과 실행 증거](../map-concepts/sr18-slope-spots-2026-09-05/README.md)를 참고한다.

## 맵툴에서 이어서 작업하기

2026-09-05 기존 코너 15곳의 회전 스팟을 전체 도로 폭에 맞게 정렬했다. 루트 위치·목표 방향·0.5초 회전은 유지하고, 감지 박스의 월드 크기를 `8 × 2 × 0.8`, 진입 방향 중심 오프셋을 `1.10`으로 맞췄다. 플레이어 반지름을 보정해 너무 일찍 회전하거나 가장자리에서 놓치는 문제를 줄인다. 직진 교차점에는 중복 스팟을 추가하지 않았다. [진행 순서와 배치 기록](../map-concepts/sr18-turn-spots-2026-09-05/README.md)을 참고한다.

1. SR18 씬을 연다.
2. `Tools/맵 제작 도구/노량진 맵 제작/맵툴 열기`를 실행한다.
3. `편의 > 작업 그리드 범위`에서 `600` 프리셋을 선택한다. 이 값은 EditorWindow 표시 범위이며 씬에 저장되는 설정이 아니다.
4. 오브젝트·적·기믹·보너스를 원하는 위치에 배치한다.

맵툴은 SR18 경로를 정식 제작 씬으로 인식하므로 씬 버튼이 맵1로 돌아가지 않고 SR18을 유지하며, 회전 스팟 표시와 배치 도구도 동일하게 동작한다.
