# 노량진 SR18 등대 인피니티 길 전용 씬

## 상태

`Assets/ShooterSurvival/Scenes/Tools/Noryangjin_MapTool_Mode_SR18.unity`는 현재 노량진 맵1을 원본으로 만든 정적 길 제작 씬이다. 기존 맵1과 `Noryangjin_MapTool_Mode_2.unity`는 변경하지 않았으며, SR18 씬도 Build Settings에는 포함하지 않았다.

이 씬은 사용자가 오브젝트를 직접 배치하기 전의 길 전용 기반이다. 플레이어·카메라·Managers·Canvas·EventSystem·UpgradeServices와 맵툴 작업 루트는 유지하지만 장식 Props, Enemies, Bonuses와 Water 배치는 비웠다. `Props`에 남은 항목은 주행 방향을 바꾸는 회전 스팟 15개뿐이다.

## 경로 규격

- 보존 구간: 맵1 도로 51개와 회전 스팟 5개
- SR18 신규 구간: 도로 179개와 회전 스팟 10개
- 전체: 도로 230개와 회전 스팟 15개
- 신규 경로: `남27 → 서17 → 북24 → 동26 → 북12 → 동9 → 북13 → 동10 → 남6 → 서17 → 북18`
- 최종 진행 방향: 북쪽
- 신규 길 종류: 기본길 157, 오르막길 6, 내리막길 6, 우회전길 8, 좌회전길 2
- 신규 도로 루트 경계: 대략 `X -67.00~439.25`, `Z -347.75~338.50`
- 배치 기준: 맵1 종점의 실제 판자 출구 `(124.2499, 0, -44.0011)`, 피치 11.25

전체 179개 Transform과 교차 계약은 `map-concepts/noryangjin-expansion-2026-09-02/sr18-unity-placement.json`의 schemaVersion 2를 따른다. `source.endpointWorld`는 원본 프리팹 피벗이며 실제 경로 원점은 `target.routeOriginWorld`다.

## 2026-09-05 도로 표면 수정

초기 제작본은 직선 부두 프리팹의 한쪽 끝 피벗을 도로 중앙으로 취급해 코너가 어긋났다. 판자보다 길게 뻗은 기둥을 포함한 Renderer 경계 검사는 바닥의 틈을 검출하지 못했다. 이를 실제 판자 길이 4.95와 중앙 X=-1.5 기준으로 보정했다.

`Assets/ShooterSurvival/Models/Generated/SR18RoadDecks/`의 여섯 공유 메시가 중앙 정렬 직선, 코너, 코너 진입부, 고가, 오르막, 내리막 표면을 담당한다. 원래 맵툴 프리팹 연결과 재질은 유지하며, MeshFilter와 MeshCollider가 같은 보정 메시를 참조한다. 코너의 출구 길은 3.3만큼 뒤로 확장하고 진입 길은 같은 양만큼 줄여 빈 모서리와 판자 중복을 없앴다. 일반 이음새에는 0.24의 여유를 둔다. `이어 복붙`은 해당 프리팹 인스턴스의 메시 오버라이드도 함께 보존한다.

## 입체 교차

세 교차는 하나의 갈림길이 아니라 먼저 지나간 하부 길을 나중의 상부 길이 넘어가는 구조다.

| 교차 | 하부 | 상부 | 기준 좌표 |
| --- | --- | --- | --- |
| 첫 8자 중심 | 신규 3번 | 신규 85번 | `(0, -3)` |
| 기존 맵 재통과 | 맵1 첫 도로 부근 | 신규 73번 | `(-12, -3)` |
| 등대 고리 중심 | 신규 122번 | 신규 154번 | `(18, 16)` |

- 상부 기본길의 루트 Y는 12다. 고가의 기둥 하단을 짧게 조정해 하부 도로와 겹치지 않는다.
- 첫 경사: 70~72번 오르막, 73~86번 고가, 87~89번 내리막.
- 두 번째 경사: 151~153번 오르막, 154~155번 고가, 156~158번 내리막.
- 경사 한 조각마다 높이 4를 변화시켜 3개 길, 33.75의 수평 거리로 높이 12를 연결한다. 내리막은 높이가 실제로 감소한다.
- 초기 도면의 한 조각 내리막을 세 조각으로 늘려 실제 고가 영향 구간은 `[70,90)`, `[151,159)`다. 도로 총수, 회전 순서, 세 교차는 유지한다.

현재 `PlayerScript`는 Rigidbody Y 위치를 고정하므로 이 입체 경로는 아직 런타임 완주용이 아니다. 실제 플레이를 연결하려면 높이 추종, 카메라, 하부 통과 여유와 투사체 충돌을 별도 구현해야 한다.

## 맵툴에서 이어서 작업하기

1. SR18 씬을 연다.
2. `Tools/맵 제작 도구/노량진 맵 제작/맵툴 열기`를 실행한다.
3. `편의 > 작업 그리드 범위`에서 `600` 프리셋을 선택한다. 이 값은 EditorWindow 표시 범위이며 씬에 저장되는 설정이 아니다.
4. 오브젝트·적·기믹·보너스를 원하는 위치에 배치한다.

맵툴은 SR18 경로를 정식 제작 씬으로 인식하므로 씬 버튼이 맵1로 돌아가지 않고 SR18을 유지하며, 회전 스팟 표시와 배치 도구도 동일하게 동작한다.
