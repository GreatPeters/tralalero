# 노량진 스테이지 1 맵툴 확장 기획

## 범위

이 문서는 현재 `Noryangjin_MapTool_Mode.unity`를 출발점으로 노량진 스테이지 1만 확장하는 기획안이다. 다른 스테이지, 맵 2, 공용 캠페인 시스템은 범위에 넣지 않는다.

현재 씬의 핵심 정체성은 유지한다.

- 물 위의 좁은 목재 부두와 젖은 시장 바닥
- 왼쪽의 언덕 마을과 중앙 수산시장
- 플레이어가 한 방향으로 전진하고 회전 스팟에서 진행축을 바꾸는 단일 경로
- `오브젝트 / 적군 / 기믹 / 보너스`로 분리된 맵툴 팔레트
- 5종 Forward 적, 8종 장애물, 단일 `운명의 제단` 프리팹

확장의 목표는 맵을 넓히되 길찾기 게임으로 바꾸지 않는 것이다. 이동 경로는 하나로 유지하고, 전투 공간의 폭·높이·측면 등장·보상 포켓을 늘린다.

## 전체 동선

현재 중앙 부두와 시장 구간을 첫 번째 기준점으로 삼고, 플레이 시간을 다섯 구역으로 나눈다. 전체 체감 길이는 현재 배치의 약 2.5배를 목표로 한다. 셀 크기와 기존 미세 그리드는 유지하고, 더 넓은 배치가 필요하면 맵툴 `편의 > 작업 그리드 범위`에서 탑뷰 표시 반경만 늘린다.

| 진행 | 구역 | 공간 역할 | 핵심 플레이 |
| --- | --- | --- | --- |
| 0–20% | 언덕 마을·시장 입구 | 규칙 소개 | 좁은 길, 낮은 적 밀도, 첫 측면 진입 |
| 20–40% | 젖은 경매 골목 | 압박 상승 | 수조와 상자 사이 교차 사격, 기름 바닥 |
| 40–60% | 냉동 화물장 | 첫 넓은 전투장 | 얼음·컨베이어, 엘리트 첫 등장, 보너스 포켓 |
| 60–80% | 작업항·선박 부두 | 동적 위협 | 보트 측면 등장, 크레인 스윙, 파도 범람 |
| 80–100% | 방파제 | 결산·보스 | 넓은 원형 전투장, 혼합 편성, 여성 보스 |

경로는 갈라지지 않는다. 보너스 포켓은 본선 옆 1–2칸 깊이의 짧은 확장 공간으로 만들고 다시 본선으로 합친다. 배경용 물과 언덕은 이동 가능 영역처럼 보이지 않게 난간, 타이어 완충재, 계선주, 조명으로 경계를 읽힌다.

## 적 확장

새 모델을 먼저 늘리기보다 현재 5종의 역할과 배치를 강화한다.

- `Enemy_YllowMan` — 기본 전열. 2–4명 지그재그 배치와 짧은 좌우 이동으로 조준 규칙을 익히게 한다.
- `Enemy_Guard` — 좁은 길의 차단자. 경매 골목과 방파제 입구에서 중앙을 막고 다른 일반 적이 측면을 사용하게 한다.
- `Enemy_OldMan` — 변칙 일반 적. `트리거 후 옆 등장`을 우선 사용해 시장 가판·컨테이너 뒤에서 늦게 합류한다.
- `Enemy_FatMan` — 엘리트 압박자. 냉동 화물장과 작업항의 넓은 공간에 단독 배치하고 일반 적 2–3명과 조합한다.
- `Enemy_Woman` — 스테이지 1 보스. 방파제의 최종 전투에서만 사용하고, 이전 구역에는 실루엣·간판·조명으로 존재를 예고한다.

권장 배치 예산은 일반 22–28명, 엘리트 3–4명, 보스 1명이다. 전투 발동 스팟은 8–10개로 나누고 한 번에 활성화되는 적은 모바일 화면 기준 6명을 넘기지 않는다. 기존 `가만히 / 좌우 이동 / 트리거 후 전진 / 트리거 후 옆 등장` 조합만으로 1차 패스를 만들고, 투사체·방패·상자 던지기 같은 신규 전투 기능은 별도 구현 단위로 둔다.

## 기믹 확장

현재 `ObstaclePrefabs.asset` 기반 팔레트를 유지한다. 새 기믹은 해당 목록에 하나의 완성 프리팹으로 등록하고, 구성 파트는 팔레트에 중복 노출하지 않는다.

1. 기름 웅덩이 — 짧은 감속 구역. 안전콘으로 범위를 미리 읽힌다.
2. 갈라진 얼음 — 진입 후 짧은 지연 뒤 위험 상태가 되는 바닥 모듈.
3. 무너지는 부두 — 경고 흔들림 후 일정 시간 통행 위험이 생기는 1회성 모듈.
4. 크레인 훅 — 일정 주기로 한쪽 차선을 쓸고 지나가는 회전 기믹.
5. 생선 상자 컨베이어 — 엄폐와 충돌 공간이 옆으로 이동하는 구역 기믹.
6. 방파제 파도 — 바닥의 젖은 경고 띠 뒤에 한 차선을 덮는 주기성 기믹.

한 전투에는 핵심 기믹 하나만 사용한다. 기름과 얼음처럼 이동을 방해하는 기믹을 같은 셀에 겹치지 않는다. 크레인·파도처럼 시간축이 있는 기믹은 플레이어 진행선에 명확한 안전 구간을 남긴다.

## 보너스 확장

보너스 제단 종류는 늘리지 않는다. 기존 `Box_left` 한 개와 노멀·엘리트·유니크 등급을 재사용한다.

- 첫 제단: 경매 골목 종료 지점, 노멀
- 두 번째 제단: 냉동 화물장 측면 포켓, 엘리트
- 세 번째 제단: 작업항 종료 지점, 엘리트
- 선택 제단: 보스 직전 위험 구간을 통과했을 때만 접근 가능한 유니크

제단은 본선 중앙을 막지 않고 최소 한 캐릭터 폭 이상 옆으로 뺀다. 가까운 제단의 중복 능력 배제 규칙을 유지한다. 물고기 픽업과 항구 비콘은 이미지상의 추가 제안이며, 실제 보상 효과와 저장 규칙이 정해지기 전에는 장식 오브젝트로만 취급한다.

## 오브젝트 확장

오브젝트는 장식 수를 늘리는 것보다 구역별 조합 규칙을 만든다.

- 시장: 수조, 파란·주황 상자, 스티로폼 박스, 빨간등, 생선·게 간판
- 경매 골목: 젖은 바닥, 수레, 양동이, 주의콘, 생선 잔해
- 냉동 화물장: 흰 얼음 상자, 컨테이너, 지게차형 실루엣, 얼음 조각
- 작업항: 그물더미, 닻, 계선주, 타이어 완충재, 어선, 크레인
- 방파제: 낮은 난간, 구조등, 콘크리트 턱, 구명부표, 파도 흔적

장식은 플레이어 경로의 바깥쪽에 밀도를 높이고 중앙 진행선은 단순하게 유지한다. 반복 소품은 회전·스케일·높이 차이를 주되, 충돌이 필요한 루트와 순수 장식 루트를 구분한다. 모바일 정적 배칭 대상은 동작 컴포넌트가 없는 환경 오브젝트로 제한한다.

## 맵툴 UX

이번 변경으로 `편의` 화면에 `UI 활성화 / UI 비활성화` 세그먼트가 추가된다. 대상은 씬 루트의 화면용 `Canvas`뿐이다. 적 체력, 보너스 수치, 플레이어처럼 배치 오브젝트 아래에 있는 월드 UI는 유지된다. 따라서 큰 화면 UI가 SceneView를 가릴 때 숨기고, 플레이 확인 전에 다시 켤 수 있다. 변경은 Undo/Redo와 씬 dirty 상태를 따른다.

같은 화면의 `작업 그리드 범위`는 탑뷰 오버레이 반경을 `50..1200`칸에서 조절한다. `300/600/900/1200` 프리셋을 제공하며, 변경 즉시 SceneView만 다시 그린다. 셀 크기, 배치 좌표, 물리 작업 가이드, 작성 씬 오브젝트는 바꾸지 않으므로 큰 맵을 기획할 때 안전하게 시야만 확장할 수 있다.

다음 UX 확장은 이 순서가 적절하다.

1. `오브젝트 / 적군 / 기믹 / 보너스`별 눈 아이콘으로 SceneView 표시만 제어
2. 팔레트 검색과 자주 쓰는 프리팹 고정
3. 현재 선택 탭의 배치 수·누락 프리팹·경로 침범 경고 요약
4. 적 발동 스팟별 연결 수와 동시 활성 적 예산 표시
5. 기믹의 발동 주기와 안전 차선을 SceneView 색상으로 미리보기

이 기능들은 실제 GameObject 활성 상태와 SceneVisibility를 혼용하지 않도록 각각의 계약을 분리해야 한다. 화면 UI 토글은 GameObject 활성 상태, 콘텐츠 눈 아이콘은 편집기 전용 SceneVisibility를 사용하는 편이 안전하다.

## 완료 기준

- 시작부터 보스까지 끊김 없는 단일 경로와 정확한 회전 스팟이 있다.
- 다섯 구역이 조명, 바닥 재질, 소품 조합으로 구분된다.
- 모든 전투 공간에 플레이어 진행선과 최소 한 개의 회피 차선이 남는다.
- 적 26–34명, 발동 스팟 8–10개, 핵심 기믹 10–14개, 제단 3–4개 범위에서 1차 밸런스를 잡는다.
- 넓은 공간의 적은 자동 경로 정렬 후 수동 회전 보정이 가능하다.
- 씬 루트 UI를 끄고 켜도 월드 UI와 배치 오브젝트는 변하지 않는다.
- EditMode 검증 전후 맵툴 씬 파일 해시가 동일하다.
- Android 목표 기기에서 동시 활성 적, 파티클, 화면 UI가 프레임 예산을 넘지 않는다.
