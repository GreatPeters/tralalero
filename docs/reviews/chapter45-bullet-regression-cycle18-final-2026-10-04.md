## 실행과 수정

12:01 UTC까지는 최근 입력 신호에 따른 보호 가드로 Play0이었다. 이후 사용자가 상황을 설명받고 **“실행해”**라고 명시적으로 승인했다. 입력 경과 시간만으로 차단하는 조건을 해제하고, 미저장 씬·편집·컴파일·타 검사 callback의 보호 조건은 유지했다. 무관한 앱/프로세스·창·커서를 조작하지 않았다. 이전 [준비·차단 기록](chapter45-bullet-regression-cycle18-2026-10-04.md)은 승인 전 이력으로 보존한다.

검사에서 두 문제를 재현했다. Ch5 일반 적의 내부에서 탄이 시작하면 첫0.64m 이동에 capsule을 벗어나 피해가 누락됐다. Ch5 최초 실행과 Retry에서 Water/Bomb 중앙·뒤쪽 내부·다중 탄 조건이 실패했다. 또한 탄을 먼저 발사한 뒤 같은 프레임에 Pause하면 게임 clock은 멈춰도 물리 trigger가 들어와 Ch4 패널은40→32, Ch5 적은8→0으로 변했다. Ch5는 당시 `targets`가 비어 있어 cycle17 패널 보정의 적용 밖이었다. 이를 cycle17이 새로 만든 회귀라고 주장하지 않는다.

`BulletScript.cs`는 챕터 탄의 최초/재개 비행 직전에 현재 겹친 살아 있는 적을 확인하고 기존 적 피해 함수를 호출한다. 정지 중 `CanHitTarget`은 충돌 피해와 반환을 막으며, 재개 때 겹침을 다시 처리한다. 기존 층·씬·전환·활성·생존 판정을 유지한다. 새 적 검색은 최초/재개 시점에만 실행하고 재사용 collider buffer를 사용한다. `EnemyScript_space.cs`는 기존 피해 함수의 접근 범위만 internal로 열고 설명을 추가했다. 피해 계산·반응·보상 로직을 복제하거나 능력치를 바꾸지 않았다. 기존 패널 처리도 유지한다.

최초 Ch4 검사에서 Retry 직후 시작을 너무 일찍 눌러 기존0.3초 입력 제한에 막힌 것은 검사 코드의 시점 오류였다. 제한이 자연 해제될 때까지 기다리도록 검사만 고쳤다. 게임의 빠른 재입력 보호 코드는 바꾸지 않았다. 최초 실패 자료는 성공 집계에서 제외하고 보존했다. 과거 Temp 참조 권한 문제로 오프라인 재컴파일을 못 한 뒤 공식 Unity 컴파일 경로를 사용했으며 실제 게임 컴파일 오류0을 확인했다.

## 남은 한계와 후속 요청

이번 승인 범위의 미실행 검사나 재현 후 미수정 결함은 남지 않았다. 사람의 재미·손 입력 체감과 임의의 빠른 마우스 재입력을 모두 확인한 것은 아니다. Windows 최근 입력 신호의 원인도 확정하지 않았으며 사용자 승인으로 실행 차단만 해제했다. 기존52개 실패 수리와 금지된 폰 검증을 완료 조건에 추가하지 않았다.

사용자는 Ch1은 약80% 만족하지만 Ch2~5, 특히4~5의 툰 스타일과 모델 인상에 불만족한다고 새로 평가했다. 이는 미술 변경의 승인이 아니며, 이후 모든 챕터의 툰 스타일 변경 **방법을 설명하는 후속 요청**으로 구분한다. 이번 전투 검증 완료를 미술 최종 승인으로 표현하지 않는다.
