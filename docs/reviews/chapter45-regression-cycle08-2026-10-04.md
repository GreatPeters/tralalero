- **여전히 확정하지 못한 판단:** 원거리에서도 촬영/나이/관객 역할이 일관되게 읽히는지, 실제 사람이 경고와 난이도를 어떻게 체감하는지. 일반 자동 완주로 확정할 수 없다.

## 검증 도구와 증거 구분

공식 Unity CLI가 연결을 발견하며 포트를 고정하지 않았다. 실제 경로 진입점은 `tools/chapters45-regression-cycle08.cs`, UI 제어 fixture는 `tools/regression-ui-fixture-cycle08.cs`, 정확한 게임 키 복원은 `tools/regression-prefs-cycle08.cs`, 엔진 registry 읽기는 `tools/regression-native-cycle08.cs`다. 기존 테스트 도구의 전체 카탈로그 복원 코드는 새 경로 runner에서 제외했다.

읽기 분석 스크립트가 장면 전환 중 없는 HUD의 null 문자열을 더하려다 한 번 실패한 것은 QA 파서 문제였다. null을 빈 문자열로 다루도록 고쳤으며 진행 중인 게임/경로 runner에는 영향이 없었다. 준비용 셸 인용 오류도 게임 코드/저장값을 바꾸기 전 실패한 도구 문제로 구분한다.

최종 `summary.json`/`actual-route-results.json`/`post-fix-hud-analysis.json`/`post-fix-focused-summary.json`/`integrity.json`/`source-diff.patch`에 수치와 변경을 분리했다. 갤러리 원본 PNG 32장과 HTML은 기존 로컬 서버에서 HTTP로 다시 읽어 SHA-256을 대조했다. 이미지를 편집/재생성하지 않았고 private registry 원본은 갤러리에 복사하지 않았다.
