## 남은 차단과 다음 작업

TRELLIS는 로컬 상태 HTTP 요청의 연결 거부(10061)와 기존 Python 실행의 접근 거부(5)가 각각 기록됐다. Meshy는 로컬 클라이언트/기존 키가 있으나 잔액 요청이 소켓 접근 차단(10013)으로 HTTP 응답 전에 실패했다. 정확한 시각, 대상, 기존 실행 순서, 필수 조치는 [진단 문서](department-generation-diagnosis-2026-10-02.md)에 있다. 계정 잔액·키 유효성은 미확인이다.

사용자가 정상 데스크톱 계정에서 기존 TRELLIS 서비스를 시작하면 동일 포트 읽기부터 다시 확인할 수 있다. 설치 실행 권한을 자동으로 변경하거나 거부된 경로를 다른 방식으로 우회하지 않는다. Meshy도 네트워크 문제 해결과 읽기 잔액 확인 후 별도 비용 한도가 승인되어야 유료 생성을 진행한다. 새 설치·인증·결제는 하지 않았다.

기능과 일부 시각 보완은 적용·검증됐지만 신규 AI 모델·남은 참조 미술 품질·실기기 성능은 미완료다. Git push, 전체 변경 일괄 commit, 외부 백업, 기존 파일 삭제는 하지 않았다.
