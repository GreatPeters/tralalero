# Galaxy S22 성능·시각 품질 개선 적용 기록

2026-10-01 · Tralalero Shooter D · 적용·빌드·저장값 복원 확인


## 판단 기준

사용자가 제공한 [Claude 검토](https://claude.ai/artifact/Dft5AkhivSWuUANkX4JeEN)와 [선행 실측 보고서](s22-performance-visual-audit-2026-10-01.md)를 대조했다. 지적을 그대로 적용하지 않고, 실제 코드·자산·Play 화면으로 재현되는 문제부터 수정했다. 새로운 유료 Meshy 생성은 사용하지 않았다.

주요 병목은 평상시 게임에서 매 프레임 반복하는 가림 검사와 맵 자원의 부담이었다. 영상 종료 후에는 기존에도 디코더와 RenderTexture가 해제됐다. 이번에는 영상 재생 중 3D 월드의 렌더링도 생략하도록 바꿨다. 영상 하나가 모든 렉의 원인이었다고 결론 내리지는 않는다.

## 어색한 표현과 모델

- **주인공:** 원래의 얼굴·텍스처·리그를 보존하면서 뒤쪽 두 다리를 제거하고 꼬리 끝을 세 번째 신발로 연결했다. 기존 사용자의 ‘두 발+꼬리 신발’ 요구를 기준으로 삼았다. 기본 포함 여덟 신발 스타일의 실제 스키닝을 검수했고, 원본 메시와 되돌릴 수 있는 카탈로그 기록을 보존했다.
- **간판:** 높인 판넬은 Y 10.7~13.5인데 TMP는 Y 5.9/5.3에 남아 있었다. 빌더의 미생성 TMP bounds 의존을 없애고 변환 위치로 높이를 적용했다. 설치된 76개 라벨 정렬, 중복 간판 루트 38개 정리.
- **시장 연출:** 떠 있는 별도 입찰 모자 제거, 군중의 작은 크기·색 변화, 입찰/호가 애니메이션이 1.65초마다 끊기지 않도록 지속시간 조정. 기존 애니메이션을 실제 72개 재생 프레임으로 확인했다.
- **음성:** 방송·경매·상인을 구분한 한국어 합성 음성으로 실제 9개 참조 교체. 14개 파일 중 미사용 파일도 구분한다. ‘낙찰!’은 약 1.57초로 줄여 다음 경매 박자와 겹치지 않게 했다. 사람 성우 녹음이라고 표현하지 않는다.
- **피드백:** 가까운 코인 팝업 합산, 보상은 왼쪽·적 피해는 오른쪽으로 분리. 플레이어 자신의 피해 표시 전용 슬롯은 유지한다. 파도의 거품/마루 규모는 줄이고 위험 타이밍과 판정은 유지한다.
- **시간과 문구:** 경매 직후 갑자기 14시간이 흐르던 표시를 새벽 04:00~04:30 흐름으로 정리. 방송/교통 안내는 짧고 상황에 맞는 문장으로 수정했다.
- **소품:** N19 작업코드 라벨을 제거하고 활어·통의 본래 텍스처를 보존. 휴게소의 높은 표지판을 건물 가림 처리에 포함하고 바닥 대비를 조정했다.

- **영상:** 기존에 선택한 프롤로그 앞 30초는 보존하고 마지막 9초를 실제 시장 도착으로 교체했다. 고속도로·휴게소 진입도 같은 게임 모델의 실제 보행·차량 이동·피신 동작으로 구성했다. 216/121/121개 프레임이며 정지 그림을 이어 붙인 슬라이드쇼가 아니다. 오프닝 936프레임/39초와 0·8·20·30초 이동 버튼 규칙을 유지했다.

## 그대로 믿지 않은 지적

1. ‘입찰자가 손을 들지 않음’, ‘보스가 웅크린 채 달림’은 선행 감사에서 이미 폐기한 즉시 스키닝 캡처를 근거로 한 주장이다. 실제 Play 애니메이션에서는 손을 들고, 보스도 서서 달린다. 잘못된 증거로 정상 리그를 교체하지 않았다.
2. SM-S901N을 Exynos 기종으로 설명한 부분도 맞지 않는다. 삼성 서비스의 기종 안내는 Snapdragon 8 Gen 1을 명시한다. 이 오인에 근거해 Vulkan/GLES를 강제 전환하지 않았다. [삼성 서비스 기종 안내](https://www.samsungsvc.co.kr/solution/639578)
3. 삼각형을 가장 적게 만드는 후보가 최선은 아니다. 네이티브 LOD 검수에서 깨지는 후보를 제외했다. 같은 이유로 새 영상 시안도 실제 구도·모델·연속성이 확인되기 전에는 원본에 덮어쓰지 않는다.

최종 PC 시작 화면 240프레임(90프레임 준비)의 중앙값은 **14.39 ms**, p95 **15.70 ms**다. 별도 함수 측정은 10.03→0.790ms였고 빌드 후 최종 재확인은 **0.775 ms**다. 전체 프레임과 함수 비용은 측정 범위가 다르며 S22 FPS로 바꾸어 말하지 않는다.

고속도로의 마지막 28개 표본은 88~751배치, 73~657 SetPass였다. 혼잡 구간의 그리기 호출 부담은 아직 남아 있어 실기기에서 우선 확인할 부분이다.

캐릭터·의상·도착 영상의 정체성과 바닥·간판은 개선했지만, 겹친 반투명 천장/기둥에서 대비가 낮아지는 구간은 남는다. 보존한 프롤로그와 실제 게임의 화풍도 완전히 같지는 않다. 경매 음성은 여전히 합성 음성이며 사람의 연기 품질을 보증하지 않는다. 모든 생성 흔적을 없앴다고 주장하지 않는다.

ADB 최종 장치 목록도 비어 있었다. 실기기의 발열 누적·GPU 프레임 시간·배터리·입력 지연은 측정하지 못했다. 기존 광범위 Noryangjin 테스트 기록에는 26개 실패가 있었고 이번에는 그 전체 묶음을 다시 통과시켰다고 주장하지 않는다.

## 설치 파일과 복원

ARM64 일반 APK 빌드가 **성공**했다. 오류 0개, 경고 58개. 실제 포함 씬은 Revamp·HighWay·RestStop 세 개다.

경고 원문도 보존했다. Toon 34건, FlatKit 표면 19건, 물 2건의 셰이더 경고와 Player Pipeline 비활성 안내, 광고 SDK의 iOS 플러그인 대상 안내, Android 현지화 메타데이터 안내가 각 1건이다. 경고가 없었다고 표시하지 않는다. 새 제조 소품 셰이더의 컴파일 오류는 없었다.

- 파일: `Builds/Android/TralaleroShooter-20261001-S22-release.apk`
- 용량: **752.1 MB**. 9월 30일 APK 1,526.2 MB 대비 **50.7% 감소**.
- SHA-256: `9a56047c27ed5feb83401bdd38ea9619f229d894fd14a17b0df509061b49c68c`
- 현재 기기에 설치하거나 플레이했다고 주장하지 않는다. 연결된 S22가 없으므로 전달물은 설치 가능한 APK다.
- 코인 **40,218**, 보석 **30**과 전체 저장 레지스트리를 작업 시작 시점으로 복원했다. 바이트 일치, Play 중지, 원래 개편 씬의 clean 상태, 원래 테스트 옵션 복귀를 확인했다.

원본 모델/영상을 보존했다. 새 자산은 Generated/S22Polish 및 JH/UI/S22Polish에 분리했고, 원본 카탈로그·메타 설정은 작업 전 백업을 남겼다. 유료 Meshy 생성 비용은 0이다.
