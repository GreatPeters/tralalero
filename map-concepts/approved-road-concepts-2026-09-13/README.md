# 승인된 고속도로·휴게홀 컨셉 적용

2026-09-13 사용자의 적용 요청에 따라 원본 Unity 프로젝트에 구현했다. 전체 씬을 다시 만들지 않고 공식 Unity CLI/Pipeline으로 필요한 도로·배경·식당 계층과 프리팹을 수정했다.

## 적용 내용

- **고속도로:** 방향별2차선, 총4차선. 노란 이중 중앙선과 방향별 흰 점선을 구분했다. 기존 곡선·두 회복 우회로·전투 배치·정면 차량11대 패턴을 유지했다. 별도의 반대편 차로에는 충돌체 없는 장식 차량6대를 움직인다. 곡선 바깥쪽 방음벽/가드레일 간격, 밝은 도색, 배경 재질과 우회로 주변 배치를 다듬었다. 마지막 화면에서 확인한 떠 있는 외곽 식재를 도시 지면Y-6.5에 맞추고 가로등 아래 갓길 표면을 추가했다.
- **사람 캐릭터9종:** 기존 사람 모델을 재사용해 목 위 영역을 기준으로3등신 비율을 목표로 몸통·다리와 리그를 함께 조정했다.18개 본과6개 애니메이션, 재질·프리팹 경로·원거리 장비 연결을 보존했다. 일반 모델 높이는2.1m, 큰 역할은 기존 역할 배율을 유지한다. 기존 상어/코스메틱 리그는 그대로 사용한다.
- **새 매점 모델2종:** 간식 진열대와 커피 매점을 로컬 TRELLIS2로 제작했다. 각각24,427/24,532삼각형이며, FBX·GLB 재임포트와 여러 방향의 화면을 확인했다. 실내 외곽16곳, 야외 서비스 구역10곳에 재사용했다.
- **넓은 휴게홀:** 중앙36×36범위에 낮은 장식 장애물을 두지 않은48×66규모다. 매점은 외곽으로 보내고 타일 바닥·상부 창·천장·조명·출입구·셔터를 구성했다. 카메라의 부모 배율까지 반영해 지붕을16.5m로 배치하고 간판/셔터 가림을 처리했다.
- **30초 방어:** 기존 시점과 플레이어 위치를 유지하면서 몸체와 새로 발사되는 탄의 방향이 경찰을 따라360도로 바뀐다. 현재의 가까운 적 자동 조준을 유지했다. 높은 전투 카메라로 전환하는 코드는 제거했다.

이 결과는 컨셉의 공간 구성·비율·동작을 실제 에셋으로 적용한 것이다. 생성 그림의 모든 질감·형태를 그대로 재현했다는 의미는 아니다.

## 보존과 완료 상태

이번 작업 직전 파일132개와 저장 항목63개를 새로 백업했다. 통합 테스트 원본도 수정 전에 추가 보존했다. **코인3,007·보석0을 포함한63항목의 존재 여부와 값을 복구·대조했고 불일치는0개다.** [복구 결과](user-state-restored.json).

워크북 `Data.xlsx`, 서명된 `Data.bytes`, SR18 씬은 작업 전 SHA-256과 동일하다. 워크북을 변경하지 않았으므로 아카이브를 다시 생성하지 않았다. 두 수정 씬은 기존 맵 루트/적·보너스 ID를 유지하며 누락 스크립트0개다. 원본 에디터는 저장된 HighWay 하나를 연 Edit Mode로 남겼다. 작업에서 시작한 Trellis 서버 프로세스는 빈 큐를 확인하고 종료했으며 Blender 작업도 모두 끝났다.

## 반복 실행과 남은 검증 범위

`tools/apply-approved-road-concepts.cs`는 초기 단계의 중복 실행을 거부한다. 지난 단계나 과거 백업 복원을 무작정 재실행하지 않는다. 후속 검증 전에는 그 시점의 새 저장값 백업을 만든다. [기획](../../docs/plans/2026-09-13-feat-approved-road-concepts-plan.md), [실행 기록](../../docs/exec-plans/completed/approved-road-concepts-2026-09-13.md).

이번 변경 뒤 전체20판 성장 코호트나 Android 기기 검증은 하지 않았다. 넓어진 홀은 동일한 전투 수치에서도 접근 시간과 난이도를 바꿀 수 있으므로 후속 밸런스/기기 검증에서 확인해야 한다. 이전 APK를 이번 결과의 기기 증거로 사용하지 않는다.
