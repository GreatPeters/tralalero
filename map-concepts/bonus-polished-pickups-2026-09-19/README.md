# 입체 보너스 제작 시안 3종

2026-09-19. 사용자 후속: Arrow a Row의 외형이 허접하다고 지적한 뒤 “참고해서 네가 만들 수 있는 걸로 이미지그려줘봐”라고 요청했다.

## 반영한 기준

러닝 슈터 레퍼런스에서 좌우 선택의 가독성, 능력 아이콘과 수치의 묶음, 획득 결과의 표현만 참고했다. 기존 단순 배너의 외형을 복제하지 않고, 현재 파랑·아이보리 항구 UI와 맞는 베벨·재질·입체 아이콘으로 새 시안을 만들었다.

세 안의 이름·형태·색상·부품 연결은 에이전트 제안이며 사용자 선택/게임 적용 승인이 아니다. 내장 ImageGen으로 만든 기획 이미지다.

## 시안과 제작 경로

| 안 | 이미지 | 구현 출발점 |
|---|---|---|
| 01 에나멜 능력 휘장 | [PNG](images/01-enamel-emblems.png) | 단순 휘장 메시 + 기존 능력 아이콘 + 바닥 하이라이트 + 짧은 획득 트레일 |
| 02 신발 개조 모듈 | [PNG](images/02-footwear-modules.png) | 작은 케이스·덧창·앞코 메시 + 기존 아이콘/TMP + 축소·흡수 연출 |
| 03 입체 아이콘 성장 카드 | [PNG](images/03-relief-upgrade-cards.png) | 기존 나인슬라이스·아이콘 + 얇은 카드 메시 + 회전·페이드·빛 연출 |

- 01: 휘장 외곽/안쪽/아이콘을 간단한 메시 또는 아이콘 평면으로 제작한다. 에나멜/금속 대비는 기존 스타일 셰이더 계열의 재질 조정과 단순 하이라이트로 접근한다.
- 02: 케이스 몸통·뚜껑·덧창/앞코를 별도 정적 메시로 만든다. 기존 보급함은 출발점 후보지만 그림과 동일한 모델이 있다는 주장은 아니다. 영구 장비 교체가 아니라 임시 능력 획득 예시다.
- 03: 얇은 카드 메시와 기존 나인슬라이스/아이콘/TMP를 조합한다. 회전·축소·페이드와 짧은 빛 효과를 별도 구현한다.
- 실제 메시를 만들 경우 프로젝트의 Blender CLI 작업 흐름을 사용한다. 이번 시안 생성에 Blender나 TRELLIS를 실행한 것은 아니다.
- 현재 체력/공격력 아이콘 외 능력도 같은 틀에 넣을 수 있도록 구현 시 매핑한다. 이 세 장에서 모든 능력의 모습을 확정한 것은 아니다.

## 유지할 게임 규칙과 검증 범위

기존 보너스 수치, 충돌 영역, 1택·중복 방지·런 초기화 로직은 이번 작업에서 변경하지 않았다. +13 / +14%는 그림 비교용이며 밸런스 변경 요청이 아니다.

게임 안 모습 / 형태 확대 / 획득 장면을 한 장에 담았다. 02의 첫 획득 컷은 화살표 방향이 모호해 흡수 직후 상태로 수정했다. 01·03의 소수 glint, 발생 위치 및 잔상은 렌더 참고이며 정확한 런타임 입자 수를 증명하지 않는다. 일부 캐릭터 세부 형태는 생성 과정에서 변형될 수 있으며 실제 캐릭터 모델 변경 제안이 아니다.

3개 PNG를 육안 확인하고 System.Drawing으로 다시 열어 1536×1024임을 확인했다. Chrome의 외부 갤러리에서 01을 클릭·확대해 정상 표시를 스크린샷으로 확인했다. 원래 Codex 패널의 이미지 클릭 문제가 해결됐다는 뜻은 아니다.
