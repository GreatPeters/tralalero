## 범위

- 내장 ImageGen으로 제작한 기획 이미지다. 실제 프리팹의 렌더링 또는 Unity 적용 결과가 아니다.
- 기존 공물·촛대·그릇·조개·등불 프리팹 후보와 단순한 받침·원호·석판·원판 메시를 조합하는 방향이다.
- 왼쪽은 조립 형태, 가운데는 게임 안 대기, 오른쪽은 획득. 세밀한 조각·큰 광선·다량 입자를 줄였다.
- 고사상 공물이 저주 신발로 흡수되는 기획서 설정을 유지한다. +13 / +14%는 비교용 표기다.
- TRELLIS는 이번 제작에 사용하지 않았다. 기본 모델 구성에 필수로 요구하지 않는다.

## 확인과 후속 구현

- 최종 PNG 10개 모두 1536×1024이며 파일을 다시 열어 확인했다. 생성 결과의 3패널 구성·제목·제단 형태·효과를 육안 점검했다.
- 03번 첫 생성에서 금지한 별 입자가 다시 나와 획득 패널만 수정했다. 최종본은 빛 궤적 중심이다. 기존 생성 원본은 보존했다.
- 일부 정지 장면은 공물 잔상이나 비활성 왼쪽 선택물을 남긴다. 이것이 최종 게임의 소멸 상태나 1택 동작을 바꾸는 제안은 아니다.
- 실제 효과 개수·제단 높이·UI 간격은 생성 이미지의 수치가 아니라 Unity 구현 시 맞출 목표다. 이미지가 발광량/형태를 완벽하게 준수한다고 단정하지 않는다.
- 실제 적용 전 후보 프리팹 외형, 재질, 피벗과 모바일 시야를 확인해야 한다. 이번 작업에서 씬/프리팹/C#은 수정하지 않았다.
