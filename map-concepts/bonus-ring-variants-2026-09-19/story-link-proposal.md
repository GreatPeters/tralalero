# 슬림 링과 저주 신발 연결 제안

2026-09-19. 사용자: “1번이 제일 좋긴한데..게임이랑 이게 엮을 수 있나? 말이 되나? 엮어봐”. 1번의 선호와 설정 연결 요청이며 아래 세부 설정의 확정이나 Unity 구현 승인은 아니다.

## 기존 근거

`GAME_DESIGN_OVERVIEW.md` §3.3은 저주 신발을 힘과 통제를 동시에 주는 족쇄로 정의하고 공물 흡수를 임시 성장의 근거로 삼는다. §12.5는 인간의 공물을 흡수하는 런 중 강화와 시작 부활 제단을 구분한다. §12.3의 개조상은 영구 성장을 담당한다. 신의 친절한 축복으로 표현하지 않는다. 이 내용은 저장소 기획이며 모두 사용자 직접 발언이라고 주장하지 않는다.

## 제안: 공물의 힘이 드러난 고리

링은 사람들이 길에 배치한 첨단 장비가 아니라 저주 신발이 공물의 힘을 감지할 때 나타나는 봉인 형태다. 사람이 남긴 작은 공물은 장소에 존재하고, 플레이어에게 보이는 선택물은 공물에서 떠오르는 고리다. 링의 물리적 금속감은 신발에 묶인 봉인을 시각화하는 스타일로 유지한다.

- 링: 힘을 붙잡는 봉인. 얇은 은색 테두리와 남색 연결부는 1번 유지.
- 중앙 하트/검: 각각 생명력과 공격의 힘을 플레이어에게 읽히게 하는 상징. 실제 검을 지급하는 의미가 아니다.
- 접근: 작은 공물/받침 흔적 위에서 링과 아이콘이 나타난다. 거대한 고사상이나 길을 막는 문을 추가하지 않는다.
- 획득: 아이콘이 작은 빛으로 신발에 흡수되고 링이 수축한다. 신발의 같은 원형 문양이 잠깐 반응한다. 불꽃·연기·독 효과를 사용하지 않는다.
- 미선택: 남은 고리의 빛이 꺼지고 내려앉아 선택 종료를 보여준다.
- 런 종료: 빌려 쓴 공물의 힘이 소진되므로 임시 강화가 초기화된다. 상인의 영구 개조와 구분된다.

설정의 아이러니는 “저주를 풀려고 달리는데, 달릴수록 저주 신발의 힘에 기대게 된다”다. 신이 호의로 보상을 제공한다는 서사를 추가하지 않는다.

## 플레이어에게 보여줄 최소 연결

출발 제단의 기존 장식에 동일한 원형 문양을 작게 반복하고, 첫 공물 접근 때 신발 문양 → 링 등장 → 흡수 → 신발 반응을 연속으로 보여준다. 상인의 선택적 첫 대사는 “그 신발, 공물 냄새도 맡네. 먹일수록 세지겠어.” 정도로 짧게 둔다. 새 영상은 필수 전제가 아니다.

항구·고속도로·휴게소 모두 고리와 능력 색은 통일하고 길 가장자리의 작은 공물 배치만 장소에 맞춘다. 장소별로 새로운 신·장치·설명 체계를 만들지 않는다.

## 변경 경계

현재 기획 §12.5의 ‘낮은 돼지머리 고사상 + 바닥 표식’ 기본 외형에서 ‘작은 공물 흔적 + 떠오르는 봉인 고리’로 바꾸는 제안이다. 공물을 흡수하는 핵심 설정은 이어지지만 외형 변경까지 이미 승인됐다고 취급하지 않는다. 이번에는 기획 원문이나 게임 파일을 수정하지 않았다.
