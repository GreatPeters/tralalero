# 신성한 공물 제단 — Bonus Wall 시안 10종

2026-09-19. 사용자 요청: “신성한 제단 느낌? 그리고 이 기획서랑 잘 맞는 느낌으로 다시 10개”.

## 기획 근거와 해석

별도 문서 경로 답변이 없어 저장소의 `GAME_DESIGN_OVERVIEW.md` §3.3 및 §12.5를 기준으로 제작했다. 이 문서는 런 중 보너스를 인간이 차린 돼지머리 고사상의 공물을 저주 신발이 흡수해 임시 강화하는 구조로 정의한다. 스테이지 시작 부활 제단과 기능은 구분한다.

사용자가 지정한 것은 신성한 제단 분위기와 기획서에 맞는 새 시안 10개다. 백옥·청자·월륜 등 구체적인 형태, 색, 재질, 효과는 아래 에이전트 제안이며 승인된 구현 요구가 아니다.

각 PNG 왼쪽은 대기, 오른쪽은 획득. 같은 항구 배경에서 낮은 공물 제단과 신발 중심 흡수 효과를 비교한다. 표시된 +13 / +14%는 비교 예시이며 밸런스 변경이 아니다.

## 제작과 확인

- 후속 제작 범위: [확인한 프리팹과 10안별 실제 제작 방식](FEASIBILITY.md). 기존 에셋을 우선 사용하고, TRELLIS는 필요한 정적 장식의 선택적 제작 경로로 검토한다.
- 내장 `image_gen`으로 시안마다 별도 호출, 총 10개 PNG 제작. 원본은 삭제하거나 덮어쓰지 않았다.
- [프롬프트 전체](prompts.json), [생성 원본 경로](generated-files.json).
- 참조: [기존 게임 화면](../bonus-concepts-2026-09-19/reference-game.png).
- 열람용 사본: `tmp/image-previews/bonus-sacred-altars-2026-09-19/`.
- 생성된 10개 결과의 제목, 두 패널, 제단의 다른 실루엣, 공물, 신발 흡수 표현을 육안 확인했다.
- 시안은 실제 Unity 적용 화면이 아니다. 메시·파티클 기반 제작 방향이며 성능 측정이나 런타임 검증은 하지 않았다.
- 08번은 생성 결과에서 UI가 제단 아래쪽으로 배치됐다. 실제 적용 시 공통 UI 위치로 맞춘다.
- 획득 패널은 흡수 도중의 정지 장면이다. 실제 구현은 기존 1택·중복 획득 방지 및 미선택 제단 정리 규칙을 유지해야 한다. 일부 그림에 남은 공물/제단은 최종 소멸 상태가 아니다.
- 크기·불투명 장식은 실제 휴대폰 화면에서 앞길 가림과 통과감을 재확인한다.
