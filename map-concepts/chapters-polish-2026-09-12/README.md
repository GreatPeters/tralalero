## 사용자 상태와 작업 경계

원본 에디터의 저장되지 않은 씬을 보관한 후 원본 API로 적용했다. 반복 테스트는 `tmp/q`의 별도 파일/Library/회사·제품명과 분석 비활성 설정으로 격리했다. 원본58저장값은 코인3007·보석0을 포함해 유지됐고 새 보상 플래그도 생성되지 않았다. QA 부트스트랩/제품 설정은 원본에 복사하지 않는다.

광고는 공식 테스트 ID다. 실제 수익 광고 전환에는 AdMob 앱/광고 단위 ID, 대상 연령·동의 설정과 기기 검증이 필요하다. 게시/계정 생성/프로덕션 광고 활성화나 커밋·푸시는 수행하지 않았다.

광고 SDK 요구 사항에 맞춰 Android 최소 버전은7.0/API24다. Android6.0지원은 제외되며, 잘못된 최소 버전은 빌드 초기에 검사한다.

[Android 테스트 APK](../../Builds/Android/ChapterPolish-Test-20260913.apk)는727.7MB이며 디버그 서명/테스트 광고 구성이다. 최소API24·target36·ARM64·APK v2서명을 확인했다. 빌드 오류0개/경고44개이며, 실제 기기 검증이나 스토어 배포 인증은 아니다. [최종 검증 요약](final-verification.json).

검증용 에디터는 종료했고 원본 에디터는 노량진 씬을 유지했다. 임시 생성 서버와 원본 저장값 보존 상태도 실행 로그에 기록했다.
