## 후속 구현 기준

- 차단기: 한 차선 이상 항상 통과 가능, 닫히기 전에 색/점멸로 예고. 색만 쓰지 않고 X/화살표도 유지한다.
- 슬라럼: 차량은 갓길 배경과 실제 충돌 장애물을 명확히 구분한다. 연속 좌우 이동 사이의 시간을 확보한다.
- 단속 카메라: 도로의 절반만 예고하며 반대편은 안전하다. 피해 수치는 구현 전 밸런스 시트에 별도로 확정한다.
- 적: 새 캐릭터 그림을 그대로 모델이 존재하는 것처럼 취급하지 않는다. 기존 인간형 적의 애니메이션 재사용 가능성을 먼저 확인하고 필요한 외형만 제작한다.
- 보스: 내리막 직후나 가려진 장소 대신 충분한 평지 사격 구간 뒤에 둔다. 노량진 E23에서 발견한 문제를 반복하지 않는다.
- 가져오기: 외부 FBX/텍스처 원본을 보존하고 프로젝트용 프리팹에 스케일·피벗·콜라이더를 설정한다. 보이는 도로와 실제 주행면을 따로 검증한다.

이미지는 내장 ImageGen으로 제작했다. 입력 참조와 프롬프트는 [prompts.json](prompts.json)에 기록했다. 전체 A 보정은 같은 구도에서 Bonus Wall 두 개를 차선 안으로 옮기는 요청이었다. 원본 생성 파일은 사용자 generated_images에, 클릭 가능한 사본은 `tmp/image-previews/highway-examples-2026-09-10/`에도 보존했다.
