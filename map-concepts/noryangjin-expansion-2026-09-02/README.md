# 노량진 SUPER RADICAL 입체 교차 경로 30안

이전 경로 도면은 모두 폐기하고, 사용자가 표시한 것처럼 기존 길이나 신규 길 위를 다리·고가 데크로 넘어가는 `SUPER RADICAL` 30안으로 전면 교체했다. 모든 안은 현재 51모듈 뒤에 신규 179모듈을 연결해 총 230모듈이며, 의도된 입체 교차를 2~5개 포함한다.

## 공통 제작 기준

- 현재 경로: `서4 → 북9 → 동18 → 북6 → 서6 → 남8`, 총 51모듈
- 신규 경로: 모든 안이 179모듈, 전체 합계 230모듈
- 시작 리듬: 기존 종점에서 남쪽으로 최소 24모듈 진행한 뒤 첫 회전
- 경로 복잡도: 11~16개 직선 구간, 구간 길이 6~32모듈
- 의도된 입체 교차: 안별 2~5개; 신규 자기교차 1~5개, 기존 검은 길 통과 0~3개
- 교차 표현: 흰 고리는 교차점, 청록은 위로 지나는 다리, 주황은 오르막·고가 데크·내리막
- 금지: 같은 높이의 충돌, 평행선 되밟기, 교차점에서의 분기, 동일·좌우 반전 방향열
- 고속도로: 마지막 진행 방향 그대로 회색 `STAGE 2 HIGHWAY`에 연결하며 지나온 길을 다시 덮지 않음
- 시간 참고: 최근 실측 `13.5모듈 = 약 17.5초`의 선형 환산값은 약 298.1초; 회전·전투 정체 제외
- 제작 권위: [검증 매니페스트](route-manifest.json), `reference/routes`의 4096×4096 도면, `generate-route-schematics.ps1`

## 아이디어 강도

| 구간 | 성격 | 교차 구성 |
| --- | --- | --- |
| SR01~SR10 | 기존 맵 침투형 | 기존 검은 길을 1~3번 넘고 신규 길도 1번 교차 |
| SR11~SR20 | 8자·나선·클로버형 | 신규 자기교차 2번을 중심으로 일부 기존 길도 통과 |
| SR21~SR30 | 불가능한 항만 매듭형 | 신규 자기교차 3~5번; 가장 과감한 플라이오버 구조 |

표의 교차 수는 `전체(신규 자기교차/기존 길 위 통과)`이고, 도로 구성은 `기본길/다리/오르막길/내리막길/우회전길/좌회전길` 순서다. 도로 구성 여섯 수량의 합은 항상 신규 179개다.

## 추천안

사용자가 표시한 아이디어와 가장 가까운 안은 `SUPER-RADICAL-08 다섯 관문 클로버`다.

- 기존 검은 길을 세 번 고가로 통과한다.
- 신규 길끼리도 한 번 교차해 전체 교차가 네 번이다.
- 기존 구역을 지우지 않고 위·아래로 다시 활용한다.
- 마지막은 동쪽 고속도로로 연결된다.

[SUPER-RADICAL-08 4096×4096 정확 도면](reference/routes/super-radical-08-schematic-4096.png)

가장 과감한 안은 `SUPER-RADICAL-30 최종 인터체인지 카오스`다. 신규 길끼리 다섯 번 교차하고 서쪽 고속도로로 빠진다.

[SUPER-RADICAL-30 4096×4096 정확 도면](reference/routes/super-radical-30-schematic-4096.png)

## 검증 결과

- 정확 도면 30장, 모두 4096×4096 PNG
- 모든 경로: 현재 51 + 신규 179 = 총 230모듈
- 모든 입체 교차: 정확히 하나의 다리 또는 고가 데크가 위쪽 경로를 담당
- 같은 높이의 겹침·접촉: 0
- 동일·좌우 반전 방향열: 0
- 고속도로 미리보기의 경로 재침범: 0
- 도로 종류별 수량 합계: 모든 안이 신규 179개
- 주의: 실제 높이와 카메라 가림은 Unity 복제 작업 씬에서 검증하기 전까지 기획 도면 기준
