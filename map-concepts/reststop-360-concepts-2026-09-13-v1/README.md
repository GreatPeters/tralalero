# 식당360도 회전 방어 컨셉3안

**카메라 구도는 이후 사용자 검토에서 거부됐다.** 후방 경찰을 보여 주면서 상어가 화면 중간에 멀리 배치돼 기존 플레이와 다르게 보였다. 최신 수정은 [기존 플레이 구도 v2](../reststop-360-concepts-2026-09-13-v2/README.md)다. 아래 설명은 최초 제작 의도이며 시점 일치가 승인됐다는 뜻이 아니다.

사용자의 추가 설명을 반영했다: **위치는 고정되고, 몸체와 사격 방향이360도로 바뀌며, 접근하는 경찰을30초간 상대한다.** 기존 뒤쪽 게임 카메라의 방향을 유지하므로 몸체가 돌아가면 옆모습 또는 앞쪽 모습이 보인다.

세 그림은 같은 승인된 식당 스타일 안에서 측면·대각선·후방 대응을 비교한다. 상어는 하나이며, 한 순간의 사격은 현재 바라보는 목표 방향으로 표현했다. 가까운 화면 가장자리에 등을 보이며 들어오는 경찰을 넣어 후방 접근을 보여 줬다. 탑뷰나 카메라 회전으로 바꾸지 않았다.

## 해석 범위

- 바닥의 얇은 원형 화살표와360° 문구는 회전을 설명하기 위한 컨셉 표시다. 실제 스킬·방어막·플랫폼 구현으로 제안한 것이 아니다.
- 인물은 사람이면서 이전보다 몸통·다리가 긴3등신 방향이다. 정확한 모델 비율이나 애니메이션은 이 그림으로 검증한 것이 아니다.
- 수동 회전 입력인지 자동 조준인지 이번 발언에서 확정하지 않았다. 그림에는 임의 조이스틱이나 조작 버튼을 넣지 않았다.
- 이번 작업은 이미지 생성과 요구사항 문서 보존이며 Unity 씬·프리팹·저장값을 수정하지 않았다.
- [전체 프롬프트](prompts.md), [파일 대응](manifest.json), 사용자 직접 발언 U45는 `docs/design/USER_STATED_REQUIREMENTS.md`에 보존했다.
