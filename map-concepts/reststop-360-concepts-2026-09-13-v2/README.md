# 기존 플레이 구도를 유지한360도 방어 — 수정 v2

공간 구성에는 이후 [사진 기반 개방형 휴게홀](../reststop-open-hall-concepts-2026-09-13-v1/README.md) 정정이 추가됐다. 이 버전의 하단 플레이어 구도와 별개로, 좁은 통로형 식당은 최신의 확 트인360도 공간 요구를 충족한 것으로 취급하지 않는다.

이전360도 그림은 후방 경찰을 크게 보여 주면서 상어가 화면 중간으로 멀어져 관전 구도처럼 보였다. 사용자가 기존 스테이지와 비슷한 뷰를 다시 요구했으므로, 승인된 휴게소 R3 및 고속도로 H1의 **화면 하단 플레이어 위치·크기와 실내 원근 구도**를 기준으로 다시 편집했다.

세 장은 같은 식당과 같은 플레이 구도를 유지하면서 상어의 몸체·사격 방향만 왼쪽/오른쪽/후방으로 달리 보여 준다. 후방 적은 화면 밖에 두며 이를 보이게 하려고 카메라를 빼거나 올리지 않는다. 큰 후방 경찰과 중앙 바닥의 큰 원형 표시를 제외했다.
