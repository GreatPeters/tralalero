# 휴게소 개별 에셋 이미지 분해

2026-09-24 완료: 독립 PNG **69종**(신규 63종 + 기존 차량 6종). 원래 10개 구간 전체에 사용할 소품·구조 부품을 대응시켰다.

후속 [Blender 누락 검토](../reststop-prop-audit-2026-09-24/README.md)에서 환경 6종 누락·기믹용 진열대 1종 형태 보완·인물 장비 6종을 확인했다. 위 완료는 이 69종의 이미지 제작 완료이며, 최신 Blender 전체 소품이 빠짐없이 갖춰졌다는 의미가 아니다.

- [전체 갤러리](http://127.0.0.1:8771/): 구간 01~10 및 분류 필터, 개별 확대, PNG 저장.
- [최종 PNG 69종 ZIP](http://127.0.0.1:8771/reststop-atomic-assets-69png.zip): 67,986,629 bytes. 최종 선택본만 포함한다.
- [구간별 소품 CSV](http://127.0.0.1:8771/atomic/asset-map.csv).

사용자가 지정한 http://127.0.0.1:8771/ 의 공간 시안 전체를 독립적으로 재사용할 소품과 단순 구조 모듈로 분해한다. 새 이미지 63종과 기존 단독 차량 6종, 총 69종이다. 같은 형태의 반복 배치는 한 원본을 공유한다. 나사·경첩·핸들 등 부착 세부는 해당 물체에 포함하지만, 테이블/의자·판매대/진열장·화분 용기/조경 식물·차단기 본체/봉처럼 독립 배치나 움직임이 필요한 물체는 분리한다.

이미지만 제작한다. TRELLIS 실행, 새 Blender 모델, Unity 설치는 하지 않는다. ImageGen으로 원본 시안의 재질과 형태를 참고하여 가려진 면을 포함한 단독 물체를 새로 그린다. 기존 시안에서 잘라낸 불완전한 조각으로 대체하지 않는다.

- 최초 제작 계획·기본 프롬프트·원래 구간 대응: `catalog.json`
- 최종 선택 파일·검토 상태·해시: `final-manifest.json` (최종 상태의 기준)
- 실제 생성에 사용한 프롬프트·참고 이미지·정확한 출력 경로: `final-prompts-and-sources.json`
- 검증 결과: `verification.json`; 구간별 목록 사본: `asset-map.csv`
- 새 PNG: `tmp/image-previews/reststop-trellis-images-2026-09-23/atomic/`
- 생성 결과별 정확한 원본 경로·실제 프롬프트·검토 상태: 위 폴더의 `records/`
- 이전 공간 시안 페이지: 같은 서버의 `layout-reference.html`

차량 6종은 이미 단독 물체이므로 검토된 기존 PNG를 그대로 재사용한다. 포장 상품은 반복 배치할 기본 형태(봉지·병·상자·캔)와 식당의 트레이·빵·컵으로 분류하며, 저해상도 시안의 개별 상표까지 복제하지 않는다. 개별 PNG의 표시 배율은 게임 월드 치수가 아니다. 실제 TRELLIS 출력과 게임용 토폴로지·충돌은 아직 미검증이다.

## 검토와 전달

모든 최종 이미지를 생성 결과에서 육안 확인했고, 69개 PNG의 디코딩·RGBA·불투명 영역 경계 검사와 ZIP 내부 해시 대조를 통과했다. Chrome에서 69/69 완료 표시, 식당 필터 19종, 식당+가구 필터 7종, 주유소 전용 설비 4종, 의자 확대 표시를 확인했다. 갤러리·ZIP·CSV의 HTTP 200 응답도 확인했다. 이 검증은 이미지 전달 검증이며 실제 3D 변환 성공을 의미하지 않는다.

초기 F04 나무 이미지에 건물이 함께 생성돼 제외하고 `f04-v2.png`로 수정했다. 원본 `atomic/f04.png`는 기록용으로만 남아 있으며 갤러리와 최종 ZIP에는 들어 있지 않다. 작업 폴더 전체를 입력으로 넘기지 말고 최종 ZIP 또는 `final-manifest.json`의 파일만 사용한다. F09 의자는 F08의 형태를 유지한 색상 편집이다.

재생성 도구는 내장 `image_gen`을 사용했다. 프롬프트를 수정할 때는 최종 프롬프트 기록을 참고한다. 갤러리 재빌드는 저장된 PNG와 기록을 읽기만 하며 이미지 생성·TRELLIS를 실행하지 않는다:

```powershell
python tools/build-reststop-atomic-gallery.py
```
