# 최종 프리비즈 보고

상태: **Blender 프리비즈 제작·검증 완료**. 최종 게임 아트가 아닌 형태·배치·카메라·동작 검토용 산출물이다.

| 항목 | 결과 |
|---|---|
| 전체 공간 | 하나의 좌표계에 진입→주차→휴식→입구→광장→식당→편의점→화장실→주유소→출구 |
| 영상 | 1280×720,24fps,10개 구간 +300.00초 통합본 |
| 시간 | 25/25/25/25/60/30/30/30/25/25초, 총7,200프레임 |
| 방어전 | 60초 위치 고정,연속90도/초 제한,32명/8웨이브,35회 발사 |
| 화장실 | 30×20m=600㎡,개념 기준120㎡ 대비 면적5배 |
| 새 시안 | ImageGen 인물8종과 편의점2장. 프롬프트 보존 |
| Blender 원본 | 5.2.1 LTS,텍스처·폰트 포함,카메라 시점/네이티브 키 재생 |
| 모델 측정 | 전체880,366삼각형. 정적GLB 재임포트260메시/388,430삼각형/29재질 |
| 범위 유지 | TRELLIS·Seedance 실행 없음. Unity 씬 수정 없음 |

## 단계별 검토

1. 계약과 참조: PPT34슬라이드 및 앞 콘셉트와 최신 사용자 요구를 대조했다.
2. 공간 비율: 전체 배치와10구간 카메라에서 연결 관계를 검토했다. 화장실 공용 통로의 불필요한 칸막이를 제거하고 편의점/주유소 연결 바닥을 보강했다.
3. 주요/보조 형태: 저층 장방형 건물, 지붕선, 아치 캐노피, 판매대, 가구, 주유기, 차량, 휴게소 인물 역할을 모델링했다.
4. 구조와 계층: 문·차단기·차량·카트는 동작 계층을 갖는다. 정적인 직원의 다리를 개별 인물 관절로 복구해 형상과 정점 위치를 보존했다.
5. 재질: 석재·목재·금속·유리 등 구분된 재질을 적용하고 기존 상어 텍스처를 포함했다. 저샘플 유리 노이즈를 수정했다. 최종 게임용 텍스처 베이킹은 이번 범위가 아니다.
6. 카메라와 동작: 지붕·간판 가림, 화장실 전면 벽 가림, 회전 각도랩, 첫 효과의 키 충돌을 수정했다. 각 최종 MP4에서4개 시점을 추출해 확인했다.
7. 내보내기: 마스터를 새 프로세스에서 열고 방어1,441프레임을 검사했다. 환경GLB를 별도 재임포트하고 여러 방향·실제 인물 렌더를 확인했다.

## 증거와 한계

- `video-manifest.json`과`final-verification.json`:10클립 전체 디코드 통과, 순서대로 합친 프레임 해시와 통합본7,200프레임이 동일.
- `scene-validation.json`:고정XY·탑뷰·300초 통과. 회전 속도 실측90.003752도/초는0.01도/초 부동소수점 허용차 이내.
- `timeline-tests.txt`:10개 순수 로직 테스트 통과.
- `indoor-aisle-check.json`:190–253초,높이1.2m의 정적 중심동선505표본에서 막는 면 없음. 전체 충돌체/게임물리 검증은 아니다.
- `restroom-camera-visibility.json`:6개 시점의 몸통 가시성 검사 통과.
- `actor-ownership-validation.json`:직원6명의 다리3,696삼각형을 보존했고 정점 오차0.000018m 미만.
- 사람 시안의 얼굴/복장을 최종 고품질 메시로1:1재구성했다고 주장하지 않는다. Blender 인물은 움직임을 보여주는 간소화한 프리비즈 캐릭터다.
- 정적인 환경은 일부 구간·재질별로 합쳐져 있다. 재배치는 제작 스크립트를 기준으로 하며 GLB에는 환경만, 전체 애니메이션은`.blend`에 있다.
- 게임 밸런스, 실제 플레이 조작, 모바일 성능, 최종 게임 적용은 수행하지 않았다.

파일 목록과 재현 명령은[README](README.md), ImageGen 프롬프트는[concept-prompts.json](concept-prompts.json)을 참조한다.
