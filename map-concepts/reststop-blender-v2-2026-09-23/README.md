5번은 54차례의 경찰 접근, 방향 전환, 발사·피격·쓰러짐, 분사구 지연을 네이티브 키프레임으로 만든다. 네 개 분사구는 예고 후 작동하고 해당 방향의 접근 속도를 낮춘다. 제한된 회전 때문에 반대편 적에 대응하는 시간이 필요하다. 타이머 종료 때 남은 적은 정리되며 전원 사살을 보장하는 전투 시뮬레이션은 아니다.

기믹은 후진 경고등과 차량 회피, 움직이는 배식 카트, 편의점 카트 행렬·넘어지는 진열대·굴러가는 캔, 화장실 물 분사와 청소 로봇, 주유소 버스 교차, 곡선을 따라가는 출구 차량, 자동문·차단기다.

## 검증과 한계

검증 기록은 출력 폴더의 `validation.json`, `video-manifest.json`, `fresh-glb-validation.json`, `comparison/manifest.json`, `review-final/`에 둔다. `iteration_review.json`은 이전판의 비평, 보존 조건, 수정 원인과 최종 결정을 기록한다.

Blender 5.2.1 LTS / EEVEE / 1280×720 / 24fps / 7,200 프레임 / 무음. 프레임 보간이나 정지 화면 늘이기를 사용하지 않는다. 정적 GLB는 환경 교환용이며 게임용 LOD·콜라이더·성능 최적화 완료를 의미하지 않는다. 상어의 크기는 기준 프레임에서 평가된 몸체를 측정했고, 걷는 자세에 따라 순간 시각 바운드가 바뀐다. 조준 표식은 몸체 치수에서 제외했다.

## 재현

저장소 루트에서 Blender CLI로 `tools/run-limited-generation.py`를 통해 아래 스크립트를 실행한다. 한 번에 GPU 렌더 작업 하나를 실행한다.

1. `scene.py`: 전체 모델·애니메이션 작성. 마지막에 `calibrate_player.py`, `repair_exit.py`를 실행해 평가 몸체 크기와 출구 동선을 정규화한다.
2. `validate.py`: 저장된 네이티브 FPS·전체 길이·제자리 방어·회전 속도·카메라·몸체 크기를 검증하고 정적 GLB를 내보낸다.
3. `python tools/reststop-previs-v2/render_pipeline.py`: 최종 정지 화면, 전체 배치, 전체 프레임 렌더와 구간별 인코딩. 소스 프레임은 `frames-final/`이다.
4. `python tools/reststop-previs-v2/post_pipeline.py`: 영상 완성 후 GLB 새 임포트, 동일 배율 전후 비교, 인코딩된 영상 샘플 검토 시트와 갤러리.
5. `python tools/reststop-previs-v2/package.py`: 최종 검증 결과가 존재할 때 오프라인 갤러리·영상·원본 패키지 생성.

`finalize_candidate.py`는 이번 R3 중간 후보를 보정한 이력용 스크립트다. 새 `scene.py`는 그 변경을 포함하므로 이 스크립트를 다시 실행하지 않는다. 이전의 중단된 `frames/`는 검토 이력이며 최종 영상에 사용하지 않는다.

갤러리 서버가 종료되면 `python -m http.server 8768 --bind 127.0.0.1 --directory "tmp/image-previews/reststop-blender-v2-2026-09-23"`로 다시 열 수 있다. 또는 오프라인 패키지를 풀고 `index.html`을 브라우저로 연다.
