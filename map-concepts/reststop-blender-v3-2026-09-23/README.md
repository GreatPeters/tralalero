# 휴게소 v3 — 카트 제거, 차량 다양화, 자동 전진과 좌우 이동

사용자가 요청한 1~10번 구간의 **Blender 정지 이미지 10장**을 제작했다. 이전 v2 파일은 보존했다. 이번에는 새 동영상을 렌더하지 않았고 수정된 300초 애니메이션은 Blender 원본에 저장했다.

- 갤러리: http://127.0.0.1:8769/
- PNG와 전체 보기: `tmp/image-previews/reststop-blender-v3-2026-09-23/`
- 원본: `outputs/reststop-blender-v3-2026-09-23/reststop-v3.blend`
- 정적 환경: 같은 폴더의 `reststop-v3-environment.glb`
- 재현 소스: `tools/reststop-previs-v3/`

## 적용 내용

이동 카트 8대와 관련 예고 6개를 제거했다. 카트 때문에 하던 좌우 회피도 제거했다. 원래의 청소 로봇·분사구·후진 차량·진열대·버스 기믹은 구분해서 보존했다.

차량은 프로젝트에 있던 6개 모델을 사용했다. 흰색 승용차 18대, 빨간 소형차 19대, 초록 차량 16대, 배송 트럭 13대, 노란 박스 트럭 12대, 파란 버스 13대로 합계 91대다. 큰 차량은 경로에서 충분히 떨어진 자리에 배치하고 주차면 길이를 조정했다. 트럭의 세로축과 버스·배송 트럭의 원본 바닥판을 확인하고 수정했다. 원본 Unity 모델 파일은 수정하지 않았다.

이동은 `AUTO_RAIL_ANCHOR`가 정해진 중심선을 자동 전진하고, 자식 `PLAYER_ROOT`의 `lane_offset`만 좌우 위치를 제어한다. 로컬 전후와 높이 이동은 0으로 제한되며 좌우는 ±2.2 게임 유닛이다. 회전 방향도 경로가 결정한다. 카메라는 좌우 입력과 독립적인 지정 경로를 따른다. 입구에서는 작은 고정 카메라 오프셋을 사용한다. 이 오프셋도 사용자 입력과 무관하다.

5번은 예외적으로 제자리에서 60초 사방 방어하며 쿼터뷰와 최대 90도/초 연속 회전을 유지한다. 노란 점선·화살표는 자동 진행선, 파란 선은 통과 경로 폭을 보여주는 **검토용 표시**다. 최종 게임 UI를 설치한 것은 아니다.

## 검증

- 저장된 Blender 원본 재열기, 카트 잔존 0개, 6개 차량 모델과 총 91대 확인.
- 303개 시점에서 실제 월드 위치와 경로+좌우 입력을 비교한 최대 오차 약 0.000041 유닛.
- 좌우 입력 ±999를 넣어도 실제 위치는 ±2.2로 제한됨. 로컬 전후 입력 50은 차단되고, 카메라는 움직이지 않음.
- 5번 위치 고정과 최대 회전 속도 약 89.99064도/초 확인. 24fps·7,200프레임 유지.
- 10장과 차량 확인 렌더를 직접 열어 검토. GLB를 새 Blender 프로세스로 가져와 필수 구간·재질·전체 배치를 확인.

수치 기록은 출력 폴더의 `validation.json`, `build-metrics.json`, `fresh-glb-validation.json`, `images.json`에 있다. 프리비즈 수정이며 Unity 씬·게임 제어 코드는 바꾸지 않았다. TRELLIS와 Seedance를 실행하지 않았다.

## 재현

저장소 루트에서 `python tools/reststop-previs-v3/run.py`를 실행하면 보존된 v2 원본을 불러와 수정·검증·이미지 렌더를 수행한다. 이어 `verify_export.py`를 Blender CLI로 실행하고 `python tools/reststop-previs-v3/gallery.py`로 갤러리를 만든다. `tools/run-limited-generation.py`를 통해 CPU 4스레드와 순차 GPU 작업을 유지한다.

`entrance_camera.py`는 이번 첫 후보의 입구 촬영을 보정한 이력용 스크립트다. 최종 `revise.py`에는 이 변경이 포함되므로 새로 재현할 때 다시 실행하지 않는다.

갤러리 재시작: `python -m http.server 8769 --bind 127.0.0.1 --directory "tmp/image-previews/reststop-blender-v3-2026-09-23"`.
