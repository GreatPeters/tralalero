# 휴게소 v3 수정 계약

사용자 요청: 이동 카트 제거, 더 다양한 자동차, 정해진 경로의 자동 전진과 경로 기준 좌우 조작만 가능한 이동, 수정 후 1~10번 이미지 제공.

이전 v2 원본과 결과는 보존한다. 기존 확대 편의점·화장실, 300초 타임라인, 10구간 순서, 5번 쿼터뷰 60초 제자리 방어와 90도/초 회전 제한은 유지한다. 새 영상 렌더 대신 이번 요청의 10장 PNG를 제공한다. TRELLIS/Seedance/외부 모델 생성/Unity 씬 설치는 제외한다.

수정:
- 모든 `Cart_train` 조립체와 `Cart_crossing` 예고를 제거한다. 제거된 카트에 반응하는 좌우 동작도 제거한다.
- 기존 프로젝트 Highway Props의 054/067/080/081/082/083 모델을 실제로 렌더해 확인한 후 사용한다. 크기와 실루엣이 다른 차량을 섞고 대형차 주차면을 늘린다. 차종은 이미지 확인 후 확정한다.
- `AUTO_RAIL_ANCHOR`가 시간에 따라 고정 중심선을 전진한다. `PLAYER_ROOT`는 이 루트의 자식이며, 유일한 위치 조작값은 `lane_offset`이다. 로컬 전후 이동은 0에 제한하고 좌우는 ±2.2 게임 유닛으로 제한한다. 방어 중에는 좌우도 0이다.
- 카메라는 경로 중심을 따라가며 좌우 조작을 따라 흔들리지 않는다. 이동 경로와 좌우 폭은 이번 검토용 바닥 안내선으로 표시한다.

형태·재질은 기존 게임 모델과 v2 프리비즈 수준을 유지한다. 새 완성 게임 아트나 게임용 최적화 완료로 부르지 않는다. 차량은 색상뿐 아니라 차체 형상·크기가 구별되어야 한다.

검증: 저장된 파일 재열기, 카트 잔존 0, 차량별 분포·치수·재질, 세계 좌표 = 경로 앵커 + 좌우 오프셋, 5번 위치·회전 제한, 네이티브 10장 렌더와 차량 확인 이미지, 정적 GLB 새 임포트. 실제 Unity 제어 코드의 `PlayerMove`/`ApplyForwardMovement` 분리와 같은 방식으로 프리비즈를 구성한다.
