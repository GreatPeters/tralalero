# v3 완료 기록

요청한 10장 PNG와 수정된 Blender 원본을 완성했다. 결정은 `retain_repair`이며 v2는 보존했다.

기준 확인 → 기존 차량 형태·축·바닥판 검토 → 차종별 배치와 주차면 수정 → 카트 제거 → 자동 경로 부모와 좌우 제약 구성 → 네이티브 검증 → 10장 촬영 → 정적 GLB 새 임포트 → Chrome 갤러리 확인 순서로 진행했다. 기존 프리비즈 건축과 게임 모델의 재질을 재사용했으며 새 완성 게임 아트로 주장하지 않는다.

확인한 값: 이동 카트 0개, 차량 모델 6개·총 91대, 경로 위치 최대 오차 0.000041 유닛 미만, 전후 입력 차단, 좌우 극단 입력 제한, 카메라의 좌우 입력 독립, 방어 60초와 최대 회전 89.99064도/초. 24fps·7,200프레임 유지.

10개 PNG는 모두 1600×900이며 차량 확인 이미지는 1600×1100이다. Chrome에서 모든 이미지 로드와 번호별 링크·다운로드 링크를 확인했다. 소스·원본·GLB·수치 기록 위치는 [README](README.md)를 참조한다. 이번 수정의 이미지 ZIP은 갤러리 폴더의 `reststop-v3-images.zip`이다.

변경 범위는 Blender와 검토 이미지다. Unity 씬 설치, TRELLIS·Seedance 실행, 새 동영상 인코딩은 수행하지 않았다. 고정된 경로·차선 폭·기믹 타이밍은 프리비즈용 구성이고 Unity 런타임 충돌·밸런스 검증을 대신하지 않는다.

재사용할 측정·축·이동 제약 검증 교훈은 `ce-compound mode:headless`로 기존 Blender 워크플로 문서에 통합했으며 frontmatter 검증을 통과했다.
