# 사진 기반 개방형 휴게홀 —360도 방어 컨셉3안

사용자가 첨부한 실제 휴게소 사진을 공간 기준으로 삼았다. **매점은 먼 외곽에 두고, 중앙과 좌우로 끊김 없이 넓은 타일 바닥을 비운다.** 이전의 좁은 식당 통로를 확정안으로 취급하지 않는다.

상어는 화면 하단의 가까운 플레이 위치를 유지하고 제자리에서 몸체와 사격 방향을 바꾼다. 공간을 넓히기 위해 카메라를 관전 시점이나 탑뷰로 바꾸지 않는다. 화면 밖의 후방 적을 보이게 하려고 카메라를 뒤로 빼지 않는다. 주변은 사람 경찰,3등신 방향의 비율이다.

## 범위와 기록

- 원본 사진의 개방된 바닥·가장자리 매점 구성을 반영했다. 상호 복제나 실측 크기 일치를 요구한 것으로 해석하지 않았다.
- 각 그림에서 하단의 큰 상어, 가까운 가구/기둥 없는 바닥, 먼 외곽 매점, 회전 사격 방향과 사람 경찰을 시각적으로 확인했다.
- ImageGen 컨셉이며 실제 Unity 카메라 수치·메시·충돌체의 검증 결과가 아니다. 씬·프리팹·밸런스·저장값은 변경하지 않았다.
- [전체 프롬프트](prompts.md), [원본/최종 파일 대응](manifest.json).
- 사용자 직접 요구는 `docs/design/USER_STATED_REQUIREMENTS.md` U46에 보존했다.
