## 이번 시안의 설계 선택

하나의 저층 본관에 정면 간식 거리, 중앙 식당, 오른쪽 화장실을 연결하고, 주유소는 진입 쪽에 분리한다. 크림색 벽·목재·짙은 지붕·황토색 띠를 공통으로 쓰며 빨간 주유소 캐노피를 구분점으로 둔다. 이는 PPT를 종합한 에이전트 제안이며 사용자 확정 배치·치수가 아니다.

기존 사용자의 실내 제자리 방어전 요구를 고려해 식당 중앙의 시야와 이동 여백을 살린다. 현재 게임 카메라에서의 가림, 치수, 충돌과 동선은 이 이미지로 검증되지 않는다. 실제 제작에서는 Blender에서 배치를 확정한 뒤 개별 구조·소품의 뷰를 뽑아 검토할 수 있다.

## 산출물

6장 완성. 모든 PNG는 1672×941이며 파일 디코딩과 SHA-256을 확인했다. 이름·크기·해시는 미리보기 폴더의 `manifest.json`에 있다.

| 파일 | 내용 |
|---|---|
| `01-overall.png` | 전체 조감도 |
| `02-promenade.png` | 정면과 간식 거리 |
| `03-food-hall.png` | 식당과 중앙 방어전 공간 제안 |
| `04-restroom.png` | 화장실 컷어웨이 구조 참고 |
| `05-fuel-station.png` | 주유소와 진입 구역 |
| `06-module-board.png` | 개별 제작할 8개 주요 조립 단위 |

브라우저 갤러리: <http://127.0.0.1:8766/>. 전용 미리보기 폴더만 루프백으로 제공한다. Chrome 탭을 보존했으며 갤러리의 이미지 표시, 모듈 보드 확대, Escape로 닫기와 복귀를 직접 확인했다. 서버가 종료되면 같은 폴더의 `index.html`을 브라우저로 열 수 있다. 서버 PID는 `server.pid`에 기록했다. 원본 PPT나 기존 Unity/Blender 파일은 변경하지 않았다.

주의: 여러 이미지가 같은 재료와 형태를 공유하지만 실제 동일한 3D 씬에서 렌더한 다중 시점은 아니다. 정면 간판, 주유기 수, 창·캐노피 세부와 실내 비율은 시점마다 다를 수 있다. 식당의 넓은 중앙 공간과 화장실 세부 배치는 모델링 전 제안이다. 모듈 보드의 물체별 표시 배율도 동일하지 않다. 후속 제작에서 하나의 블렌더 배치와 치수로 정리해야 한다.

모듈 보드는 RGBA이다. 일부 단독 미리보기의 검은 바탕·가장자리 색점은 실제 브라우저 합성 화면에 나타나지 않았다. 알파를 유지한 원본을 그대로 보관했으며 밝은 갤러리 배경과 어두운 확대창 모두 확인했다.
