# 실행 기록

- 입력90종 준비 및 디코딩/잘림 경계 확인 완료. 신규18장, 이전 인물 입력3장, 원래69장을 사용한다.
- 작업 서버8189는 기존 독립 UV 수학 구현이다. 실제 새 생성2건에서 호출 카운트2를 확인했다.
- F08은 자동감량2회 모두 프레임 표면 결함으로 거절했다. 직접 보정 F08-r3를 시각/새 FBX·GLB 임포트 검증 후 선택했다. `final-overrides.json`에 기록하며 자동 원장은 덮어쓰지 않는다.
- H01 정적 몸체는 단계별검토 통과(13,373삼각형). 18본/9동작 후보를 만들었으나 **H01, H01-r2, H01-r3, H01-r4 리그는 모두 최종 승인하지 않았다**. r1은 손목 변형/FBX 접지, r2/r3은 장갑 색상 경계 처리에서 옷·바지가 손에 따라가는 변형, r4는 기존 v2 리그의 최근접 표면 가중치 전사 후에도 팔/조끼 변형이 남는다. 내보내기 수치 통과만으로 완료 처리하지 않는다.
- H01-r2부터 보행 Hips 수직 이동키를 없애고 Root 접지에 맡겨 FBX·GLB 접지검사 통과. 손목 변형은 별도 미해결이다. UV 분리 정점의 동일 가중치와 장갑 분류 영역을 다시 조사 중이다.
- H02 요리사는 형태·고밀도 재질·감량본 비교 통과(12,771삼각형). 앞·뒤·사선·중립 재질 렌더와 새 FBX·GLB 임포트를 확인했다. 현재 H03 바리스타 생성 중이다. 배치는 F08을 제외한 인물8종을 우선하고 나머지를 이어간다. 전체 자동 배치 PID/현재상태는 `outputs/reststop-production-2026-09-24/runner.json`, `status.json` 참조.
- H01-r5 원본 메시 직접 bone heat는 실패했다. r6은 닫힌 복셀 프록시에서 heat를 계산하고 원본 UV 메시로 가중치를 옮겨 계산은 성공했으나 팔 변형은 남았다. 정면·측면 좌표 도식에서 이전 기증 리그의 몸통/팔다리 뼈가 새 모델 중심보다 앞·옆으로 치우치고 손목도 너무 낮음을 확인했다. 표면끼리 근접한다는 검증은 기증 리그의 뼈 위치가 적절하다는 증거가 아니었다.
- H01-r7은 실제 모델 비율에 맞춰 중심·어깨·팔꿈치·손목을 다시 배치하고 프록시 heat를 적용했다. 공격·인사 주요 포즈의 팔 찢어짐이 해소되었다. 새 FBX·GLB 임포트에서 18본/9동작, 가중치 합, 동작 변화, 접지 검사를 통과했다. 전체 동작의 시각 검토와 영상 확인 전까지 리깅 완료 수에는 넣지 않는다.
- H01-r8과 H02-r2를 최종 리그로 선택했다. 보행 발 각도에 허벅지·정강이 회전 보상을 적용해 양쪽 발끝이 함께 들리던 모습을 고쳤다. 각 18본·9동작·338프레임/30fps 영상, 새 FBX/GLB 검사, 주요 포즈 시각 검토를 통과했다. `accepted-rigs.json` 및 개별 `visual-review.json`에 기록했다. 갤러리는 이 명단만 리깅 완료로 센다. H01 영상은 브라우저에서 실제 재생·11.266667초·readyState4도 확인했다.
- H03 바리스타는 정적 모델 13,601삼각형 및 H03-r1 리그 검증을 통과했다. 18본·9동작·338프레임 영상과 새 FBX·GLB를 확인했다. 큰 팔 동작에서 앞치마 주름과 소매 끝 작은 원본 요철은 경미한 사항으로 기록했다. 이후 H04 계산원부터 계속 생성한다. H04~H08은 팔다리가 긴 입력 비율이므로 별도 뼈 위치 초안을 마련했으며 실제 생성본에서 다시 검증한다.
- H04 계산원은 정적 모델 13,410삼각형 및 H04-r1 리그 검증을 통과했다. 긴 몸통/다리에 맞춘 본으로 공격·인사·서빙·걷기·달리기·피격·사망 주요 포즈를 확인했다. 18본/9동작, 338프레임 영상, 새 FBX·GLB 및 반복 동작 끝점 검사가 통과했다. H01~H03도 반복 4동작 끝점 검사를 추가 확인했으며 오차는 0이었다. H02 영상은 브라우저에서 끝까지 재생된 화면(0:11/0:11)도 확인했다.
- H05 청소원은 정적 모델 12,913삼각형 및 H05-r1 리그 검증을 통과했다. 청소 동작을 포함한 9동작/18본/338프레임 영상, 새 FBX·GLB, 반복 동작 끝점을 확인했다. 들어올린 소매 끝의 작은 원본 요철은 경미한 사항으로 기록했다. `build-reststop-rig-candidate.py`는 검토 대기 중인 GPU 휴지 구간에서 본 작성→새 임포트→동작 렌더를 순차 실행하며, 시각 승인이나 완료 명단 추가는 자동으로 하지 않는다.
- H06 주유소 직원은 정적 모델 13,326삼각형 및 H06-r1 리그 검증을 통과했다. 안내 동작 포함 18본/9동작/338프레임, 새 FBX·GLB와 반복 끝점 검사도 통과했다. 옷깃의 작은 어두운 이음새는 경미한 사항으로 기록했다. 다음 H07 여행객, H08 경찰 뒤에 나머지 소품 배치가 이어진다.
- H07 여행객은 정적 모델 13,171삼각형 및 H07-r1 리그 검증을 통과했다. 놀라는 동작 포함 18본/9동작/338프레임, 새 임포트·반복 끝점·주요 포즈 시각 검토를 확인했다. 추가 `compare-reststop-export-poses.py`는 원본 Blender와 새 FBX·GLB의 모든 동작 5개 위상에서 변형된 표면 샘플과 관절 위치를 비교한다. H07 최대 표면 오차0.009926, 관절 위치 오차0.006321로 허용0.02단위 안에서 통과했다. 기존 승인 인물도 동일 검사를 추가하고 최종 패키지에 기록을 포함한다.
- H08 경찰은 정적 모델 13,032삼각형 및 H08-r1 리그 검증을 통과했다. 방어 동작 포함 18본/9동작/338프레임, 새 임포트·반복 끝점·원본/내보내기 포즈 비교·주요 포즈 시각 검토를 마쳤다. **인물 8종의 리깅·애니메이션은 완료**이며 소품 배치는 계속 진행 중이다. 각 인물은 손 소켓을 제공하고 휴대 장비는 별도 에셋이다. 전체90종 완료와 혼동하지 않는다.
- 인물 8종/72클립 전용 ZIP `reststop-humans-rigged-8-r1.zip`을 만들고 CRC 검사를 통과했다(207,348,304바이트). 갤러리 다운로드 링크의 HTTP200/동일 Content-Length도 확인했다. 모델8종×3형식·동작영상·기준이미지·검증기록을 포함하며, 나머지 소품은 포함하지 않는다고 README에 명시했다.
- B01 실내 바닥 타일은 14,798삼각형 최종본을 통과했다. 바닥 제거 옵션에서도 본체가 유지됐고, 평평한 상판·4분할 줄눈·외곽 테두리·하부 홈을 확인했다. 중립 뷰의 하부 모서리 약한 둥글어짐과 원본보다 조금 강한 석재 무늬를 경미한 사항으로 기록했다. `make-reststop-review-sheet.py`는 원본 입력·5개 실제 렌더·감량 전 비교 렌더를 진단용 한 장으로 모으며, 원본 이미지/모델을 수정하지 않는다.
- B02 석재 벽은 두 자동 감량본 모두 넓은 면에 새로 생긴 울렁이는 음영으로 거절했다. B02-r1은 주 면을 보정했으나 옆면의 이전 베이크 노멀과 새 정점 노멀이 충돌했다. 전체가 단단한 판인 점을 확인하고 B02-r2에서 면적/각도 가중 노멀과 전체 면의 낡은 노멀 입력 제거를 적용했다. 13,578삼각형·정점 위치·UV·기타 PBR 채널을 유지하고 앞뒤/위/중립 렌더, 새 FBX·GLB 검증을 통과했다. `final-overrides.json`으로 선택하며 자동 원장은 `review_needed`로 보존했다. 작은 원본 줄눈 패임과 규칙적 배열로 바뀐 줄눈은 경미한 차이로 기록했다.
- 갤러리는 15초마다 상태 JSON만 읽어 진행 숫자/문구를 갱신한다. 새 완료본이 생기면 새로고침 버튼을 표시하므로 기존 동영상 재생을 강제로 재시작하지 않는다. B02의 검토→생성 단계가 페이지 새로고침 없이 바뀌는 것을 브라우저에서 확인했다.
- B03 목재 슬랫 패널은 m1의 전면 슬랫 누락/뒷면 문손잡이 형태, m2의 거의 평평한 전면 때문에 두 형상을 거절했다. m3에서 전체 전면의 반복 홈과 뒷면 지지대가 복구됐다. `inspect-reststop-slat-profile.py`의 광선 단면 검사로 m2의 평평한 앞면과 m3의 주기적 홈을 대조했고, `reviews/B03-profile-comparison.png`에 보존했다. m3 형상은 통과해 첫 텍스처 생성으로 진행한다. 수동으로 슬랫을 재구축하지 않았고, 허용 메시3회 한도를 지켰다.
- B03의 후속 감량 두 방식에서 앞면의 얇은 홈이 실제로 불규칙해진 것을 확인했다. B03-r1 가중 노멀만으로는 형상을 되살리지 못했고, B03-r2 최근접 원본 노멀 전사/재베이크는 검은 음영을 만들어 거절했다. B03-r3에서 보존된 TRELLIS 고밀도 원본의 1,025개 단면 표본을 202개 점으로 정리해 전면 구간만 재토폴로지하고 2K PBR을 다시 구웠다. 단면 최대오차0.0001281(허용0.0005), 실제 새 FBX·GLB 14,210삼각형으로 검증을 통과했다. 프레임과 뒤 지지대는 보존했다. 최초 다각형 n-2 추정14,214와 실제 내보내기14,210의 차이는 기록했으며 최종 수치는 실제 파일 기준이다. `reviews/B03-normalized-profile-proof.png`는 모델 높이로 정규화한 원본/감량/복구 단면 비교다.
- B04 석재 기둥은 14,680삼각형 최종본을 통과했다. 기둥·상부 캡·하부 받침과 석재 재질이 유지되며 새 FBX·GLB 검사도 통과했다. 중립 뷰에서 더 보이는 경미한 받침/캡 모서리 둥글어짐은 기록했다.
- B05 창문은 14,784삼각형 최종본을 통과했다. 상부3칸/하부3칸 유리와 프레임이 유지됐고 새 FBX·GLB 검사도 통과했다. 더 차가운 프레임 색조, 강한 반사 띠, 얇은 안쪽 테두리의 경미한 감량 흔적은 기록했다. 중립 뷰만으로 정상적인 노멀맵 복원을 오판하지 않고 실제 PBR 모습과 구조 보존을 함께 판단했다.
- B06 자동문 프레임의 m1은 하부 레일 중간이 없어지고 끝이 불규칙하게 돌출돼 거절했다. 캐시된 동일 u2net/CPU로 전처리를 읽기 전용 재현한 결과 원본과 rembg 후 모두 레일이 온전히 남아 있었다(`reviews/B06-preprocess/`). 입력이나 전처리 설정은 바꾸지 않았다. m2는 통로를 큰 판으로 막아 거절했으며 마지막 허용 형상을 생성한다.
- B06 m3도 하부 레일이 끊겨 세 형상을 모두 거절했다. `restore-reststop-door-track.py`로 m3의 문틀·센서를 유지하고 생성된 레일 끝의 단면을 연결해 연속 가이드를 만들었다. glTF 객체가 Quaternion 모드여서 Euler 회전이 적용되지 않은 초기 두 실행은 중앙 통로 검사에서 중단됐고, `rotation_mode='XYZ'`를 명시해 고쳤다. 보정 형상의 5개 시각 뷰와 통로/레일 검사를 통과한 뒤 별도 원장으로 남은 텍스처 예산 중1회를 사용했다(원래 AI형상3회/텍스처0회 + 보정 텍스처1회, 전체 텍스처한도3). GPU가 비어 있는 B07 최종 비교 대기 구간을 이용했고60초 생성 휴식도 지켰다. 자동 원장은 수정하지 않았다.
- B06 최종 선택은 `manual/B06-r1/texture1/low1`, 14,491삼각형이다. 새 FBX·GLB 모두 통로9광선/레일5광선 및 기본 임포트 검증을 통과했다. 차가운 금속색·밝고 단순화된 레일 마감과 작은 원본 자국은 경미한 차이로 기록했다. B07 유리 문짝은 14,795삼각형으로 별도 최종 검토를 통과했고, B06 GPU 처리 후 보류했던 완료 판정을 기록해 배치를 이어갔다.
