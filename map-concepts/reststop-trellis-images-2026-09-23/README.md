# 휴게소 배치 시안과 단독 차량 후보 — 16장

## 정정

사용자가 지적한 대로 01–10의 복합 공간 전체를 한 번에 사용할 TRELLIS 제작용 입력이라고 분류한 판단은 잘못이었다. 이 파일들은 **배치 참고 시안**으로만 취급한다. 테이블·의자·판매대·진열대·화분·구조 모듈 등으로 나누어 실제 입력 이미지를 별도로 제작해야 한다. 11–16은 단독 차량 입력 후보이지만 실제 변환은 미검증이다. 투명 배경·파일 디코딩·잘림 검사는 복잡한 공간의 3D 변환 적합성을 증명하지 않는다. 기존 PNG는 보존했고 갤러리 안내를 정정했다.

사용자의 “이미지만” 요청에 따라 기본 제공 ImageGen으로 공간 모듈 10장과 차량 단독 이미지 6장을 제작했다. Blender 모델 제작·영상 렌더·TRELLIS 추론·Unity 설치는 이번 작업에서 수행하지 않았다.

- 갤러리: http://127.0.0.1:8771/
- 이미지 폴더: `tmp/image-previews/reststop-trellis-images-2026-09-23/`
- 선택된 16개 PNG만 포함한 ZIP: 같은 폴더의 `reststop-trellis-inputs-16png.zip`
- 최종 목록·파일 해시·알파 경계: `manifest.json`
- 정확한 생성/수정 프롬프트와 반환된 원본 경로: `prompts.json`
- 최종 선택과 원본 대응: `selected.json`

PNG는 모두 1254×1254 RGBA이며 생성된 알파를 그대로 보존했다. 한 파일에는 하나의 공간 모듈 또는 한 대의 차량이 들어 있다. 공간 모듈은 독립된 정적 조립 단위다. 차량은 따로 생성하여 주차장 모듈에 합치지 않았다. 이미지 표시 크기는 게임 월드 크기를 지정하지 않는다.

01 진입로, 02 주차 구획, 03 정면 휴식·간식 공간, 04 본관 입구, 05 넓은 중앙 홀, 06 식당, 07 대형 편의점, 08 대형 화장실, 09 주유소, 10 출구. 11 흰색 크로스오버, 12 빨간 소형차, 13 초록 소형 SUV, 14 배송 트럭, 15 노란 박스 트럭, 16 대형 버스.

주차장 초기 이미지의 잘린 모서리를 ImageGen 수정으로 복원했고, 승용차 3종의 외부 접촉 그림자와 바닥 패치를 ImageGen 수정으로 제거했다. 이 네 개의 초기 후보는 보존했지만 최종 갤러리와 ZIP에는 넣지 않았다. 최종 16장은 모두 직접 확인했으며 PNG 디코딩·해시·알파 존재·불투명 영역의 캔버스 경계 비접촉·ZIP 무결성을 검사했다.

갤러리는 흰 배경 위에서 알파를 합성해 보여준다. 일부 도구의 검은 미리보기 배경은 원본 PNG의 불투명 검은 배경을 뜻하지 않는다. 개별 PNG를 입력해야 하며, 전체 보기 화면이나 여러 이미지를 합친 보드는 입력용이 아니다.

입력 전처리 근거와 범위는 [production.md](production.md)에 기록했다. 실제 TRELLIS 변환 결과, 숨은 면·실내 구조 복원, 게임용 토폴로지·콜라이더는 아직 검증하지 않았다.

갤러리 재시작: `python -m http.server 8771 --bind 127.0.0.1 --directory "tmp/image-previews/reststop-trellis-images-2026-09-23"`.
