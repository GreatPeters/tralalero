# TRELLIS 입력용 이미지 제작

정정: 아래의 최초 계획은 제작 단위가 너무 컸다. 여러 가구와 건축이 함께 있는 01–10 공간 그림은 배치 참고이며 한 번의 제작용 입력으로 사용하도록 권장하지 않는다. 후속 입력은 독립적으로 재사용·배치할 물체 또는 단순 구조 모듈 한 개 단위로 다시 설계한다.

이번 요청은 이미지만 제작하는 것이다. Blender 모델·영상·TRELLIS 생성·Unity 설치는 수행하지 않는다.

1~10 구간의 공간 모듈과 별도로 배치할 차량 6종을 각각 한 장씩 생성한다. 이미지 안에는 여러 시점의 보드·자막·게임 HUD·이동 안내선·캐릭터·이동 카트를 넣지 않는다. 기존 PPT의 크림색 석재·목재·짙은 지붕·황토색 처마와 주유소의 빨간 캐노피를 통일된 재질 기준으로 사용한다. 큰 편의점·화장실과 넓은 중앙 홀을 유지한다.

각 입력 PNG는 한 개의 모듈 또는 한 대의 차량을 사선 한 시점으로 보여준다. 흰 배경 또는 생성된 실제 알파를 보존하고 전체 실루엣을 확인한다. 차량은 주차장 그림에 합치지 않는다. 갤러리의 모아보기 이미지는 검토용이며 실제 입력은 개별 파일이다.

기본 제공 ImageGen을 사용한다. 정확한 프롬프트와 생성 원본 경로는 `prompts.json`에 보존한다. 생성 즉시 반환된 정확한 경로에서 프로젝트로 복사한다.

Microsoft의 [TRELLIS.2 입력 전처리](https://github.com/microsoft/TRELLIS.2/blob/main/trellis2/pipelines/trellis2_image_to_3d.py)는 알파가 있으면 사용하고, 그렇지 않으면 배경 제거 후 피사체 영역을 자른다. 고립된 피사체·선명한 경계·단일 시점 구성은 이 흐름을 고려한 이번 제작 선택이며 변환 성공이나 숨은 내부 구조의 복원을 보장하지 않는다. 이미지의 표시 크기는 게임 월드 크기를 고정하지 않는다.
