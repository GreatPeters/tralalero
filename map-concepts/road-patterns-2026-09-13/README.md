# 고속도로 분기와 휴게소 식당 방어전

2026-09-13에 기획 후 원본 HighWay와 RestStop 씬에 적용했다. 코인, 보석, 강화, 스킨 등 사용자 저장값 63개는 테스트 전과 동일한 상태로 복구·검증했다. 원본 Unity는 HighWay를 연 Edit Mode로 남겼고, 별도로 실행한 QA 에디터는 종료했다.

## 플레이 변화

- **HighWay:** 다섯 직각 정지 코너를 연속 곡선으로 바꾸고 긴 구간에도 완만한 굴곡을 넣었다. 두 갈림길에서 왼쪽 초록선은 회복 우회로, 오른쪽 분홍선은 본선이다. 선택 후 각각 다시 합류한다. 우회로는 한 번씩 최대 체력의 10%를 회복한다.
- **정면 차량:** 단독 차량, 시간차 두 차량, 공사 차로 합류, 가운데 틈을 남긴 차량 행렬, 터널 앞 접근의 다섯 구간에 총 11대가 등장한다. 2.2초 예고 후 고정된 차로로 접근한다. 차량 한 대가 같은 플레이어에게 피해를 중복 지급하지 않으며, 이동 구간을 검사해 빠른 차량이 플레이어를 통과하는 것을 막는다. 기존 횡단 차량·차단기도 유지한다.
- **RestStop:** 주차장과 매점 거리에서 실제 식당 안으로 들어가 30초간 버틴 뒤 다시 달린다. 상어의 위치는 고정되고 가장 가까운 경찰을 자동 조준한다. 10초 단위로 양옆, 앞뒤, 사방의 출입구를 사용한다. 완료 시 셔터가 열리고 최대 체력의 12%를 회복한다.
- **식당 내부:** 26.4 × 43.2 규모의 지붕을 생략한 내부에 매대, 자판기, 테이블과 의자를 배치했다. 중앙 전투 공간과 네 출입구를 비웠다. 카메라를 올려 뒤쪽의 적도 보여 주고, 생존·사망·재시작 때 기존 카메라와 이동 상태를 복구한다.
- **연결 기능:** 곡선에서도 지원군이 도로를 따라간다. 식당에서는 지원군이 앞쪽으로 떠나지 않고, 원거리 지원군도 경찰을 조준한다. 고속도로 진행 로그는 없어진 코너 트리거 대신 실제 경로 진행률을 사용한다.

한국 고속도로의 유도선·방향 안내는 [국토교통부 노면 색깔 유도선 매뉴얼](https://www.molit.go.kr/USR/policyData/m_34681/dtl.jsp?id=4366)을 참고했다. 특정 실제 나들목을 복제한 지도는 아니다.

## 밸런스와 편집

`Assets/ShooterSurvival/GameData/Editor/Data.xlsx`의 **밸런스 조정 109~118행**에 차량 예고·속도·피해, 우회로 회복, 방어 시간, 경찰 체력·속도·진입 간격, 탈출 회복을 추가했다. 환경 변수 26~34행과 연결되며 서명된 `Data.bytes`도 갱신했다. 최종 경찰 체력은 700, 기본 속도 3.8, 기본 진입 간격 1.05초다.

RestStop 전진 속도는 7 → 7.8로 조정했다. 약 269초의 이동과 30초 방어를 합친 약 300초가 목표다. 식당과 겹치는 야외 배치 11·12번은 ID를 보존하고 사용 값을 0으로 바꿨다. 따라서 야외에는 적 46명·보너스 23쌍·기믹 23구간이 활성화되고, 식당에서는 별도의 16개 재사용 경찰 오브젝트를 쓴다. 기존 50/25/25 표의 연결 ID는 모두 남아 있다.

도로·분기·차량 일정·식당은 저장된 씬의 구성 요소이며 Inspector에서도 편집할 수 있다. `RoadChapterPatternBuilder`와 `tools/refine-road-pattern-*.cs`는 이번 네이티브 작성·수정 기록이다. 초기 작성 메뉴는 기존 개선 씬을 덮어쓰지 않도록 거부한다.

## 검증 결과와 범위

자동 테스트 **123개 통과**: 새 패턴 19, 기존 회전·투사체 48, 전투·지원군 12, 챕터 통합 4, 분석 로그 25, 워크북·서명 15. 런타임 및 Editor C# 빌드 성공. 프로젝트 검증 스크립트 통과. 마지막 QA 콘솔 오류 0개.

실제 플레이와 화면 검토를 반복하면서 곡선 방향 튐, 과도하게 넓은 식당, 가독성, 출입구를 가리는 매대, 우회로 가까운 수목, 경찰 재사용 위치 초기화를 수정했다.

| 검증 | 결과 | 조건 |
|---|---|---|
| 초록 우회로 | 선택·회복·본선 합류 후 374m까지 진행 | ATT27, HP32, 공격속도30, 일반 좌우 입력 |
| 본선 초반 | 정면 차량을 피하고 본선 선택, 16초 진행 | 같은 강화 단계, 체력 보정 없음 |

| 식당 생존 | 30초 완료, 앞뒤·좌우 총 27명 생성, 탈출 후 이동 | ATT37, HP46, 공격속도30, 식당 접근 구간부터 시작 |

식당 성공 검증의 생성 수는 출입구별 6·7·8·6명이다. 마지막 체력은 9,897.6이었다. 낮은 진입 강화 ATT27/HP32와 야외 보너스 없는 구간 설정에서는 29.09초에 패배했으며 사망 시 잠금 복구도 확인했다. `killed` 진단 값은 접촉으로 제거된 적도 포함한다.

이번 변경 후 챕터별 20판 성장 코호트 전체와 Android 기기 플레이를 새로 완료한 것은 아니다. 이전 17/22/22판 기록과 이전 APK는 이 패턴 변경 전의 기록이다.
