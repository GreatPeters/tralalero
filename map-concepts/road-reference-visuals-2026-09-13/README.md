# 고속도로·휴게소 원본 이미지 기반 외형 개선

기준은 사용자가 지정한 `output/meshy_images/stage_02_1_highway_concept_batch_v1.png`와 `stage_03_3_rest_stop_concept_batch_v1.png`다. 두 원본, 수정 전 화면, 적용 후 실제 플레이 화면을 직접 열어 비교했다. 기존 씬을 재생성하지 않고 공식 Unity CLI/Pipeline의 `run_script`로 장식 배치와 씬 전용 재질을 수정했다.

## 외형 변경

- **HighWay:** 띄엄띄엄 놓였던 방음벽을 곡선에 따라 연결하고 초록색 하단 띠를 추가했다. 첫·두 번째 분기의 왼쪽 개구부는 비워 둔다. 수목과 여러 거리의 도심 건물, 과속 카메라 주변 소품을 추가했다.
- **RestStop 진입부:** 기존 주차장 도로를 유지하며 다섯 서비스 구역을 구성했다. 왼쪽 주유소·버스, 오른쪽 매점·자판기·충전기·야외 테이블, 초록색 시설 띠와 안내판을 배치했다. 기존 초반 장식 배치는 계층에 보존하고 일부를 비활성화했다.
- **RestStop 전 구역:** 코너 및 식당 공간을 비우고 포장 보도·경계석·화단을 연결했다. 주행로 표면을 아스팔트로 통일했다. 신규 건물과 수목은 기존 프로젝트 에셋을 사용했다.
- **식당:** 기존 내부 규모와 네 출입구를 유지하고 초록색 벽 상단·간판, 메뉴 보드, 화단과 돌 바닥 마감을 적용했다.
- **조명:** 기존 하늘 텍스처의 실제 Cubemap 임포트를 사용하고 낮 조명·안개를 조정했다. 신규 수목에는 기존 Unlit 아틀라스의 Lit 재질 복사본을 사용했다.

색·공간 구성과 배경 밀도를 개선한 결과다. 원본의 모든 건물 형태·주유기·소품·하늘·사진 같은 질감을 충실하게 재현한 결과라고 표현하지 않는다. 기존 매점의 경사진 지붕 등 원본과 다른 형태는 남아 있다.

## 보존과 실행 방법

- `before/`는 **이번 작업 직전** 두 씬, SR18, 원본 워크북, 서명된 런타임 아카이브와 저장값63개의 백업이다. 과거 작업의 백업을 사용하지 않았다.
- 장식 루트는 각 맵의 `Reference_Scenery_20260913`이다. 신규 장식에는 충돌체가 없다. 재질은 `Assets/ShooterSurvival/Models/Chapters/ReferenceScenery/`에 별도로 둔다.
- `tools/road-reference-visuals.cs`는 Assets 밖에서 공식 Pipeline이 컴파일·실행하는 도구다. `Prepare`, `ApplyHighway`, `ApplyRestStop`은 중복 적용을 거부한다. 이미 적용된 씬에 초기 작성 메서드를 다시 실행하지 않는다.
- 각 저장 전 경로·적·보너스·기믹·교통·방어전·플레이어 설정을 비교한다. `VerifySaved`는 Play Mode 종료/재로드 이후에도 같은 설정인지 확인한다.
- 외형 조정 메서드도 저장된 Edit Mode를 요구한다. Play Mode 변경을 씬에 저장하지 않는다.

## 검토에서 고친 사항

- 첫 하늘 적용은 PNG를 Texture2D로 잘못 읽어 회색으로 나왔다. 실제 타입인 Cubemap과 맞는 skybox 셰이더로 수정했다.
- 첫 수목은 너무 크고 Unlit 재질이 밝아 도심 배경을 가렸다. 크기·거리·재질 복사본을 수정했다.
- 주유소 띠가 지붕 안에 들어가 보이지 않았다. 실제 메시 깊이를 측정해 외부 면으로 옮겼다.
- 식당의 첫 밝은 체크무늬 바닥은 실제 전투 화면에서 과도한 대비를 만들었다. 돌 바닥으로 수정하고 `reststop-final-holdout`에서 전투와 화면을 다시 확인했다.

`tmp/image-previews/road-reference-visuals-2026-09-13/`에 수정 전, 실패 후보, 수정 후보와 최종 PNG를 보존한다.
