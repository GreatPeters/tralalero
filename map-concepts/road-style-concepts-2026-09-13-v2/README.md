# 수정 컨셉 v2 — 사람 3등신·양방향 2차선·기존 식당 시점

사용자의 2026-09-13 정정을 반영한 컨셉 이미지6장이다. **실제 Unity 씬에 적용한 화면이 아니다.** 이번에는 그림과 요구사항 기록만 수정했다.

## 반영한 정정

- 펭귄·동물형 적을 제거하고 인물을 모두 사람으로 표현했다. 이전2등신보다 몸통과 다리를 늘리는3등신 방향이다.
- 고속도로는 방향별2차선, 총4차선으로 표현했다. 노란색 이중 중앙선과 방향별 흰 점선1개로 구분했다. 요금소의 중복 유도선은 후속 편집에서 정리했다.
- 휴게소는 식당 입구를 지나 실제 실내로 들어가는 흐름이다. 실내에 천장·벽·식사 시설을 표현했다.
- 식당 내부와 방어 장면은 기존처럼 상어 뒤에서 앞으로 바라보는 시점이다. 탑뷰·지붕을 들어낸 조감도는 사용하지 않는다. 뒤쪽 출입구가 화면 밖에 있어도 카메라를 들어 올리지 않는다.
- 상어는 실내에서 제자리에 서고 사람 경찰이 접근한다. 방어 장면에는30초 버티기 표시를 넣고 실내 보너스 제단은 제외했다.
