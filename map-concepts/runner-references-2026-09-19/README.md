# 러닝 슈터 Bonus Wall 레퍼런스 조사

2026-09-19. 사용자: “1번과 2번 다 별로야. 차라리 3번이 나아. 혹시 레퍼런스 찾아볼 수 있어? 러닝 슈터? arrow a row 나 뭐 비슷한”.

가장 최근 맥락 수정 시안 1·2를 거절하고 3의 장소별 구성을 상대적으로 선호한 발언으로 이해했다. 3번 전체 구현 승인이나 보급품 흡수 설정 확정은 아니다.

## 조사 결과

추가 요청으로 [6종을 더 조사](MORE_REFERENCES.md)했다. 현재 외부 갤러리는 **10개 게임·21장**이며 신규 자료가 먼저 나온다. 아래는 최초 4종의 조사 기록이다.

### Arrow a Row — 주 레퍼런스

[개발자 Steam 페이지](https://store.steampowered.com/app/2495980/Arrow_a_Row/)는 자동 전진·자동 사격, 좌우 조작, 런 중 파워업, 동료와 영구 업그레이드를 명시한다.

공식 스크린샷 01에서 선택은 목제 기둥 사이의 배너 두 개로 표시된다. 02에서 획득한 수치 문구와 공격 구성이 보인다. 03은 장비·동료 보상 선택 패널이다. 정적인 화면이므로 효과 지속 시간·충돌 처리는 확인하지 않았다.

**디자인 해석:** 우리 게임과 구조적 유사성이 가장 높다. 선택의 의미와 좌우 영역을 먼저 읽게 하는 얇은 배너 구성을 참고한다. 게임의 모든 보너스에 새 물품의 물리적 출처를 붙일 필요는 없다.

### Weapon Craft Run — 강화 소재와 결과의 연결

[개발자 App Store 페이지](https://apps.apple.com/us/app/weapon-craft-run/id1672925980)는 장애물/문 사격, 탄창 수집, 총기 업그레이드와 진화를 설명한다. 공개 이미지에는 총기·탄창 형태와 더블/트리플 총기 표현이 등장한다.

**디자인 해석:** 보너스의 소재와 강화되는 대상을 한 계열로 묶고, 증가 결과를 발사/장비 모습으로 보여주는 접근을 참고한다. 스토어 홍보 이미지의 모든 상태를 직접 플레이로 검증한 것은 아니다.

### Gun Head Run — 읽기 쉬운 기호와 단순 형태

[개발자 App Store 페이지](https://apps.apple.com/us/app/gun-head-run/id1633171432). 공식 이미지에서 무기, 숫자가 큰 대상, Fire rate/Damage 게이트와 플러스/마이너스·색 구분이 보인다.

**디자인 해석:** 단순한 목표 실루엣, 아이콘, 짧은 효과명, 색을 참고한다. 숫자가 큰 적 대상과 보너스 수치를 구분해야 하며 화면의 모든 숫자를 획득량으로 읽지 않는다.

### Mob Control — 증가 결과의 시각화, 보조 참고

[개발자 App Store 페이지](https://apps.apple.com/us/app/mob-control/id1562817072)는 게이트로 군중을 증폭하는 타워 디펜스 액션으로 소개한다. 러너와 동일한 조작 구조로 분류하지 않는다. 공개 이미지에서 배율/증가량과 군중 변화가 가까이 놓인다.

**디자인 해석:** 숫자 변화가 눈에 보이는 결과로 이어지는 피드백만 참고한다. 군중 시스템이나 거대한 배율을 우리 게임에 적용하자는 제안은 아니다.

## 우리 게임에 대한 제안

3번의 장소별 배경 구성 + Arrow a Row의 간결한 좌우 선택 + Gun Head Run의 짧은 효과명/아이콘을 우선 검토한다.

배경 소품은 장소를 설명하고, 플레이 중 읽어야 하는 핵심은 아이콘·증가량·효과명으로 좁힌다. 항구의 목재, 고속도로의 도로표지 소재, 휴게소의 안내판 소재 같은 프레임 변주는 고려할 수 있으나 새 사용자 확정 요구가 아니다. 신발 흡수의 복잡한 서사를 추가하는 것보다 우선 보너스인지·무엇이 늘어나는지·어디로 이동할지를 읽게 한다.

구현 출발점은 기존 WallScript/보너스 선택 바인딩, 기존 아이콘과 TMP, 간단한 프레임 메시/스프라이트, 짧은 수치 팝업이다. 실제 프리팹 수정이나 새 이미지 시안 생성은 수행하지 않았다.

- 공개 이미지 17개를 보존했고, 직접 확인한 9개를 비교 갤러리에 선별했다.

- 실행 중 외부 브라우저 갤러리: 기존 loopback 갤러리 서버의 /references/ 경로. 이번 확인 URL은 http://127.0.0.1:6753/references/ 이다. 서버 재시작 시 server.json의 현재 주소를 확인한다.
- Chrome에서 선택 화면을 클릭해 확대하고 실제 표시를 스크린샷으로 확인했다.
- 이것은 공식 스토어 공개 이미지 조사다. 모바일 이미지에는 홍보 문구가 있으며 최신 버전을 직접 실행하거나 광고와 실제 동작의 동일성을 검증한 자료는 아니다.
- 이미지는 참고 열람용이며 게임 리소스에는 편입하지 않았다. 이미지 권리는 각 게임 권리자에게 있다.
