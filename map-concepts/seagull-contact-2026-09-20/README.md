# 갈매기 접촉 판정·회전·퍼센트 피해

갈매기에 닿으면 캐릭터가 두 바퀴 돌고 체력이 약 20% 감소하도록 요청받아 적용했다. 퍼센트 기준은 기존 쓰러진 가로등 기믹과 같은 **최대 체력**으로 선택하고 작업 중 사용자에게 알렸다.

## 수정

- 고정된 1.5m 큐브 대신 실제 Sitting/Fly 메시의 뼈별 정점을 표본화한 13개 트리거를 설치했다. 몸통과 날개 움직임을 따라가며, Rigidbody는 피해 소유자인 루트에만 둔다.
- 경고 그림자에는 접촉 피해가 없다. 실제 갈매기가 등장한 후 내려오기·착지·떠나기 동안 접촉 가능하다. 착지 프레임에 판정을 끄던 동작을 제거했다.
- 플레이어 루트 몸체 콜라이더만 받는다. 무기나 보이지 않는 자식 콜라이더의 접촉은 소비하지 않는다.
- 한 갈매기와 여러 부위가 겹쳐도 한 번만 `MaxHealth × value / 100`을 차감한다. 프리팹과 현재 배치의 value는 20이며, 엑셀 배치 데이터도 이미 20이라 워크북은 변경하지 않았다.
- 기존 `CosmeticHitSpin`으로 보이는 캐릭터만 1.2초 동안 720도 회전한다. 기름의 조작 감도 감소를 추가로 적용하지 않으며 경로·카메라 방향은 유지한다. 재시작 시 해당 회전을 초기화한다.
- 갈매기 경고·낙하·대기·퇴장과 애니메이션은 실행/일시정지 및 시뮬레이션 배율을 따른다. 새로 생성한 장애물의 최종 배치도 Start에서 같은 초기화 경로로 확인한다.

## 검증

| 실제 Play Mode 시나리오 | 체력 | 회전 | 피해 횟수 |
|---|---|---|---|
| 정상 속도로 갈매기와 접촉 | 500 → 400 | 720° | 1 |
| 옆으로 회피 | 500 → 500 | 0° | 0 |
| 내려온 뒤 착지 상태에서 접촉 | 500 → 400 | 720° | 1 |

세 시나리오 모두 플레이어의 경로 회전 변화는 0°였고, 보이지 않는 갈매기로부터 받은 피해는 없었다. 갈매기는 정상적으로 떠났다. `play-final/report.json`에 기록했고, 실제 게임 HUD에서도 `400 / 500`, `-100`과 피해 테두리를 확인했다.

- Edit Mode 15개 통과: SeagullContact 8, OilSteeringEffect 1, 갈매기 프리팹 callback ownership 1, CombatFeedbackRevision 5.
- 두 C# 프로젝트 빌드 및 agent harness 검증 성공. 기존 ithappy `SplineSpeed.m_LastIndex` 미할당 경고 외 오류 없음.
- 확인 영상은 갈매기와 플레이어의 실제 이동·물리 접촉이다. 갤러리의 영상은 근접 검증 카메라이고 `hit-hud.png`는 기존 Game View 합성 화면이다.
- 실제 휴대폰 또는 한 챕터 전체의 연속 클리어를 검증한 것은 아니다.

- `before/`: 작업 전 프리팹·SR18 사본. 이전 부적·적·배 변경은 보존했다.

첫 `play-v1` 검증의 임시 이동 잠금 객체에는 경찰 배열이 없어 남아 있던 무기 코루틴이 예외를 냈다. 이는 검증 장치 문제였으며, 최종 probe는 발사 코루틴을 중단하고 임시 배열을 초기화한 뒤 새 Play Mode에서 세 시나리오를 다시 완료했다. 실제 휴게소 코드는 변경하지 않았다.
