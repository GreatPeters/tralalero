## Asset decisions

- The source shark has **four weighted feet and27 bones**. The first three-foot assumption was rejected by the import audit.
- Paid shoes use four fitted copies in one skinned mesh and a corresponding closed body mesh. Body extensions follow each shoe opening; they preserve source weights and avoid tail/keel cuts. Models were checked in neutral front/rear views and actual walking.
- Static shop previews reset to bind pose and bake once per selection. The CPU preview worked where the manual static GPU skinning probe looked twisted; the underlying discrepancy was not isolated.
- The diver helmet uses a precisely cut, interpolated front aperture so the face remains visible. The circlet has a separately reviewed offset. All24 final item icons were rendered from actual assets.
- The hall's35k export showed roof tears. Its65k refinement uses the detailed source and that source's own textures, with a fresh Unity visual check. A50k restroom trial did not improve the wall slit and was rejected. Small source imperfections remain on distant scenery; these models are decorative, not collision meshes.
- The initial rest-stop plaza was too sparse. Services were moved toward parking, a landscaped rear garden and existing benches/tables were added, and the cafe was moved beside the road. The first scene/screenshots are retained.97 ground probes pass, all124 existing road-root transforms and125 encounter transforms are unchanged, and the decorative hierarchy adds no colliders. The sign's generated-X front was normalized to+Z before authoring.
- Production used the task's independent UV raster/interpolation implementation. The installed stock NVIDIA dependency has a non-commercial restriction, so the earlier stock-backend evaluation files are excluded from production imports. This is a dependency-specific correction, not blanket legal clearance for every upstream component.
