# 현재 맵에 배치된 Props를 기준으로 한 SR18 기획

상태: 원본 배치 분석은 유효하나, 18점포·저밀도 확장안은 사용자 피드백으로 철회했다. 최신 방향은 [417점포 고밀도 수산시장 시안](../sr18-dense-market-2026-09-05/README.md)이다. 원본 Unity 씬에 미적용.
기준 자료: 2026-09-05 열린 `Noryangjin_MapTool_Mode`의 실제 배치 인스턴스. SR18 자체의 Props에는 회전 스팟 15개만 있으므로, 현재 화면에서 보이는 기존 시장 배치를 맵1에서 조사했다.

| --- | ---: | --- |
| Props 전체 | 530 | 아래 배경·소품·스팟 포함 |
| 물 타일 | 454 | 바다 면적을 채우는 배경 |
| 회색 시장 지면 | 33 | 길 옆으로 연결되는 넓은 안벽과 마당 |

## 배치 기획의 기준

1. 점포별 돌출 받침을 만들지 않는다. 현재의 회색 지면을 이어 시장 안벽부터 구성한다.
2. 가판을 길 전체에 같은 간격으로 반복하지 않는다. 현재처럼 3개 또는 6개의 점포가 모인 구간과 긴 빈 안벽을 번갈아 둔다.
3. 실제 배치된 점포 묶음을 복사·회전한 후 필요한 한쪽을 덜어내는 방식으로 변주한다. 프리팹 원본의 크기나 회전으로 되돌리지 않는다.
4. 어선은 현재 배치된 큰 어선의 크기와 수면 높이를 참고한다. 작은 배 수십 척을 같은 간격으로 늘어놓지 않는다.
5. 갈매기·닻·구명부표는 부두의 맥락을 만드는 소수 강조점으로 쓴다. 지금 배치에 없는 개별 수조·상자 행렬을 핵심 배치로 추가하지 않는다.
6. 바다·회색 지면은 면적과 접합으로 계획한다. Props 530개라는 총수를 길 비율로 단순 증식하지 않는다.
7. 시작 제단·개조업자는 현재 시작 구역에 유지한다. 중간 구역마다 새로운 부활 제단을 만들지 않는다.
8. 현재 배치에 없는 거대 생선 건물, 크레인, 냉동창고, 등대 모델을 제작된 에셋처럼 전제하지 않는다.

## 추천안: 10번의 구역 진행

| 위치 | 제안 배치 | 기대 장면 |
| --- | --- | --- |
| 기존 51개 길 | 현재 회색 안벽·6점포·어선·갈매기·배경 유지 | 익숙한 시작 시장 |
| SR18 첫 긴 남하 구간 | 안쪽 회색 안벽을 길게 연결하고, 중앙에 현재와 같은 양측 6점포 구간 1곳 | 시장이 한 번 더 확장된 느낌, 전후로 넓은 작업 여백 |
| 아래쪽 큰 루프의 서쪽 진행 구간 | 한쪽 3점포와 짧은 회색 안벽, 물가의 어선 | 시장에서 포구로 전환 |
| 중간 동쪽/북쪽 진행 구간 | 한쪽 3점포 구간 1곳, 앞뒤는 비움 | 멀리 도달했을 때 만나는 작은 영업 구역 |
| 후반 고리·북쪽 출구 | 점포 밀도 낮춤, 어선·갈매기와 신호대 중심 | 넓은 방파제와 다음 스테이지 예고 |

첫 배치 예산은 기존 점포 6 + 신규 6 + 3 + 3 = **전체 18점포**다. 확정 수량이 아니라 현재 맵의 밀도를 과도하게 키우지 않는 검토용 출발점이다. 큰 루프의 빈 내부는 바다와 정박 시야로 두고, 실물 배치 후 카메라에서 너무 비는 구역만 조정한다.

## 이미지와 실제 적용의 경계

- 미리보기는 현재 인스턴스의 모델·스케일·회전·자식 구성을 유지한다. 점포 묶음의 기준점과 진행 방향만 옮긴다.
- 원본의 물 타일 454개는 같은 물 모델·재질을 넓힌 배경 표현으로 대체해 렌더링했다. 실제 적용 시 타일/면적 예산을 결정한다.
- 식별을 위해 미리보기의 외곽선만 숨겼다. 원본 재질은 수정하지 않는다.
- 원본 씬을 저장하지 않았으며 맵1의 clean 상태와 SR18의 기존 dirty 상태를 그대로 유지했다.
- 실제 적용 전에 지면 접합, 점포의 반대편 길 침범, 입체 교차 시야, 소품 충돌을 별도로 확인한다. 그림의 배치는 공간 기획이며 검증 완료된 런타임 배치가 아니다.
- 생성 근거: `tools/render-sr18-authored-cluster-concepts.cs`. 신규 배치 기록의 `sourceInstance`가 기존 맵의 어떤 배치를 참조했는지 보여준다.
