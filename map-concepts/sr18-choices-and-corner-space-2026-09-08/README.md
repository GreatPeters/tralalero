# SR18 좌우 선택과 코너 대응 공간

2026-09-08 요청, 2026-09-09 적용·검증. 현재 SR18 씬에 저장했다. 이전 단일 BonusWall 배치를 대체하며 적 처치 드롭은 사용자의 선택대로 유지했다.

## 좌우 보너스

- 고정 보너스 25지점에 좌우 두 개씩, 총 50개를 배치했다. 획득 기회는 25번으로 동일하다.
- 기존 모델을 75% 크기(스케일 2.25), 중심에서 좌우 1.9유닛에 배치했다. 기존 길을 넓히거나 새 모델을 만들지 않았다.
- 양쪽은 서로 다른 효과를 추첨한다. 중앙 통과는 자동 선택하지 않으며 왼쪽/오른쪽으로 이동해 고른다.
- `BonusWallChoicePair`가 효과 적용 전에 선택을 확정하고 반대쪽을 닫는다. 같은 프레임에 반대쪽 충돌 콜백이 도착해도 추가 보상이 없다.
- 기존 엑셀 `보너스 배치` 25행을 유지한다. 기존 이름을 가진 왼쪽 배치ID가 한 쌍을 대표하며 등급과 사용 여부를 두 제단에 함께 적용한다. `_Right`에 중복 행을 추가하지 않는다.
- 새 Play 준비 시 두 제단과 선택 상태를 초기화한다. 처치 드롭의 단일 제단·스케일 3·드롭 개수는 변경하지 않았다.

## 코너 이후

- 적의 시작점/이동 목표는 코너로부터 최소 28유닛, 발동 스팟 중심은 최소 20유닛 뒤다. 현재 속도 8에서 각각 약 3.5초/2.5초 이동 거리이며 실제 충돌은 콜라이더 반경만큼 먼저 발생한다.
- 코너 직후 기믹도 중심 기준 16유닛 이상 뒤로 옮겼다.
- 뒤로 밀린 지점과 다음 지점 사이에는 경로 거리 24유닛 이상의 간격을 확보했다. 적 9곳·보너스 5지점·기믹 7곳을 재배치했다.
- `EnemyCornerClearance`는 엑셀 발동앞거리를 다시 읽어도 스팟이 코너 앞으로 돌아가지 않게 제한한다. 이동 범위가 적 대응 공간을 침범하면 적용 전 거부한다.
- 사용자 지정 고가 보너스 161/177/269 식별 슬롯의 중심 X는 유지했다. 도로 230개, 기존 소품 666개, 점포/안벽 306쌍과 회전·경사 스팟은 보존했다.

4초 조우는 기존 거리 환산 기준이다. 이번에는 코너 대응 공간을 우선해 일부 현지 간격이 달라졌으므로 식별 슬롯 이름을 실제 통과 시각으로 해석하지 않는다. 전체 5분 난이도 완주는 별도다.

## 검증과 화면

- 자동 검사: 선택/초기화/드롭 유지, 방향별 코너 안전거리, 엑셀·적 이벤트·SR18 기하와 체력 재로딩.
- 실제 Play: 25쌍 모두 좌/우 레인 각각만 충돌하고 중앙 레인은 두 제단 모두와 겹치지 않았다(좌우 50개 판정). 서로 다른 효과도 확인했다.
- 실제 `WallScript` 충돌 처리에 결정적인 +1 공격력 테스트값을 넣어 좌/우 두 경로 모두 보상이 정확히 한 번만 적용되는지 검사한 후 값을 복원했다. 전체 경로를 물리적으로 완주한 검사는 아니다.
