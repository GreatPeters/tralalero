# SR18 전투·보너스 보완 — 2026-09-09

현재 `map2`의 `Noryangjin_MapTool_Mode_SR18`에 적용했다. 길 230개, 기존 상점/부두/장식 666개, 조우 지점 74곳은 유지한다. 새 모델은 만들지 않았다.

## 적용

- 매복 5명: 원거리 길 가장자리에서 보이는 상태로 대기, Walk 3유닛/초로 중앙 진입 후 .8초 준비 사격. 앞거리 44(코너 뒤 20유닛 제한 우선), 진입 전방 8·측면 1.6. 짧은 E05/E24는 전방 4로 줄여 반응 시간을 확보했다.
- 적 시선: 실제 플레이어 XZ 위치를 계속 추적. 배치용 180도 회전과 메시 정면을 분리하여 반대로 바라보는 문제를 수정했다.
- 고정 보너스 25쌍/50개: 폭 2.25·좌우 중심 ±1.9 유지, 높이/깊이 2.9로 약 29% 확대. 더 넓히면 일부 구간에서 경계를 넘으므로 폭은 유지했다. 처치 드롭은 단일 제단 그대로다.
- 바구니: 기존 9곳을 3개씩 총 27개로 변경, 스케일 50→70(+40%). 같은 옆 차선에 길 방향 2.5유닛 간격으로 놓아 반대쪽 회피 통로를 남겼다. 한 엑셀 행이 묶음 전체를 제어한다.
- 중복 바구니의 사격 금지를 소유자별로 관리하고 비활성/초기화 시 해제한다. 키네마틱 바디 속도 설정 경고도 제거했다.
- BoomBar/TungTung: GameManager가 없는 맵에서 노량진의 기존 프리팹 소환기를 사용. 없는 무기를 목록에 추가하지 않고, 실제 생성 성공 시만 개수를 올린다. BoomBar는 현재 도로 높이 +2로 추종한다.
- TungTung: 자신의 코너 진행 순서로 길을 따라 전진한다. 플레이어 회전 스팟은 소모하지 않고, 물 위로 적을 직선 추격하지 않는다. 도로 높이와 작은 나무판 틈을 처리한다.
- `적 배치` M:P에 타입·공격력·체력·증가율 추가. 이 수치가 SR18 전투의 최종 기준이다. Normal은 약 30% 순차 성장, Elite/Boss는 동구간 Normal 배수로 초기화했다. [엑셀 사용법](../../docs/noryangjin-encounter-workbook.md).
