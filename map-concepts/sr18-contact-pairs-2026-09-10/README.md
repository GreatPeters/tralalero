4. **Bonus Wall 공통2초 제한:** 고정 선택 제단과 처치 드롭 모두 마지막 성공 획득부터 `Time.time` 기준2초 미만이면 다음 획득을 막는다. 차단된 쌍을 선택 처리하거나 없애지 않는다. 정확히2초부터 허용하며 새 플레이어/재시작은 즉시 획득 가능하다. 동일 쌍의 두 번째 선택은 기존 쌍 소유권 규칙으로 계속 금지된다.
