# SR18 고밀도 수산시장 기획

상태: **철회된 이전 배치 — 현재 씬과 다름.** 2026-09-05 적용 후 사용자가 나무 길을 덮고 별도 시장 골목을 만든 문제를 지적했다. 아래는 당시 기록이며, 현재는 [기존 길 중심 306점포 배치](../sr18-roadside-market-2026-09-05/README.md)로 교체했다.

사용자 방향: 상점이 아주 많아야 한다. 기존 맵은 모델·크기·정면 방향·회색 안벽 구성의 참고이며, 기존 점포 6개를 밀도의 상한으로 해석하지 않는다. 이전 18점포·빈 부두 중심안은 철회한다.

## 적용한 밀도

**총 417개 점포 = 기존 6개 + 추가 411개**다. 현재 맵에 이미 배치된 수산상점·횟집가판·해산물가판 세 종류만 복제했다.

| 배치 | 추가 점포 | 구성 |
| --- | ---: | --- |
| 길 양옆 연속 상가 | 295 | 평지 직선에서 약 12.1m마다 양쪽 점포. 현재 점포 길이에 가까운 촘촘한 간격 |
| 큰 하단 루프 내부 | 100 | 마주 보는 두 줄씩 세 묶음, 총 여섯 줄의 시장 블록 |
| 기존 상단 회색 마당 | 4 | 기존 빈 지면에 점포 추가 |
| 후반 작은 고리 내부 | 12 | 마지막 고리도 상가 구역으로 채움 |

회색 바닥도 길 양옆과 내부 블록 아래로 이어 배치했다. 시안의 신규 지면 후보 351개 중 중복 3개를 제외하고 점포 발밑 보강 2개를 추가했다. 기존 33개를 포함한 최종 지면은 **383개**다. 차양 끝은 원본처럼 안벽 밖으로 돌출될 수 있으며, 건물 발밑을 기준으로 지면 지지를 검사했다.

## 공간 방향

- 맵의 주인공은 연속된 수산시장이다. 빈 바다·부두는 회전과 경사·입체 교차를 읽기 위한 국소적인 공간으로 제한한다.
- 큰 루프는 내부까지 시장으로 채워 조감도에서 큰 빈 사각형처럼 보이지 않게 한다.
- 원본의 양쪽 점포가 길을 바라보는 방향을 유지한다. 상점 뒤를 주행로 쪽으로 돌려 놓지 않는다.
- 세 점포 유형을 번갈아 사용해 높은 밀도를 유지하면서 진열물·차양·외형의 반복을 완화한다.
- 주행로 중심의 폭 약 5.4m 영역과 다른 점포의 바운딩 박스를 침범하는 후보 35개를 제외했다. 실제 플레이 충돌·카메라 가림 검증을 대신하는 결과는 아니다.
- 내부 시장 골목은 배경 배치이며 새로운 플레이어 분기 경로나 체크포인트를 만들지 않는다.

## 근거와 상태

- [점포별 원본 인스턴스와 실제 Transform](placements.json)
- [저장된 전체 배치 기록](applied-layout.json): 기존 장식 복사본, 신규 점포·지면과 물의 프리팹 경로 및 Transform.
- 시안 스크립트: `tools/render-sr18-dense-market-concept.cs`; 적용 스크립트: `tools/apply-sr18-dense-market.cs`. 적용 스크립트는 길 전용 기준선에서만 실행 가능하며 이미 채워진 씬을 덮어쓰지 않는다.
- 모델·텍스처·스케일과 프리팹 연결·원본 인스턴스 오버라이드를 보존했다. 신규 모델은 만들지 않았다. 맵툴에서 각 배치물을 계속 선택·복사·이동할 수 있다.
- 시안의 외곽선 없는 표현을 저장하기 위해 `Assets/ShooterSurvival/Materials/Generated/SR18DenseMarket/`에 씬 전용 재질 13개를 만들었다. 원본 공유 재질과 프리팹은 수정하지 않았다.
- 물은 기존 물 프리팹과 최적화 메시를 재사용한 `Water/Background_Water` 1개이며, 범위는 920×1050이다.
- 최종 수량: 도로 230개, 점포 417개, 지면 383개, 물 1개. `Props` 직접 자식 846개에는 점포·지면·기존 장식과 회전 스팟 15개가 포함된다. Enemies와 Bonuses는 비어 있다.
- 적용 전 SR18의 미저장 작업까지 `tmp/backups/sr18-before-dense-20260905-074735.unity.tmp`에 복구용으로 보관했다. 백업 복구가 필요하면 별도 `.unity` 파일로 복사해 먼저 확인한다.
