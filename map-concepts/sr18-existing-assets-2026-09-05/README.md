# SR18 실제 보유 에셋 배치 10안

상태: 보관용 팔레트 실험. 현재 맵에 이미 배치된 Props의 크기·조합·회색 안벽을 제대로 계승하지 못해 기준에서 제외한다. 최신 기획은 [현재 맵의 실제 배치 기준안](../sr18-authored-props-2026-09-05/README.md)이다.

PNG는 Unity에 존재하는 프리팹을 임시 PreviewScene에 복제·배치해 직접 렌더링했다. 생성형 이미지 모델을 사용하지 않았다. 현재 도로 230개를 복사한 비교용 장면이며 원본 씬을 수정하거나 저장하지 않았다. 작업 시작 당시 SR18의 미저장 상태도 유지했다.

그림은 **왼쪽 전체 맵 / 오른쪽 위 구간 확대 / 오른쪽 아래 가까운 시점**이다. 배치 비교용 단색 배경을 사용하며, 먼 거리에서 검게 뭉치는 외곽선만 미리보기 인스턴스의 MaterialPropertyBlock에서 숨겼다. 모델·텍스처·원본 재질은 수정하지 않았고, 측면 받침도 기존 부두 길 모델을 재사용한다.

## 실제 에셋 조합

- 건물/가판: 014 수산상점, 015 횟집가판, 016 해산물가판, 043 시장차양.
- 하역: 001 파란상자, 002 스티로박스, 020 상자더미, 022 얼음박스, 032 주황상자, 033 흰상자, 004 수산물수레.
- 진열: 003 얼음수조, 021 수족관줄, 030 게 수족관, 031 문어 수족관.
- 항구: 018 항구어선, 034 그물더미, 035 닻소품, 024 구명부표, 025 타이어완충, 037 바다부표, 042 어선소품.
- 표식/배경: 007 시장간판, 027 빨간등, 028 게간판, 029 생선간판, 019 언덕마을.

번호는 프리팹 파일명의 앞 세 자리다. 전체 경로·크기는 [조사 목록](asset-inventory.json), 각 안의 프리팹 경로와 Transform은 [배치 목록](placements-reviewed.json)에 있다. 조사 목록에는 사용하지 않은 후보도 포함된다. 팔레트에서 제외된 026 금속계선주는 배치에 사용하지 않았다.

## 추천

10번처럼 구역마다 비중을 바꾸고, 초반에는 01/02, 중반에는 04/05, 후반에는 06을 조합하는 방식이 현실적이다. 같은 가판을 전체 길에 동일한 간격으로 반복하기보다 상점 군집과 빈 부두를 번갈아 배치한다. 어선 여러 척·간판·조명 군집으로 장소를 구별한다.

실제 적용 단계에서는 플레이 카메라 가림, 소품 간 충돌, 물 높이와 배경 경계를 점검한다. 이번 배치 비교 이미지에서는 소품의 콜라이더·동작 스크립트가 비활성화된다. 측면 받침은 배경용 데크이며 230개 주행 경로의 새 갈래길로 세지 않는다.

## 재현

`tools/render-sr18-existing-asset-concepts.cs`를 Unity Pipeline `eval_file`로 실행한다. 이미 PNG가 있으면 덮어쓰지 않고 중단한다. 새 폴더에서 재렌더링하려면 스크립트 상단 출력 폴더를 변경한다. 실제 프로젝트 씬에 적용하는 명령은 아니다.
