# 5초 리듬 배치 그림 예시

**사용자 정정으로 현재 맵 적용안에서 제외:** 이 그림은 통로를 넓히고 적·BonusWall을 옆으로 늘어놓았다. 현재 맵은 적 한 마리 폭이며 각 요소 사이에 충분한 앞뒤 간격이 필요하다. 수정된 위치·폭 예시는 `map-concepts/sr18-single-file-examples-2026-09-06/README.md`를 따른다.

기본 제공 이미지 생성 도구로 만든 구간별 컨셉이다. 실제 전체 SR18 맵을 재설계하거나 씬에 적용하지 않는다. 기존 게임의 나무길·상점·캐릭터·BonusWall 이미지와 맵툴 기믹 목록을 참고했다.

각 그림은 15초 목표 구간에 전투 3회, 고정 보너스 선택 3회, 기믹 판단 3회를 넣는 예시다. 0/5/10초 전투, 2/7/12초 선택, 4/9/14초 기믹으로 시간을 엇갈린다. 실제 이동·전투 시간을 측정한 도면은 아니며 표시 개체 수와 간격은 생성 일러스트의 근사다.

- 기본형: 전투 → 선택 → 구멍/기름/조명.
- 선택형: 기존 한 길 안의 좌우 이동과 다음 기믹을 미리 보는 선택. 새 갈래길이나 강제 1택 시스템을 뜻하지 않는다.
- 압박형: 중후반용 두 무리 전투와 조명/갈매기/구멍.

적 처치마다 발생하는 BonusWall 규칙은 유지/변경 여부가 아직 미결이다. 그림에는 고정 선택만 나타내며, 처치 드롭을 생략해 그린 것이 규칙 삭제를 의미하지 않는다. 현재 적용된 69명/14벽 씬은 변경하지 않았다.
