# SR18 초반 기믹 개선 — 2026-09-10

후속 요청으로 [기믹 전봇대의 고정 피해, 뚱보 중앙 진입, 좌우 Normal 군집, 보너스2초 제한](../sr18-contact-pairs-2026-09-10/README.md)을 적용했다. 아래 사격으로 가로등을 무해하게 만드는 동작은 SR18의 기믹8개에서 대체됐다. 초반 양동이·구멍·HUD 개선은 유지한다.

[플레이 검토](../sr18-pattern-playtest-2026-09-10/README.md) 뒤 사용자의 개선 요청을 받아 `map2`의 기존 작업 위에 적용했다. 원본 길230개·Props715개·적25명·고정 보너스25쌍·기믹24지점/42파트와 Excel74행은 유지한다.

기믹 종류를 추가하거나 모든 지점의 순서를 바꾸지 않았다. 기존 적→보너스→기믹의 큰 배치 틀 안에서 초반 물체의 좌우 위치, 묶음 길이, 선택 후 대응이 달라진다. 그룹 중심의 타임스탬프 이름은 기존 Excel ID이므로 실제 접촉 시각으로 해석하지 않는다. 첫 양동이는 무전투 학습 구간으로 남기고 뒤 묶음에서 전투와 결합한다.

## 결함 수정

- `ObstacleStats`의 Light는 총알을 맞으면 즉시 충돌을 끄고, 이미 큐에 들어간 플레이어 접촉도 `_lampFallen`으로 차단한다. 넘어짐 Tween에 실제 Transform을 지정하여 비활성/리셋 때 중단한다. 다시 시작하면 원래 켜져 있던 Collider만 복원하며 원래 꺼져 있던 Collider는 켜지지 않는다. **이 동작은 SR18 전용 토글이 아닌 공통 Light 규칙**이다. 서 있는 가로등의 접촉 피해는 유지한다.
- `PlayerStatusHud.SetHealth`가 수평 Filled 설정을 보장한다. SR18의 잘못된 Sliced 설정도 씬에서 수정했고, 채움 부분에는 작은 흰색 Sprite를 사용해 기존9분할 이미지의 끝부분이 길게 늘어나는 현상을 없앴다. 숫자/최대 체력 계산은 유지한다.
- 기존 장식 가로등4개, 카메라 가림/복원, 탄환 풀 반납, 출구 STAGE CLEAR/PLAY AGAIN은 유지한다. 고속도로 전환은 추가하지 않았다.

## 검토에서 보정한 부분

초안의 양동이 간격8은 기본 전진속도8에서1초였다. 좌우 입력15·민감도1/125·이동 보간25를 적용한 키보드 상당 이동은 초당 약3유닛이어서, 가장자리 사이를 움직일 때 실제 충돌 여유가 부족했다. **중심 간격12, 1.5초로 넓혔다.** 물체의 개수와 정적인 빈 차선만으로 조작 가능성을 판단하지 않는다.

초안의 보너스→구멍 간격16은 실제 화면에서 구멍 일부가 제단 숫자판에 가렸다. 접근 간격을 늘리고 양쪽 제단이 판자 이음새를 피하면서 같은 상부 데크에 지지되는 위치를 검사해25로 확정했다. 첫 적용 기록은 `applied-first-pass.json`, 현재 값은 `applied.json`이다.
