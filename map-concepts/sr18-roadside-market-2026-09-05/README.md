# SR18 기존 나무 길 중심 상점 배치

상태: 2026-09-05 사용자 지적을 반영해 **실제 SR18 씬에 적용·저장 완료**.

아래 표는 상점 배치 당시 수량이다. 이후 [경사 스팟 8개](../sr18-slope-spots-2026-09-05/README.md)를 추가해 현재 Props 직접 자식은 666개이며, 상점·안벽 수는 그대로다.

## 수정한 기준

이전 417점포 배치는 회색 바닥으로 길을 덮고 큰 루프 내부에 별도의 시장 골목을 만들었다. 상점 수와 지면 지지 검사는 통과했지만 사용자가 지정한 기존 나무 길을 중심으로 한다는 조건을 만족하지 못했다. 해당 배치는 철회한다.

- 기존 도로 230개와 회전 스팟 15개의 Transform·메시·연결을 변경하지 않는다.
- 기존 길의 실제 Renderer 경계를 읽어 평지 직선 구간을 찾고, 그 바깥 양옆에만 상점을 배치한다. 피벗을 길 중심으로 가정하거나 별도 내부 길을 만들지 않는다.
- 기존 맵의 상점 모델 3종과 인스턴스 크기·정면 방향을 재사용한다. 약 12.1 간격으로 주행로를 바라보게 배치한다.
- 회색 지면은 상점 바로 아래의 폭 9 × 길이 12.2 안벽으로 제한한다. 나무 길 전체 경계와 겹치는 점포·지면 후보는 제외한다. 상점 차양까지 지면이 받치도록 한다.
- 코너와 고가·경사·입체 교차 주변은 비워 기존 경로가 읽히게 한다. 큰 루프 내부의 임의 시장 블록은 만들지 않는다.

## 재현과 검증

- 스크립트: `tools/rebuild-sr18-roadside-market.cs`. 초기 417점포 배치와 원본 3종 인스턴스가 있는 상태에서만 사용한다. 기본값은 미리보기이며, 적용 기록이 있으면 재적용을 거절한다. 정상 맵툴 편집을 위한 상시 재생성 명령이 아니다.
- [최종 배치 기록](applied-layout.json): 612개 점포·안벽의 프리팹, Transform과 기준 도로 이름.
- 이전 배치에서 도로 전체 외곽과 평면상 겹친 지면 252개를 확인했다. 새 배치는 점포·지면 모두 도로 경계와 겹침 0개다.
- `Sr18Market_LeavesTheExistingTimberRoadsVisible`는 수정 전 실패했고 수정 후 통과했다. 도로 침범과 기존 길에서 떨어진 배치를 별도로 검사한다.
- `NoryangjinSr18SceneTests`: **5/5 통과**. 기존 24,702개 도로 표면 표본과 원본 보호 검사도 유지한다.
- `dotnet build Assembly-CSharp-Editor.csproj -nologo`: 통과 (증분 빌드 오류 0, 경고 0).
- 실기기 성능과 고가 높이 추종은 이번 정적 배치 수정 범위 밖이다. Build Settings 제외 상태를 유지한다.
