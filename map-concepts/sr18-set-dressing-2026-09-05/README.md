# SR18 건물·소품 배치 콘셉트 10안

상태: 보관용 상상 시안. 현재 보유 에셋으로 제작한다는 조건을 충족하지 못하므로 실행 기획으로 사용하지 않는다. 현재 기준은 [실제 보유 에셋 배치 10안](../sr18-existing-assets-2026-09-05/README.md)이다.

기준: 2026-09-05 수정된 230개 도로의 SR18 등대 인피니티. 기존 길과 교차 구조를 기준으로 건물 군집, 빈 공간, 소품 묶음과 분위기를 비교한다. 생성 그림은 배치 방향을 보는 콘셉트이며 정확한 경계·충돌·수량은 Unity 배치 단계에서 확정한다.

공통 배치 원칙:

- 시작 제단과 불법 신발 개조업자는 서로 가까운 한 묶음으로 읽히게 배치.
- 큰 루프 안쪽은 대표 랜드마크/건물 군집, 바깥은 항구 배경과 시야 확보에 사용.
- 기존 짧은 구간은 시장 밀도, 중반은 물류/작업장, 등대 고리는 개방감, 마지막 북쪽 출구는 고속도로 예고.
- 회전 직전·직후와 교차 하부를 가리는 건물은 피하고, 소품은 3~5개씩 활동 단위로 묶음.
- 중앙 주행 영역을 확보하고 랜드마크는 한 직선 전부터 보이게 구성.

| 번호 | 안 | 건물/공간 배치 | 소품 묶음 |
| --- | --- | --- | --- |
| 01 | 생활형 수산시장 | 큰 사각 루프 안쪽에 도매시장 블록, 기존 진입부에 점포, 등대 고리는 개방형 | 파란 상자·스티로폼 박스·수조·손수레·그물 |
| 02 | 수직으로 쌓인 시장 | 큰 루프 내부를 층층이 쌓은 시장으로 채우고 재통과 지점에서 아래 동네를 조망 | 옥상 물탱크·건조대·전선·붉은 조명·간판 |
| 03 | 냉동 물류항 | 대형 냉동창고 3개와 적재 야드, 컨테이너 벽으로 구역을 또렷하게 구분 | 팔레트·냉동 컨테이너·지게차·아이스박스·안전 볼라드 |
| 04 | 알록달록 수상 어촌 | 큰 루프 내부에 작은 수상 마을 군집 3개, 사이사이에 물길과 정박지 확보 | 부표·빨랫줄·작은 어선·생선 건조대·바구니 |
| 05 | 거대 어선 조선소 | 큰 루프의 중심에 수리 중인 대형 어선 1척, 주변을 작업장·크레인으로 구성 | 닻·윈치·프로펠러·용접 가림막·로프 릴 |
| 06 | 네온 수산 야시장 | 초중반 점포 밀집 + 수조 조명, 후반 등대는 밝고 비워 대비 | 발광 수조·생선 네온 간판·우산·포장마차·발전기 |
| 07 | 폭풍 뒤의 폐항구 | 침수된 시장·폐창고를 큰 루프 안에 모으고 후반은 텅 빈 방파제로 전환 | 모래주머니·방수포·표류 상자·구명환·녹슨 손수레 |
| 08 | 항구 축제 | 큰 루프 내부를 축제 광장으로, 중간 고리는 음식점 구역으로 분리 | 물고기 풍선·천막·등줄·가판·배럴 의자 |
| 09 | 신성한 물때 시장 | 큰 루프 중앙은 조수지, 둘레에 낮은 시장 회랑, 등대는 신성한 목적지 | 유리 부표·조개 제물·리본·풍화 간판·그물 |
| 10 | 거대 생선의 시장 | 큰 루프 안에 거대 생선 모양 시장 1개, 중간은 통조림 창고, 등대는 구명튜브 섬 | 게 크레인·거대 생선 상자·문어 간판·신발 모양 개조점 |

현재 프로젝트에서 확인한 재사용 후보: 수산시장 점포 외벽, 횟집 점포, 수산물 판매대, 차양, 파란 생선 상자, 흰 스티로폼 박스, 얼음 상자, 수조, 그물, 닻, 부표, 구명환, 어선, 마을 배경. 대형 창고·조선소·축제·초현실 랜드마크는 콘셉트 추가 제작 후보다.
