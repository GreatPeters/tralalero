# SR18 한 마리 폭 · 앞뒤 분리 배치 예시

후속: 이 세 예시와 앞뒤 남은 길을 포함한 [16구간 전체 위치도·확대도](../sr18-all-single-file-sections-2026-09-06/README.md)가 추가되었다. 실제 씬은 변경하지 않았다.

사용자 정정: 현재 길은 적 한 마리 폭이다. 적 여러 명이나 BonusWall 두 개를 옆으로 놓는 넓은 길 예시는 맞지 않는다. 적·BonusWall·오브젝트는 서로 충분히 떨어진 별도 지점에 둔다.

기존 그림처럼 맵 형태가 변형되지 않도록 생성형 일러스트 대신 실제 경로 좌표로 새 캔버스에 그린 도식이다. `full-flow-final.json`의 16구간 경로와 `sr18-roadside-market-2026-09-05/applied-layout.json`의 상점·안벽 위치를 사용했다. 원본 이미지나 Unity 씬을 편집하지 않았다.

## 그림

- [01 큰 루프 하행](../../tmp/image-previews/sr18-single-file-examples-2026-09-06/final/01-loop-down.png): 적 → 빈 길 → BonusWall → 빈 길 → 오브젝트.
- [02 큰 루프 북행](../../tmp/image-previews/sr18-single-file-examples-2026-09-06/final/02-loop-up.png): 오브젝트 → 빈 길 → 적 → 빈 길 → BonusWall.
- [03 마지막 직선](../../tmp/image-previews/sr18-single-file-examples-2026-09-06/final/03-final-straight.png): BonusWall → 빈 길 → 적 → 빈 길 → 오브젝트.

각 장 왼쪽에 같은 전체 맵과 예시 위치, 오른쪽에 같은 구간을 비례 확대했다. 한 횡단면에는 표식 하나만 둔다. 표시 중심 간격은 예시별 64~70 월드 유닛이고, 실제 전투 시간이나 확정된 5분 시간표는 아니다. 최신 요구의 폭·충분한 앞뒤 간격을 우선한 세 대표 구간이며 전체 적 수나 5초마다 각 종류가 나온다는 안을 확정하지 않는다.

표식은 적·벽·오브젝트의 위치를 나타내는 기호다. 파란 오브젝트 기호는 새 상자 모델이나 신규 파괴 기능을 뜻하지 않는다. 상점 외형과 다리 표현은 간략화했고, 경로 연결·좌표는 유지했다.

재현: `py -3.11 -X utf8 tools/draw_sr18_single_file_examples.py`. 기존 파일은 덮어쓰지 않는다. 도면상의 한 마리 폭, 단일 배치, 세 이벤트의 종류·간격을 코드에서 검사하고 완성 PNG를 육안 확인한다.

현재 적용된 69명/14벽 씬은 이번 그림 요청으로 변경하지 않았다. 실제 적용은 별도 확인이 필요하다. 앞선 넓은 통로의 `sr18-five-second-rhythm-examples-2026-09-06` 그림은 이 폭 조건에 맞지 않는 과거 참고다.
