# SR18 경사 스팟과 실제 높이 추종

상태: 2026-09-05 구현·씬 저장·두 고가 구간 Play Mode 검증 완료.

## 동작

- 기존 수평 코너 15개는 그대로 멈춘 뒤 회전한다.
- 경사 시작·끝에 스팟 8개를 추가했다. `이동 유지 (경사)` 모드에서는 전진·좌우 입력을 멈추지 않고 X 자세를 0.25초 동안 전환한다.
- 오르막 목표 X는 −19.573°, 내리막은 +19.573°, 평지 복귀는 0°다. 목표 Y는 해당 길의 진입 방향(90° 또는 270°)이며 잘못된 방향에서 들어오면 작동하지 않는다.
- SR18 플레이어의 `NoryangjinRoadHeightFollower`만 실제 `Roads` MeshCollider 표면 높이를 따른다. 발 높이 여유는 0.12이며 현재 높이 주변 ±0.75 범위만 읽어 상·하부 교차에서 다른 데크로 튀지 않는다.
- 작은 판자 틈에서는 진행 방향 ±0.06을 추가로 확인한다. 지지면을 찾지 못하면 기존 높이를 유지한다. 도로 외의 상점·물·소품은 높이 계산에 사용하지 않는다.
- 현재 카메라는 캐릭터의 자식이므로 높이와 자세를 함께 따른다. 카메라 오프셋이나 공용 카메라 코드는 변경하지 않았다.
- 수평 이동 속도, 기존 정지 회전, 원본 맵1·맵2, 도로·상점·재질은 유지했다.

## 8개 스팟

| 번호 | 경계 | Y | 목표 X |
| --- | --- | ---: | ---: |
| 01 | 70번 오르막 진입 | 0 | −19.573° |
| 02 | 73번 상부 평지 진입 | 12 | 0° |
| 03 | 87번 내리막 진입 | 12 | +19.573° |
| 04 | 90번 하부 평지 복귀 | 0 | 0° |
| 05 | 151번 오르막 진입 | 0 | −19.573° |
| 06 | 154번 상부 평지 진입 | 12 | 0° |
| 07 | 156번 내리막 진입 | 12 | +19.573° |
| 08 | 159번 하부 평지 복귀 | 0 | 0° |

정확한 Transform과 감지 박스 오프셋은 [placement.json](placement.json)을 따른다. 루트는 경사 경계에 두고, 캐릭터의 진입 기울기에 따라 캡슐 전방 중심이 달라지는 만큼 감지 박스 중심을 보정했다. 모든 스팟의 월드 크기는 8 × 2 × 0.8이다.

회전 스팟은 총 23개지만 경사 8개는 스테이지 진행도와 적 경로 구성에서 제외한다. 코너 체크포인트는 계속 15개다. `Props` 직접 자식은 658에서 666으로 증가했다.

## 검증

- `NoryangjinSr18SceneTests`: 9/9. 경사 8개 경계, 코너 15개, 상·하부 분리와 두 경사 구간을 좌우 세 위치에서 연속 높이 추종하는 4,320개 표본 포함.
- `NoryangjinSlopeTests`: 6/6. 연속 이동·자세, 잘못된 방향/구성 거절, 시간 정지, 리셋, 1회 작동과 체크포인트 제외.
- `NoryangjinTurnSpotTests`: 48/48. 기존 코너·리셋·미사일 회전 등 회귀 검사.
- Editor 빌드 성공: 오류 0, 기존 경고 2개. Agent harness 검사 통과.
- [Play Mode 측정](playmode-probe.json): 실제 SR18 플레이어를 두 고가 구간의 진입 전으로 옮겨 실행했다. 양쪽 모두 최고 Y=12.17645, 끝 Y=0.160856, X 자세 약 ±19.573°를 기록했다. 421개 표본에서 정지 구간과 코너 정지 회전은 0건, 각 구간의 스팟 4개가 모두 소모됐다.
- 실시간 검증 중에만 게임 시간을 가속했고, 종료 후 시간 배율을 복원하고 편집 모드로 돌아왔다. 전체 스테이지 완주·전투·모바일 성능 인증은 아니며 Build Settings 제외를 유지한다.

## 편집과 복구

맵툴에서 경사 스팟을 선택하면 `이동 유지 (경사)`, 목표 X/Y, 회전 시간을 편집할 수 있다. 일반 코너에서는 이 옵션을 끈다. 경사 모드는 높이 추종 컴포넌트가 없는 플레이어를 임의로 기울이지 않는다. 캐릭터 크기·경사·속도·시간 배율을 크게 변경하면 감지 박스와 한 프레임의 높이 이동량을 다시 검증한다.

- 설치 스크립트: `tools/install-sr18-slope-spots.cs` (중복 설치 거절)
- 실행 검증: `tools/probe-sr18-slope-playmode.cs` (저장된 SR18에서 Play Mode 진입 후 실행, 제한 60초)
- 작업 전 미저장 씬까지 보존한 백업: `tmp/backups/sr18-before-slope-follow-20260905-111656.unity.tmp`
