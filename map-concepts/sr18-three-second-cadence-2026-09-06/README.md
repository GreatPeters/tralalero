# 현재 SR18 맵 — 3초 주기 비교 도면

후속 사용자 요청으로 기본 조우 간격은 **4초**로 변경되었고 왕복 적·전방 매복 사격 적이 추가되었다. [최신 이미지 기획서](../sr18-four-second-moving-enemies-2026-09-06/README.md)를 따른다. 아래 3초 안은 과거 비교 기록이며 실제 씬에 적용된 상태가 아니다.

## 최신 확인안 — 처음 5초 비움

사용자가 A안의 시작 부분을 비우는 흐름을 선택했다. **0–5초는 이동만, 5초 첫 적, 8초 BonusWall, 11초 기믹, 14초 다음 적**으로 이어진다. 이후 전체에서 3초마다 하나씩 조우하며 같은 종류는 9초 간격이다. 300초를 유지하므로 총 99개 지점(적 33·고정 벽 33·기믹 33)이다.

초록 길은 조우가 없는 시작 부분이다. 첫 적은 약하게 두는 방향이지만 이 그림 작업에서 적 능력치를 바꾸지는 않았다. 첫 코너는 균등 이동 가정에서 약 4.4초 지점이므로, 5초 첫 적은 실제 회전 종료를 확인한 뒤 위치를 조정해야 한다. 주황 표식 16개는 코너·경사 등 적용 전 조정 대상이다. 시작 확대도에서는 나중에 지나갈 상부 다리의 이벤트를 생략해 첫 11초 경로만 설명한다.

재현: `py -3.11 -X utf8 tools/draw_sr18_three_second_cadence.py --quiet-start`. 첫 조우 5초, 후속 8/11/14초, 3초 간격, 종류별 33개, 최초 구간 무배치를 검증했다. 최종 전체 맵·시작 확대도·시간 흐름을 확인했으며 이전 파일은 보존했다. **실제 Unity 씬은 변경하지 않았다.** 아래 A/B는 이전 비교 기록이다.

상태: **도면만 제작, 실제 씬 변경 없음.** 현재 맵의 길·상점 좌표와 한 줄 폭을 유지한다. 적 여러 명이나 BonusWall 두 개를 같은 횡단면에 놓지 않는다.

사용자의 “3초마다 조우”와 직전 대화의 “각 종류별 3초”는 실제 밀도가 다르므로 둘 다 그렸다. 어느 쪽도 실제 적용 승인으로 처리하지 않았다.

## A. 전체에서 3초마다 하나씩 조우

[전체 맵 그림](../../tmp/image-previews/sr18-three-second-cadence-2026-09-06/01-one-encounter-every-3s.png)

적 → 3초 → BonusWall → 3초 → 기믹 → 3초 → 적. 같은 종류끼리는 9초 간격이다. 300초에 총 100개 지점: 적 34명, 고정 BonusWall 33개, 기믹 판단 지점 33개. 평균 중심 간격은 약 25.87유닛이다.

이 해석은 좁은 길에서 서로 다른 요소를 앞뒤로 분리하면서 전체 조우 공백을 3초로 맞추는 비교안이다. [스케줄 데이터](schedule-alternating.json).

## 시간 가정과 적용 전 주의

경로 중심선 약 2587.04유닛을 300초에 균등 이동한다고 가정했다. 환산 속도는 약 8.623유닛/초이며 실제 플레이어 속도를 변경하거나 실측한 값이 아니다. 회전 정지, 경사·충돌·게임 속도·실제 전투 시간을 포함한 배치 검증은 별도다.

주황 테두리/△는 코너·출구와 가까운 지점 또는 경사 전환 부근이다. A에는 17개, B에는 48개의 조정 대상 표식이 있다. 간격 비교를 위해 목표 시각을 먼저 표시했으며, 이 표식들을 그대로 게임에 설치해도 안전하다는 의미가 아니다. 구현 시 안전 위치 조정에 따라 정확한 시간 주기도 달라질 수 있다.

도면의 벽은 고정 배치만 센다. 현재 적 처치마다 생성되는 BonusWall은 별도이고 그 규칙을 삭제·변경하지 않았다. 기믹 기호는 실제 프리팹의 파츠 수나 전체 통로를 막는 물체를 뜻하지 않는다.

## 재현·검증

- `py -3.11 -X utf8 tools/draw_sr18_three_second_cadence.py`: B 전체 맵, 16구간 모음 4장, 주기 설명 및 스케줄.
- `py -3.11 -X utf8 tools/draw_sr18_three_second_cadence.py --compare`: A 비교 맵 및 스케줄.

새 캔버스에 경로 좌표를 그리는 방식이며 이미지 생성·스크린샷 수정·Unity 변경은 하지 않았다. 16구간 전부 포함, 정확한 종류별/전체 조우 주기와 개수를 검사했다. 전체 그림 두 장, 주기 설명과 네 구간 모음의 레이아웃을 확인했다. 이전 그림과 출력 파일은 덮어쓰지 않았다.
