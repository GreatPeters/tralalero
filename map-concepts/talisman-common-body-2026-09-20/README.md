# 접힌 부적: 모든 업그레이드 공통 몸통 흡수

2026-09-20. 사용자: “업그레이드가 몇갠데 ㅋㅋㅋ 그냥 몽땅 몸으로 흡수되게 해줄 수 있어? 시안을 그려줘 네가 구현할 수 있는 선에서”. 능력별 입/몸 분기와 이전 신발 흡수 제안을 대체한다. 실제 자산 구현 요청이 아닌 시안 제작이다.

## 최종 제안 흐름

1. 선택한 부적에 접근.
2. 획득 확정 즉시 기존 보상을 한 번 적용하고 부적의 양옆 판을 펼침.
3. 중앙 문양이 짧은 곡선을 따라 몸통 중앙으로 이동. 뒤쪽 게임 카메라에서 읽히는 등 중앙에 작은 발광을 잠깐 표시.
4. 종이·집게·아이콘·발광을 모두 정리. 달리기는 계속되고 실제 업그레이드 효과는 기존 게임 규칙대로 유지.

모든 업그레이드가 동일한 몸통 앵커와 동일한 연출을 쓴다. 아이콘·이름·수치만 실제 보너스 데이터에 따라 표시하며, 종류별 흡수 위치/애니메이션 분기는 없다. 항구·고속도로·휴게소에서도 동일하다. +14%는 예시다. 지원군 등 특수 보너스의 실제 동작을 능력치 증가로 바꾸지 않으며 공통 획득 피드백만 제공한다.

## 직접 구현 가능한 구성

- 두 힌지로 움직이는 얇은 판 3개와 집게: transform 회전으로 펼침.
- 아이콘 쿼드 1개: 몸통 앵커를 향해 짧게 이동하며 축소·페이드.
- 짧은 궤적 1개와 작은 additive 발광 쿼드 1개: 스케일·알파로 마무리.
- 목표 약 0.6초는 제안값. 복잡한 파괴/천 시뮬레이션이나 부위별 장비 이펙트가 필요하지 않다.
- WallScript는 보상 적용 뒤 원본 lifetime root를 비활성화하므로, 별도 효과 루트에서 연출을 재생하고 종료 시 회수한다. 시각 효과는 보상을 다시 적용하지 않는다.
- 실제 제작 시 사망·재시작·연속 획득·풀링 초기화와 몸통 앵커를 검증한다. 이번에는 Unity 코드나 게임 자산을 변경하지 않았다.
