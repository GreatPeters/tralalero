# 접힌 부적 획득 흐름 4안

**후속 정정:** 사용자가 공격력은 신발 강화가 아니라고 지적했다. 이 문서의 공격력→신발 표현과 02 인장 추천은 [능력별 흡수 대상 수정안](../talisman-stat-targets-2026-09-20/README.md)으로 대체한다. 부적 모양/분리 효과 수명에 관한 검토는 별개로 유지한다.

2026-09-20. 사용자: “3번이 매우 좋은데? 이거 먹으면 어떻게 되지? 플로우를 그려줘봐 여러가지 시안으로다가”. 최신 공통 보너스 03 접힌 부적의 외형을 유지하고 획득 연출 4개를 그렸다. 네 개라는 수, 연출 종류, 시간은 에이전트 제안이다.

## 공통 흐름

다가가기 → 획득 확정 및 보상 적용 → 신발에 힘이 들어가는 짧은 시각 효과 → 효과 정리, 달리기와 강화 유지. 항구·고속도로·휴게소에서 동일한 외형과 연출을 사용한다. 그림의 확대 컷은 설명용이며 게임 카메라를 확대하거나 플레이를 멈추는 제안이 아니다.

공격 부적 예시를 사용했다. 하트 부적은 같은 구조에서 색·문양·보상 표기를 체력으로 바꾼다. +13/+14%는 기존 시안의 비교 수치다. 부적을 먹을 때마다 별도 지속형 장비가 붙거나 화면에 검이 추가되는 기획은 아니다.

| 번호 | 흐름 | 목표 시간 | 구현 부품 |
|---|---|---|---|
| 01 | [펼쳐서 흡수](images/01-unfold-stream.png) | 약 0.65초 | 접힌 판 3개 피벗 회전 + 아이콘 이동 + 짧은 궤적 |
| 02 | [신발에 찍히는 인장](images/02-seal-stamp.png) | 약 0.60초 | 부적 위치·회전·축소 + 신발 표면 문양 페이드 |
| 03 | [접혀서 들어가는 부적](images/03-fold-in-v2.png) | 약 0.70초 | 판 3개 접기 + 짧은 직선 이동 + 축소·페이드 |
| 04 | [세 장의 문양 흡수](images/04-three-pages.png) | 약 0.80초 | 미리 분리한 판 3개 + 순차 곡선 이동 + 페이드 |

01은 펼쳐진 판에서 아이콘만 흡수된다. 02는 부적이 신발에 잠깐 닿아 인장을 남기고 소멸한다. 03은 부적 전체가 작게 접혀 들어간다. 04는 미리 나눈 판 세 개가 순차 흡수된다. 시간은 시작 제안값이며 측정 결과가 아니다. 01/02의 마지막 컷에 보이는 인장과 04의 작은 빛은 잔여 연출이며 곧 사라진다. 능력치만 런 동안 유지한다.

## 현재 코드와 연결

`Assets/ShooterSurvival/Scripts/Walls/WallScript.cs`의 OnTriggerEnter를 확인했다. Player 접촉에서 유효성·접촉 간격·ChoicePair.TryChoose 검사를 통과한 다음 ApplyWallEffect, BonusRewardCue.PlayPickup, collider 처리, lifetime root 비활성화가 이어진다. 따라서 “모든 접촉이 보너스를 준다”가 아니라 **획득이 확정되면 즉시 한 번 적용한다**가 정확하다.

- 공격력 퍼센트는 현재 코드에서 weaponScript.damage에 배율을 적용한다. 임의의 별도 대기 시간이나 효과 종료 이벤트까지 보상을 미루지 않는다.
- 시각 판/아이콘 효과는 lifetime root 비활성화 전에 별도 루트 또는 풀에 생성해야 한다. 비활성화될 부적 자식에서 코루틴을 돌리면 흡수 애니메이션이 끊긴다.
- 생성된 효과는 해당 신발의 앵커를 추적하며 보상 수치를 변경하지 않는다. 시각 판이 세 장이라도 보상은 세 번 적용하지 않는다.
- 01/03은 3개 평면의 피벗 회전, 02는 위치·회전·스케일과 표면 근접 쿼드, 04는 고정 판 3개와 순차 보간으로 구현한다. 실제 종이 찢기나 천 시뮬레이션이 필요하지 않다.
- 장면 전환·사망·재시작 시 효과 회수와 신발 문양 초기화가 필요하다. 실제 모델 제작, Unity 설치, 애니메이션 및 모바일 성능 검증은 아직 하지 않았다.
