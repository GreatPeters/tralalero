2026-09-20. 사용자는 “아니 근데 공격력은 신발이 강해지는 건 전혀 아닌데 ㅋㅋㅋ”라고 지적하고, 능력별 대상으로 바꾸자는 설명 뒤 “다시 그려봐”라고 요청했다.

이전 부적 획득 4안은 공격력까지 신발에 흡수시키는 의미 오류가 있었다. 부적 외형과 펼침은 유지하되 공격력은 공격 발사부, 체력은 몸에 짧은 피드백을 주는 6컷 비교 이미지로 교체했다. 이전 신발 인장 추천은 이 정정으로 철회된다.

## 실제 발사부 확인

처음에는 눈에 보이는 무기로 흡수되는 그림을 생각했지만, `WeaponScript.ResolveProjectileSpawnPosition`과 `CacheVisiblePlayerMuzzle`은 플레이어의 보이는 `Original/headend` 아래 `ProjectileMuzzle`을 사용한다. 대체 위치도 입 앞 오프셋이다. `WeaponManager.currentWeapon`이라는 내부 이름만으로 상어가 총을 들고 있다고 가정하면 안 된다. 실제 HUD 캡처에서도 별도 총이 보이지 않았다. 따라서 총을 새로 그리지 않고 입 앞 발사부로 정정했다.

- 공격: 부적 획득·공격력 적용 → 검 문양이 입 앞 발사부로 이동 → 짧은 발사부 반응 뒤 평소 사격 계속.
- 체력: 부적 획득·체력 적용 → 하트 문양이 몸통으로 이동 → 몸의 짧은 반응을 정리하고 계속 달리기.
- 신발에는 발광·인장·흡수 궤적을 두지 않는다. 검은 능력 아이콘이며 새 무기 지급이 아니다.
- 공격 투사체의 개수·속성·크기 변경은 제안하지 않는다. 마지막 컷의 파란 발사광은 사격을 설명하는 그림이며 실제 탄환 표현과 캐릭터 측면 외형을 정확히 복제한 런타임 캡처가 아니다.
- 실제 구현은 기존 보상 처리와 분리한 효과 루트에서 아이콘 쿼드를 입 앞 앵커/몸통 앵커로 보간하는 방식. 게임 카메라는 유지하고 확대 컷은 설명에만 사용한다.
