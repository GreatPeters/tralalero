# 노량진·고속도로 및 프레젠테이션 개선

기존 `map2` 작업을 이어서 수정했다. 기존 로컬 변경은 유지했고, 커밋·푸시는 하지 않았다. 노량진의 플레이 씬은 `Noryangjin_MapTool_Mode_SR18`, 새 고속도로 씬은 `HighWay`다.

## 요청별 반영

| 요청 | 반영 결과 |
|---|---|
|1. 스토리 UI|세로 전체 화면 영상, 읽기 쉬운 제목·자막, 다시 재생·다음 장면·건너뛰기 버튼으로 재구성했다.|
|2. 실제 움직이는 애니메이션|상어의 입·몸, 신의 손짓, 걷기와 물결이 움직이는 4개 장면을 로컬 Wan2.2로 생성했다. 최종 20.1667초 MP4를 연결했다. 이미지 이동 슬라이드쇼를 교체했다.|
|3. 스킨 상점|짙은 남색 배경, 큰 장비 미리보기, 한 열의 상품 목록, 슬롯 탭과 고정 구매·착용 버튼으로 재구성했다.|
|4. 재화 치트|맵 툴 `편의`의 `재화 지급 (에디터 치트)`에서 코인·보석을 각각 지정 수량만큼 추가한다. 라이브 상점 잔액에도 반영된다.|
|5. 고속도로 적 6종|라바콘 정비공·교통 순찰대·톨게이트 대장·타이어 중장병·아스팔트 작업자·배달 라이더의 모델, 리그, 6개 동작, 전투 프리팹을 모두 연결했다.|
|6. TRELLIS 결과물 확인|지정 폴더의 최신 고속도로 Props 29종을 SHA256으로 비교했다. 이전 프로젝트와 일치하는 FBX가 없어 29종 모두 별도로 가져오고 새 씬에 사용했다. 원본은 유지했다.|
|7. 메뉴 이름|`Tools > 맵 제작 도구 > 맵 툴 열기`로 변경했다.|
|8. 컨셉 선택|오브젝트 상단 `모두 삭제` 왼쪽에서 `노량진 맵툴` / `고속도로 컨셉`을 선택한다. 도로·Props·적·기믹 팔레트가 바뀐다.|
|9. 영상 진입 UI|로비의 이미지뿐이던 영상 버튼을 실제 스토리 다시 보기 버튼으로 연결했다. 새 상점과 스토리의 정렬·전환·닫기 동작을 함께 수정했다.|
|10. 노량진 반복 테스트|기존 장비 기준 3회, 성장 장비 기준 3회와 최종 충돌 수정 후 추가 주행을 기록했다. 무적이나 강화된 좌우 이동은 사용하지 않았다.|
|11. 노량진 환경 보강|기존 시장 소품을 이용한 작은 배치 154개, 움직이는 정박선 4척과 주변 갈매기 4마리를 추가했다. 원래 도로 230개·상점 306개·안벽 306개를 보존했다.|
|12. HighWay 및 씬 이동|고속도로 컨셉을 바탕으로 2340m, 5회전, 완만한 고저차, 공사·차량·톨게이트·터널 구간을 제작했다. 노량진 클리어 후 이동 및 툴의 별도 씬 이동 메뉴를 연결했다.|
|13. Excel 밸런스|기존 `Data.xlsx`에 고속도로 64개 배치 행과 성장·피해·기믹 제어를 추가했다. 노량진은 78개 행이다. 보호된 런타임 데이터도 갱신했다.|
|14. 고속도로 기믹|총알로 파괴하는 방벽, 예고 후 횡단하는 차량, 세 차로 중 하나가 열리는 톨게이트를 배치했다.|
|15. 미사용 노량진 기믹|반복 버킷 3개 구간을 기름 2곳·갈매기 급강하 1곳으로 바꾸고, 해안 포격선 2척을 활용했다.|
|16. 전반 점검|새 도로 참조, 높이 추종, 카메라 차폐, 실제 충돌, 투사체 반환, UI 저장·영상 수명, 챕터 이동을 점검하고 발견한 문제를 수정했다.|

앞서 보고한 버킷 위치 문제도 유지해서 수정했다. 입구가 향하는 실제 메시 축에 맞춰 머리 부착 각도를 바꿨으며, 약 3초 뒤 떨어지고 발사가 복구된다.

## 바로 사용하기

- 맵 열기: `Tools > 맵 제작 도구 > 맵 툴 열기`
- 씬 선택: `Tools > 맵 제작 도구 > 씬 이동 > 노량진 / 고속도로`
- 팔레트 전환은 배치할 에셋 목록을 바꾼다. 편집 중인 씬을 바꾸려면 별도 씬 이동 메뉴를 사용한다.
- 재화 지급: 맵 툴 `편의`에서 수량 입력 후 `코인 지급` 또는 `보석 지급`. 현재 저장 재화에 더해지는 기능이다.
- 밸런스: `Assets/ShooterSurvival/GameData/Editor/Data.xlsx`의 `밸런스 조정!B28:D45`는 고속도로, `B47:D50`은 추가 노량진 기믹이다. `적 배치`, `보너스 배치`, `기믹 배치`에서 개별 배치를 조정한다.

## 검증

관련 EditMode 회귀 테스트 **65개 모두 통과**했다. SR18, Highway, 상점, 재화, 기름, 투사체 풀 수명 테스트의 중복을 제거한 수치다. 전체 저장소 테스트를 모두 실행한 결과는 아니다. 런타임·에디터 C# 빌드와 `tools/validate-agent-harness.ps1`도 통과했다. 보호 데이터는 Excel 원본과 일치하는 `Current` 상태다.

실제 Unity 물리 접촉에서 다음을 확인했다.

| 기믹 | 측정 결과 |
|---|---|
|기름|조작 감도 55%, 2초 뒤 복원, 회전·발사 유지|
|갈매기|그림자 예고 → 급강하 → 피해 20 한 번 → 이탈|
|포격선|속도 30의 활성 포탄, 몸 중앙 조준, 피해 10|
|방벽|내구도 85, 실제 무기 3발에 파괴, 시각물·충돌 해제|
|톨게이트|열린 차로 피해 0, 닫힌 차로 피해 40|
|횡단 차량|1.5초 예고 후 9m 이동, 회피 피해 0, 접촉 피해 35|

상점에서는 100 코인·100 보석 지급, 60보석 구매, 무료 재장착, 닫기 후 로비 복구, 씬 재로드 후 소유·장비·잔액 보존을 확인했다. 영상은 재생·장면 이동·5회 빠른 재생/종료·렌더 타깃 해제·게임 시작 차단을 확인했다. 노량진 → 고속도로 이동과 고속도로 재시작도 실제 UI 이벤트를 통해 확인했다.

반복 주행은 일반 `PlayerMove`, TimeScale 3, 기본 장비를 사용한다. 성장 프로필은 테스트용으로 설정한 값이며 해당 플레이에서 구매한 것으로 주장하지 않는다. 기존 ATT12/HP60 노량진 3회는 약 48.45초에 종료됐다. ATT33/HP130 및 공격 속도 강화 4단계로 진행한 3회는 330.71초 클리어 / 311.02초 사망 / 330.67초 클리어였다. 고속도로는 ATT33/HP130, 공격 속도 강화 없이 292.70 / 292.72 / 292.68초에 3회 모두 클리어했다. 최종 충돌 수정 후에는 노량진 311.01초 사망 / 330.67초 클리어, 고속도로 292.69초 클리어를 추가 확인했다.

모든 테스트를 마친 뒤 원래 저장 상태 **57개 키를 복원하고 원본과 전수 비교**했다. 불일치 0개이며 코인 3007·보석 0, 원래 장비·강화 상태로 돌아왔다. 현재 에디터는 노량진 SR18 편집 모드다.
