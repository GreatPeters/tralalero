# 트랄랄레오 풀 스토리 기획서 — 「신발 한 켤레의 배상」

게임 기획서(`GAME_DESIGN_OVERVIEW.md`)의 세계관을 잇는 제안 문서다. 노량진 → 고속도로 → 휴게소, 총 5챕터, 챕터당 약 20판은 사용자 요구다. 4·5챕터, 악당 설정, 대사, 재미 요소, 게임 흐름은 제안이며 게임에는 반영하지 않았다.

## 0. 이번 판에서 바뀐 것 (사용자 피드백)

| 요소 | 결정 |
|---|---|
| 현상금 게이지 | 삭제 → 대신 **순찰차·견인차 우르르 패턴** |
| 탱크로리 | 유지·구체화: 체력이 높고, 부수면 **인접한 차를 모조리 폭발로 날림** |
| 교통방송 예고 | 삭제. 패턴은 **예고 없이** 온다 |
| 통나무 트럭 | 수정: **좌측 상행선(반대편 도로)에서 북쪽으로** 가다가 통나무가 **우측(내 도로)으로** 쏟아짐 |
| 공물 도감 | 삭제 |
| 휴게소 먹방 버프 | 삭제. 대신 그 그림의 **휴게소 건물 외형**을 모델 방향으로 채택 |
| 도망가는 운전자 | 삭제 |
| 개조업자 한마디 | 삭제 |
| 하이패스 | 유지·수정: 차단기 없음. **하이패스/현금 차로에서 유니크 보너스 선택** |
| 피버 | 삭제 |
| 고사상 룰렛 | 삭제(고사상 컨셉 폐기). 랜덤 요소만 살려 **랜덤 보너스 월** 신설 |
| 졸음쉼터 꿈 보너스 | 삭제 |
| 게임 흐름 | 신설: **분기 팝업으로 경로를 고르는 흐름** |

## 1. 한 줄 이야기

신발을 훔쳤다가 저주받은 상어 트랄랄레오가, 가브릴렐로가 만족할 "더 좋은 신발"을 찾아 서울까지 올라가는 동안 온 동네가 그를 쫓는다. 마지막에 그는 신발은 빼앗는 것이 아니라 만드는 것임을 알게 된다.

## 2. 등장인물

| 인물 | 역할 | 설정 |
|---|---|---|
| 트랄랄레오 트랄랄라 | 주인공 | 신발을 훔쳐 저주받은 상어. 꼬리가 발. 겁이 많지만 한번 달리면 멈추지 않음 |
| 가브릴렐로 트랄랄랄레오 | 저주를 내린 신 | 바치는 신발마다 깐깐하게 퇴짜 |
| 불법 신발 개조업자 | 기본 성장 상점 | 챕터마다 제단 옆에 먼저 와 있음. 정체는 5챕터에서 밝혀짐 |
| 퉁퉁퉁 사후르 · 붐바르딜로 | 조력자 | 몸으로 밀어내는 친구, 하늘에서 미사일로 돕는 친구 |
| 챕터 보스들 | 추적자 | 횟집 사장님 → 렉카 대장 → 경찰 포위 → 중계 헬기 → 가브릴렐로의 사자 |

## 3. 챕터 구성

| 챕터 | 장소 | 찾는 신발 | 쫓는 쪽 | 보스 |
|---|---|---|---|---|
| 1 | 노량진 수산시장 | 방수 장화 | 시장 상인 | 횟집 사장님 |
| 2 | 고속도로 | 레이싱 슈즈 | 렉카 견인 조직 + 경찰 | 렉카 대장 |
| 3 | 한울휴게소 | 할머니의 고무신 | 경찰 현상수배 | 푸드코트 30초 포위 |
| 4 (제안) | 한강 | 한정판 운동화 | 방송국 생중계 | 중계 헬기 |
| 5 (제안) | 성수동 수제화 거리 | 직접 만든 한 켤레 | 가브릴렐로의 시험 | 가브릴렐로의 사자 |

각 챕터 틀: 진입 영상 → 제단 → 본편(분기 팝업으로 경로 선택) → 보스 → 공물 장면(가브릴렐로의 퇴짜와 다음 단서).

## 4. 챕터별 이야기

**프롤로그 (기존 영상 유지)** 신발을 물고 도망 → 저주로 변신 → "절대 벗겨지지 않는다" → "더 좋은 신발을 바치면 풀린다". 첫 목적지 노량진.

**1챕터 · 노량진 — 장화의 시장.** 젖은 신발이 무거운 트랄랄레오가 상인들의 장화를 노린다. 상인들이 길을 막고, 칼 든 횟집 사장님이 장화를 지킨다. 가브릴렐로: "비린내가 난다. 퇴짜." 시장 TV 속보 구석에 "경부고속도로, 한정판 레이싱 슈즈 운송 중".

**2챕터 · 고속도로 — 정체의 끝에서.** 쌩쌩 달리는 차들을 보고 겁먹는 트랄랄레오(기존 요구). 현상금을 노린 렉카 견인 조직이 레이싱 슈즈 트럭을 가로채고 차들로 고속도로를 막는다(차량전 기획의 정체 관문). 경찰까지 가세해 순찰차·견인차가 떼로 몰려온다. 렉카 대장을 쓰러뜨리면 화물칸에서 레이싱 슈즈가 떨어진다. 가브릴렐로: "빠르긴 한데 너무 빨리 닳는다. 퇴짜."

**3챕터 · 한울휴게소 — 포위된 휴게소.** 호두과자를 먹던 사람들이 거대한 상어를 보고 도망간다(기존 요구). 푸드코트에서 30초 동안 경찰 포위를 버틴다(기존 요구). 도망가지 않은 호두과자 가게 할머니가 낡은 고무신을 준다. 가브릴렐로(처음 망설이며): "정성은 있다. 하지만 네 것이 아니다." 할머니: "진짜 좋은 신발은 성수동 가서 만들어 달래야지."

**4챕터 · 한강 (제안) — 생중계.** 서울에 들어오자 방송국이 생중계를 시작한다. 중계 드론·배달 오토바이·중계차. 보스는 중계 헬기. 경품 한정판 운동화에 가브릴렐로: "공장에서 찍어낸 수천 켤레 중 하나."

**5챕터 · 성수동 (제안) — 한 켤레의 배상.** 수제화 공방의 장인은 사실 챕터마다 제단 옆에 있던 개조업자였다. 가죽·밑창·실을 모아 직접 만든 한 켤레를 바치자: "처음으로 훔치지 않은 신발이구나." 저주가 풀리고, 바다로 돌아간 상어의 꼬리에는 작은 신발 한 짝이 그대로 남아 있다.

## 5. 게임 흐름: 분기 팝업으로 고르는 경로

### 5-1. 규칙

- 분기점 약 60 m 앞에서 게임이 **느려지고(0.2배속)** 화면이 어두워지며 **팝업**이 뜬다.
- 팝업에는 선택지 카드 2장. 각 카드에 "무엇이 나오는지"와 "무엇을 얻는지"를 짧게 적는다.
- 5초 안에 고르지 않으면 기본값(본선)으로 간다.
- 고른 뒤 상어가 자동으로 그 길로 빠진다. 좌우로 끼어들어 결정하는 방식이 아니다.
- 판이 끝나면 결과 화면에 "이번 경로"를 보여 준다. 20판 동안 성장 상태에 따라 다른 길을 고르게 만드는 것이 목적이다.

### 5-2. 고속도로 한 판 흐름 (약 300초)

| 시각 | 구간 | 팝업 선택 |
|---|---|---|
| 0–60초 | 진입 본선: 흐름 차량, 첫 정체 관문 | — |
| 60초 | **분기 ①** | **본선 직진** — 정체 관문·우르르 패턴, 코인 많음 / **우측 출구 국도** — 경운기·고라니 떼·과수원 길, 적 약함, 체력 회복, 코인 적음 |
| 60–150초 | 선택한 길 → 다시 본선 합류(IC) | — |
| 150초 | **분기 ② 톨게이트** | **하이패스 차로** / **현금 차로** — 차로마다 다른 유니크 보너스 |
| 150–230초 | 본선: 통나무 트럭, 탱크로리 관문, 랜덤 보너스 월 | — |
| 230초 | **분기 ③** | **렉카 대장 추격** — 보스전, 클리어 보상 큼 / **우측 출구 공사 우회로** — 보스 없이 공사 구간 교전, 회복, 보상 작음 |
| 230–300초 | 선택한 결말 → 한울휴게소 진입 | — |

한 판에 조합 8가지(2×2×2). 초반 약할 때는 국도·공사 우회로로 살아남는 법을 배우고, 성장하면 본선·보스 쪽으로 코인을 더 번다.

### 5-3. 다른 챕터에도 같은 틀

- 노량진: 시장 골목(상인 많음, 코인) / 부둣가(갈매기·기름, 회복)
- 휴게소: 주차장 정면(경찰 많음) / 주유소 뒤편(차 사이 좁은 길)
- 4·5챕터: 다리 위 / 한강공원, 큰길 / 골목 공방

## 6. 재미 요소 (고속도로 중심)

| 이름 | 내용 |
|---|---|
| **뉴스 속보 자막** | 화면 위 뉴스 자막이 플레이에 반응 ("상어, 탱크로리 3대 연쇄 폭파") |
| **순찰차·견인차 우르르** | 예고 없이 순찰차와 견인차 떼가 세 차로를 채우며 몰려오는 패턴. 틈을 찾거나 부숴서 뚫는다 |
| **탱크로리** | 체력이 높다. 대신 부수면 폭발로 인접한 차를 모조리 날려 버린다. 정체 관문을 한 번에 뚫는 열쇠 |
| **통나무 트럭** | 좌측 상행선(반대편 도로)에서 북쪽으로 달리던 트럭의 통나무가 예고 없이 분리대를 넘어 우측(내 도로)으로 굴러 쏟아진다 |
| **하이패스·현금 유니크 보너스** | 톨게이트에는 차단기가 없다. 하이패스 차로와 현금 차로에 각각 다른 유니크 보너스가 걸려 있고 하나를 고른다 |
| **랜덤 보너스 월** | 기존 보너스 월과 별개. 물음표 카드 안에서 아이콘이 돌다가 통과하는 순간 무엇이 나올지 정해진다 |
| **인형뽑기 조력자 소환** | 휴게소 인형뽑기 기계를 쏴서 퉁퉁퉁·붐바르딜로 인형을 뽑으면 잠시 함께 싸운다 |

**휴게소 건물 외형:** 예시 그림의 휴게소 건물(큰 "휴게소" 간판, 푸드코트 입구, 양옆 호두과자·알감자·핫바 현수막, P·화장실 표지)을 휴게소 모델 방향으로 채택한다. 버프 아이템은 쓰지 않는다.

## 7. 대사 샘플

- 가브릴렐로(장화): "비린내가 난다. 퇴짜."
- 가브릴렐로(레이싱 슈즈): "빠르긴 한데 너무 빨리 닳는다. 퇴짜."
- 가브릴렐로(고무신): "…정성은 있다. 하지만 네 것이 아니다."
- 가브릴렐로(결말): "처음으로 훔치지 않은 신발이구나."
- 렉카 대장: "그 상어 잡으면 견인비 평생 공짜다!"
- 휴게소 할머니: "배고프지? 먹고 가."

## 8. 결정할 것

1. 분기 팝업의 속도: 느리게(0.2배속) vs 완전 정지.
2. 고속도로 분기 ③에서 보스를 건너뛰는 길을 허용할지.
3. 4·5챕터 장소(한강·성수동)와 개조업자 = 장인 반전을 쓸지.
4. 유니크 보너스와 랜덤 보너스 월에 넣을 효과 목록.
