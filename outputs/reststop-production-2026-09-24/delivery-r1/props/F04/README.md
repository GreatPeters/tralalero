# F04 조경 나무

14,872삼각형의 독립 소품입니다. TRELLIS 원본의 UV와 PBR 텍스처를 유지했고, 새 FBX·GLB 임포트 검증과 다각도 비교를 통과했습니다.

- 잎 재질은 양면 표시를 유지하세요. GLB에는 `doubleSided=true`가 포함되어 있습니다.
- `textures/Normal.png`는 미연결 평면 참고 파일입니다. 원래 재질에는 노멀 텍스처가 없으므로 동봉된 재질을 우선 사용하세요.
- BaseColor는 원본 PNG 그대로이며 Roughness/Metallic은 원본 결합 텍스처의 G/B 채널을 추출했습니다.
- 잎끝과 뿌리 덩어리의 미세 형태는 고밀도 원본보다 단순합니다. 원본과 검증 기록을 함께 보관합니다.
