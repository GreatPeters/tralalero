# G01 주유소 캐노피 지붕

14,770삼각형의 독립 에셋입니다. TRELLIS의 지붕과 외곽 재질을 보존하고, 잘못 생성된 하부 조명 표시를 제거한 뒤 2열×3개의 프레임 조명과 단순한 패널 이음새를 직접 보정했습니다.

- 새 FBX·GLB 임포트와 상하부 8방향 렌더 비교를 통과했습니다.
- 조명은 형상과 재질이며 실제 게임 광원은 별도로 설정해야 합니다.
- 고밀도 후처리 소스에는 이 보정이 포함됩니다. `original-trellis-source.glb`는 수정 전 첫 TRELLIS 재질 결과입니다.
- 최초 형태와 재질 3회 시도 기록은 보존했으며 추가 AI 생성은 하지 않았습니다.
- 작은 윗테두리 요철과 기준보다 단순한 하부 패널 표현은 남아 있습니다.
