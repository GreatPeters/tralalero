# R02 곡선 도로

검수한 TRELLIS R01 직선 도로의 메시·UV·재질을 60도로 굽혀 보정한 14,991삼각형 모델입니다. R02의 자동 형태 시도 3회는 일정한 폭의 곡선을 만들지 못해 실패 기록을 보존했습니다.

- 일정한 도로 폭과 평평한 노면, 곡선을 따라가는 가장자리 차선·중앙 점선을 유지합니다.
- 기준 이미지에 정확한 반지름이 지정되지 않아 60도 굽힘을 보정값으로 선택했습니다. 최종 조립 시 경로 크기에 맞춰 배치할 수 있습니다.
- 아스팔트가 기준보다 밝고 점선이 조금 더 촘촘합니다. 감량 후 미세 모서리 연화가 남습니다.
- `high-detail-source.glb`는 보정된 곡선 소스이고 `original-trellis-source.glb`는 변형 전 R01 TRELLIS 소스입니다. 새 AI 생성 없이 재사용했습니다.
- 새 FBX·GLB 검사와 5방향 원본 비교를 통과했습니다. 기존 게임 씬에는 아직 배치하지 않았습니다.
