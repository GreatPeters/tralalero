# S02 유리 진열 케이스

최종 모델은 11,971삼각형이며 GLB·FBX·Blender 파일을 제공합니다. 실제 내부 선반 2단과 투명 곡면/측면 유리가 있습니다.

- 본체는 TRELLIS가 생성한 형상과 재질을 사용합니다. 후처리에서 사라졌던 내부 구조를 캐시된 원본에서 복구했습니다.
- 전체 메시 재질 시도 1회는 계산 시간 때문에 확인 후 취소했고 소비 시도로 보존했습니다. 두 번째 재질 시도는 본체만 대상으로 저장된 25단계·2K 설정과 파생 시드 12346을 사용했습니다.
- 자동 감량 두 방식은 삼각형 제한을 넘겼습니다. 면 연결을 정리한 본체의 11,541삼각형·UV·PBR·노멀은 유지했습니다.
- 얇은 유리와 선반의 감량 변형을 없애기 위해 원본 곡선과 선반 높이/폭/깊이를 기준으로 해당 부분만 다시 구성했습니다. 원본에서 추정한 뒤쪽 서비스 박스와 마감은 그대로입니다.
- 내장된 **본체·유리·선반 3재질을 유지**하세요. 본체용 2K 텍스처와 별도의 유리/스테인리스 재질입니다. 유리는 알파 0.13의 투명도 근사이며 물리 굴절을 보장하는 셰이더가 아닙니다.
- 새 GLB·FBX 임포트에서 삼각형 수, UV, 비유한 값, 퇴화 면, 미사용 정점을 검사했습니다. 각 형식의 앞면 9개 광선에서 투과율 약 0.87, 수직 6개 단면에서 두 선반을 확인했습니다. GLB 5방향과 FBX 재임포트 렌더도 검토했습니다.

기준 이미지보다 본체가 더 어둡고 낡은 금속 마감이며, 내부 선반은 차가운 금속색입니다. 일부 좁은 테두리에 원래 복원 형상의 불규칙함이 남습니다. 최종 모델은 정적 게임 소품이며 조명/게임 동작은 포함하지 않습니다.

`trellis_source.glb`는 보정 과정의 고밀도 조립 소스입니다. `original-textured-body.glb`는 TRELLIS의 본체 재질 원본이며, `recovered-shape-before-materials.glb`는 재질 생성 전 복구 구조입니다. `repair.json`, `validation.json`, `visibility-validation.json`, `quality/`와 `quality-fbx/`에 근거를 보존했습니다.

최종 ZIP에서는 고밀도 소스 이름이 `high-detail-source.glb`이며 검증 자료와 비교 시트는 `validation/`에 모아집니다.
