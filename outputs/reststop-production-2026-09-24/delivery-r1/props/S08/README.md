# S08 유리문 냉장고

최종 모델은 14,772삼각형입니다. TRELLIS 본체 12,108삼각형과 보정한 내부 부품 2,664삼각형으로 구성됩니다.

- TRELLIS의 외형·문틀·손잡이·환기 그릴을 유지하고, 실제 선반이 없었던 내부를 기준 이미지에 맞춰 구성했습니다.
- 유리문, 내부 라이너, 타공 선반 5개와 세로 발광 띠는 직접 보정한 부품입니다. 선반마다 실제 구멍 40개가 있으며 총 200개입니다.
- 본체 재질은 원래 저장값의 첫 수동 TRELLIS 재질 시도(시드12345·25단계·2K)입니다. 원래 형태 시도는1회이며 재처리는 캐시를 사용해 추가 AI 형태 생성 없이 진행했습니다.
- 내부 부품은 감량하지 않고 본체에만 남은 삼각형 예산을 배정했습니다. 내장된 **본체·유리·스테인리스·발광 띠 4재질을 유지**하세요. 유리는 알파0.06의 투명도 근사입니다.
- 새 GLB·FBX 모두 UV/삼각형/비유한 값/퇴화 면/미사용 정점 검사를 통과했습니다. 각 형식에서 앞면 투과 광선18개, 선반5개, 타공200개를 검증했고 GLB5방향 및 FBX 재임포트 렌더를 확인했습니다.

원본보다 밝은 윗면, 추정된 뒤쪽의 불규칙한 세로 이음 흔적, 단순화된 타공 패턴이 남습니다. 발광 재질은 포함하지만 문 여닫기나 별도 게임 조명/상호작용 코드는 포함하지 않은 정적 소품입니다.

`fridge-layout.json`과 `visibility-validation.json`에 내부 배치와 검사 근거가 있습니다. `original-textured-body.glb`는 TRELLIS 본체 재질 원본, `original-shape.glb`는 보정 전 형상입니다. `trellis_source.glb`는 감량 전 조립 소스이며, 최종 ZIP에서는 `high-detail-source.glb`로 제공됩니다. ZIP의 검증 기록은 `validation/`에 모입니다.
