# G02 주유기

13,893삼각형의 독립 에셋입니다. 새 FBX·GLB 임포트 검사와 다각도 비교, 양쪽 방향에서의 상단 개구부 검증을 통과했습니다.

- 동봉된 두 재질을 유지하세요. 검은 호스 부분은 별도의 고무 재질로 보정되어 기존 베이크 맵을 사용하지 않습니다.
- 기존 텍스처를 모든 면에 일괄 적용하면 호스의 밝은 색 번짐이 다시 나타날 수 있습니다.
- 본체 정점과 UV는 기존 감량본 그대로 유지했습니다. 원본 표면 색과 노즐 높이를 기준으로 아래쪽 호스 영역만 보정했습니다.
- 작은 호스 가장자리 음영과 연결부/조작부 디테일 단순화는 남아 있습니다. 실제 주유 기능이나 게임 상호작용은 포함하지 않습니다.
