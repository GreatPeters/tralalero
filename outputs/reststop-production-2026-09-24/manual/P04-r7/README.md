# P04 대걸레

TRELLIS의 정상 중간 형상과 생성 재질을 보존해 만든 14,799삼각형 모델입니다. 원본의 복잡한 면 연결을 표면 점유 기반 재구성으로 정리하고, 기존 재질을 2K로 베이크했습니다.

- 긴 금속 봉·파란 손잡이·고정부·걸레의 퍼진 실루엣을 유지합니다. 좁은 끈 사이 공간 일부는 합쳐졌으며 끈 무늬는 노멀맵에도 포함됩니다.
- 원본보다 밝은 파란 손잡이, 작은 봉/손잡이 표면 자국과 둥글어진 미세 모서리가 남아 있습니다.
- 새 FBX·GLB 임포트에서 삼각형 수·UV·유한 좌표·퇴화 면을 검사했고 실제 5방향 렌더를 비교했습니다. 최종 비다양체 연결은 0입니다.
- 고밀도 재질 원본은 `high-detail-source.glb`, 복구에 사용한 수정 전 AI 중간 형상은 `original-trellis-source.glb`로 제공됩니다. TRELLIS 재질 단계의 정규화 때문에 두 원본의 크기는 다르며, 최종 모델은 재질 원본 크기에 정렬돼 있습니다.
- 원래 형태 시도 3회·재질 1회·자동 감량 2회 기록과 실패 후보를 보존했습니다. 이후 보정에는 AI 추가 생성을 사용하지 않았습니다.
