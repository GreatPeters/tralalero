# R11 검정·노랑 볼라드

14,285삼각형 모델입니다. 서버에서 완료된 첫 TRELLIS 형태를 상태 조회 오류 때문에 놓쳤다가, 같은 작업 ID의 이력과 파일 해시를 검증해 복구했습니다. 형태를 다시 생성하지 않고 첫 재질·첫 감량을 완료했습니다.

- 둥근 본체/상단·노란 반사 띠·원형 받침과 고정 구멍을 유지합니다.
- 기준보다 긁힘이 강하고 반사 띠가 밝으며, 받침 구멍 수가 더 많습니다. 작은 띠 경계/모서리 연화가 남아 있습니다.
- 새 FBX·GLB 검사와 실제 다각도/고밀도 원본 비교를 통과했습니다.
- `original-trellis-source.glb`는 복구한 수정 전 첫 형태입니다. 동봉된 완료 이력/복구 기록은 이 파일의 해시와 원래 작업 ID를 설명합니다.
