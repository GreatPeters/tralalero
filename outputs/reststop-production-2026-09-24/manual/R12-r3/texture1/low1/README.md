# R12 선형 배수 그레이팅

14,726삼각형 모델입니다. TRELLIS 하부 채널·지지부를 유지하고, 후처리에서 막힌 상단을 35개의 관통 슬롯과 테두리로 보정한 뒤 TRELLIS 재질을 적용했습니다.

- 새 GLB·FBX 각각에 대해 3개 폭 위치에서 2,049개씩 수직 광선을 검사했습니다. 여섯 단면 모두 깊게 열린 구간35개를 유지했습니다.
- `opening-validation.json`과 두 형식의 상세 단면 데이터가 검증 폴더에 포함됩니다. 실제 다각도 렌더와 고밀도 원본도 비교했습니다.
- 원래 형태 시도1회·재질1회·최종 감량1회입니다. 형태를 다시 생성하거나 원래 원장을 초기화하지 않았습니다.
- 상부 테두리/끝 마감은 직접 보정한 구조이며, 기준보다 조금 차가운 금속색과 미세 모서리 연화가 남아 있습니다. 정적 형상 검사이며 유체 시뮬레이션은 포함하지 않습니다.
