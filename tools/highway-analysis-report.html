02 / OBSERVED PROBLEMS

실제로 막힌 것은
길보다 먼저, 시야입니다.

P0 · 배치 충돌 / 재현됨

우회로가 대형 산 모델
안으로 들어갑니다.

첫 우회로 135~285m에서 Mountain_Ridge의 바운딩 박스가 주행 중심 주변과 겹칩니다. 19초 촬영에서는 나무가 도로를 덮고, 회복 지점 촬영에서는 큰 검은 면이 전방을 가립니다.

이 오브젝트는 개별 나무가 아니라 나무까지 포함한 산 배경 메시입니다. 이름이 Tree인 개체만 찾으면 빠지고, 기존 우회로 정리 코드도 폭이나 깊이가 60m를 넘는 모델을 제외합니다. 해당 모델의 범위는 약 120 × 54 × 176m입니다.

판단: 의도한 ‘회복 쉼터’ 연출로 보기 어렵습니다. 배경 모델을 우회로·카메라 시야에서 옮기거나, 구간별로 다시 구성하는 것이 우선입니다. 이번 작업은 분석이며 씬 수정은 하지 않았습니다.

P1 · 전투 진입 / 10회 관측

첫 선택을 하기 전에,
또는 합류 직후에 죽습니다.

왼쪽 진입을 목표로 한 5회는 약 65m에서 종료됐습니다. 첫 분기 확정점은 80m이므로, 이는 ‘왼쪽 본선 분기를 완주한 결과’가 아닙니다. 오른쪽을 목표로 한 5회는 첫 우회로를 통과한 뒤 약 334m에서 종료됐습니다.

마지막 피해 원인은 모두 적 접촉입니다. 현재 접촉 로직은 고정 피해가 아니라 적의 남은 체력과 플레이어 체력을 서로 차감합니다. 체력 500을 웃도는 적이 남아 있으면 한 번의 접촉으로 끝날 수 있습니다.

자동 조작이 적을 충분히 처치하지 못한 영향이 있습니다. 이 10판만으로 ‘사람도 반드시 죽는다’거나 ‘강화 비용을 낮춰야 한다’고 결론 내릴 수 없습니다. 사람 입력에 가까운 1배속 재검증이 필요합니다.

P2 · 의미 전달

‘회복 우회로’가
‘졸음쉼터’로 읽히지 않습니다.

현재 보상은 멈춰 쉬거나 시설을 이용하는 행동 없이 특정 진행거리에서 자동 지급됩니다. 본선과 우회로가 곧 합류한다는 정보, 회복량, 선택 확정 시점이 한눈에 연결되지 않습니다.

우회로는 작은 쉼터·주차 공간·회복 표시가 보이는 도로로 정리하고, 본선은 ‘교전 / 보상’, 우회로는 ‘회복 / 일부 구간 회피’로 선택의 대가를 알려주는 편이 자연스럽습니다.

현재 강점도 있습니다.

분홍·초록 유도선으로 구분하고 실제 곡선으로 벌어졌다가 합류하는 구조는 동작합니다. 우회 선택과 회복 지급은 기록에 남고, 뒤의 분기도 같은 규칙을 사용합니다. 분기 시스템을 새로 만들기보다 배경 배치와 선택 안내를 먼저 손보는 것이 합리적입니다.

상단 Combat Harness 표시는 에디터 진단 UI입니다. 이번 촬영에 보이지만 모바일 빌드의 상시 UI라고 판단하지 않았습니다.

03 / TEN COMBAT ATTEMPTS

10판, 기록 그대로.

같은 저장 상태에서 시작하고 매번 원래 상태로 되돌렸습니다. 영구 강화 구매·체력 보정·텔레포트·위험물 비활성화 없이 일반 이동 함수를 한 게임 프레임에 한 번 호출했습니다. 게임은 3배속으로 실행했습니다.

회차계획 (1차→2차)실제 분기게임 시간도달 거리결과

L = 왼쪽, R = 오른쪽. 2차 분기는 일반 전투 10판에서 모두 미도달입니다. 결과는 자동 조작 1종의 관측치이며 사용자 집단의 승률 통계가 아닙니다. 회복 발동 시점의 체력과 개별 피해는 원본 JSON에서 확인할 수 있습니다.

04 / FULL ROUTE SURVEY

후반은 별도 조건으로
길 전체를 살펴봤습니다.

아래 2회는 10판 전투에 포함하지 않습니다. 캐릭터 콜라이더를 끄고 체력을 100,000 이상 유지한 시야·동선 관찰입니다. 실제 전투 완주나 난이도 검증의 증거로 쓰지 않습니다.

05 / RECOMMENDED ORDER

지금 고친다면, 이 순서입니다.

  1. 우회로 135~285m의 산·수목 겹침부터 제거

    큰 모델의 피벗이나 이름보다 실제 메시 범위와 게임 카메라로 검사합니다. 작은 나무만 옮기거나 카메라를 높이는 조치만으로 끝내지 않습니다.

  2. 첫 적과 합류 뒤 적을 1배속으로 다시 검증

    공격이 맞는지, 회피 차로가 실제로 남는지, 잔여 체력 교환이 충분히 예고되는지 확인합니다. 자동 조작 수정과 게임 밸런스 수정을 섞지 않습니다.

  3. 선택 전에 ‘본선 / 쉼터 / 합류’를 설명

    분기 전 안내에 회복량과 합류 위치를 표시하고, 튜토리얼이나 대형 표지판이 선택 구간을 가리지 않도록 정리합니다.

  4. 우회로의 장소와 선택 비용을 명확히

    졸음쉼터로 보이는 시설·주차·안내를 두고, 본선의 교전·획득 기회와 우회로의 회복을 비교할 수 있게 합니다. 현재 첫 우회는 체력이 가득 차 있어 회복 효용이 없는 판도 나왔습니다.
